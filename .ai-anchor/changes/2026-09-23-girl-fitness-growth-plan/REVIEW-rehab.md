# 运动康复师评审单

## 一、评审范围与方法

- 评审对象：本次新增的 16 篇文档（classification/fitness 9 篇、timeline/fitness 7 篇），只读不改。
- 评审视角：物理治疗 / 运动康复，长期处理青少年运动损伤与术后康复；读者设定为普通家长，方案覆盖 6–18 岁女孩（5 岁起练泰拳）。
- 评审方法：通读全部 16 篇，比对 CHANGE.md 中第 113 行约定的两条硬约束——① 不给诊断结论，只给「何时停、何时就医」；② 负荷与门槛写区间与相对量。重点查六类方向：红线完整性、分级可操作性、是否越界诊断、儿童青少年特有风险、康复与回场标准、首次剂量与高风险动作。
- 依据类型说明：每条标注为「领域共识」「个人经验」「推测」或「分不清」。凡涉及具体数值阈值或最新指南细节的，标注「分不清」表示我未在本次评审中逐一核对原始文献。
- 说明：本评审不评价文风、结构、优点；只挑错，不给修改方案。

## 二、阻断项

### R1　「关节里疼」同时被定为黄灯与红灯，读者会得到相反结论
- 位置：injury-prevention.md，第二步「看位置」第 42–44 行；红灯清单第 78 行。
- 原文引用：
  - 位置步：「在关节里、在骨头的某个点上、在一根筋的走行上：偏黄灯。」
  - 红灯：「关节里疼，或者有关节卡住、打软、锁不住的感觉」
- 问题：同一症状「关节里疼」在位置三步法里被归为「偏黄灯」（降量观察两周），在红灯清单里被列为「停练、去医院」。两处是并列呈现的，文档没有写「红灯优先于位置三步法」。读者按位置步先判断，会得出黄灯结论，与红灯直接矛盾。这正是评审要求排查的「相互交叠或互斥的定义」。
- 后果：家长按黄灯处理关节内疼痛（降量观察），可能延误对真正关节内损伤（如关节内骨折、游离体、感染性关节炎）的就医。
- 依据类型：领域共识（儿童关节疼痛的处理需谨慎，且两者不可并存于同一规则）。

### R2　0–10 分标尺与红灯清单是两套互不引用的系统，标尺可让严重伤病被「观察两周」
- 位置：injury-prevention.md，第一节「疼痛 0 到 10 分」第 27–35 行；红灯第 74–87 行。
- 原文引用：
  - 标尺：「4–5 分 … 降量：负荷减半或降一级台阶，观察两周」「6–7 分 … 停这一项，改做不疼的动作，两周不好转就看医生」
  - 红灯：「以下任何一条，都要停下来，并且尽快去医院。不要先观察两周。」
- 问题：0–10 分标尺是全篇第一个、也是最被强调的判断工具，但它与红灯清单没有任何交叉引用。一条同时满足「自评分 4–7 分」和「红灯条目」（如局部骨头点剧痛、关节肿胀、受伤当时肿起来）的疼痛，按标尺得到「降量观察两周 / 两周不好转再看医生」，按红灯得到「立刻去医院、不要先观察两周」。文档第 21 行虽有「拿不准就去看医生」的兜底，但过于笼统，无法纠正标尺给出的具体「观察两周」指令。
- 后果：一处本该立即就医的损伤（如应力性骨折、骨骺损伤）被按标尺指令在家观察两周，可能错过处理窗口。
- 依据类型：分不清（两套系统并存是文本事实，但「会导致延误」是推测性后果链；机制判断属领域共识）。

### R3　缺失儿童青少年急腹症 / 盆腔急症的就医红线
- 位置：injury-prevention.md 红灯清单（第 74–87 行），全篇未出现腹部 / 盆腔相关信号。
- 原文引用：红灯清单十条，涵盖关节、骨点、肿、变形、神经、头颈、胸痛晕倒，但无一条涉及「突发剧烈腹痛 / 盆腔痛」。
- 问题：对象是女孩，方案覆盖到 18 岁。青少年女性突发下腹痛可能是卵巢扭转、宫外孕、阑尾炎等需急诊处理的急症；任何年龄儿童的急性剧烈腹痛都可能是阑尾炎。这类信号在运动场景里会出现（运动中或运动后腹痛），但现行红线完全没有覆盖。
- 后果：家长把急腹症当成「岔气 / 肠胃不适」在家观察，可能延误阑尾穿孔、卵巢扭转等时间敏感急症。
- 依据类型：领域共识（儿科急腹症属必须立即就医的红线）。

### R4　缺失「生长中儿童跛行 + 髋/膝痛」这条儿科经典漏诊红线，且生长痛鉴别表可能掩盖它
- 位置：injury-prevention.md 生长痛与损伤鉴别表（第 95–108 行）；红灯清单无髋部 / 跛行相关条目（仅 phase-12-15 第 108 行零散提到「明显跛行」针对脚跟 / 膝盖）。
- 原文引用：
  - 鉴别表结论：「生长痛不需要治疗，也不需要停运动。但它有两条底线：只在小腿上、只在夜里、只按不到点。只要偏离了这三条中的任何一条，就按损伤处理。」
  - 表中「走路 正常」作为生长痛特征之一。
- 问题：儿童的膝痛常是髋部疾病的「牵涉痛」（如股骨头骨骺滑脱 SUFE，好发于 10–16 岁，女孩亦可发生，常仅表现为膝痛 + 跛行 + 下肢外旋），这是儿科最常见的漏诊之一。现行规则把「双侧、夜里、按不到点、走路正常」的腿痛都归为生长痛，没有提示「单侧腿痛伴跛行、或髋部不适」应作为骨科急症排查。生长痛本身极少需要就医，反而可能让家长把 SUFE 的早期表现也按「偏离三条就当损伤」轻描淡写地处理，而非尽快就医。
- 后果：SUFE 等骨骺滑脱若延误，可致股骨头缺血坏死、永久性跛行，属时间敏感损伤。
- 依据类型：领域共识（SUFE 是儿科运动损伤的经典漏诊，跛行 + 生长中儿童即应警惕）。

### R5　脑震荡只有「撞后看医生」一句话，缺循序渐进回场与必须医学 clearance，与泰拳项目风险不匹配
- 位置：muay-thai.md 第 125 行；injury-prevention.md 第 86 行；phase 各篇红灯引用。
- 原文引用：
  - muay-thai.md：「一次明显撞头之后，当天不能继续练，之后要用比成人更保守的标准判断能不能恢复正常活动。撞头后出现头痛、头晕、恶心、反应变慢，要就医。」
  - injury-prevention.md 红灯：「头部被撞击后出现头痛、头晕、恶心、呕吐、反应变慢」
- 问题：文档允许 12 岁以上在护具下做头部击打（muay-thai.md 第 68 行），但对应脑震荡的处理只写了「当天不能练」「之后用更保守标准判断」「出现症状就医」。缺少当前临床共识的核心内容：① 任何疑似脑震荡禁止当日重返对抗；② 回归运动必须经过循序渐进的分阶段方案（通常数天到数周，且每一步无症状才进阶）；③ 回归对抗性项目前需经医务人员 clearance；④ 反复头部冲击的累积风险（二次撞击综合征可致死）。这些对格斗项目尤其关键，文档却只给了一句「更保守」。
- 后果：家长可能在症状消失后自行让孩子回到泰拳对练，未做阶梯式恢复与医学评估，二次撞击风险升高。
- 依据类型：领域共识（脑震荡循序渐进回场 + 医学 clearance 是当前标准，来源如国际共识声明，但具体措辞我未在本次逐一核对，故标注分不清其细节版本）。

## 三、建议项

### R6　6 岁儿童无法可靠自报 0–10 分，标尺在低龄端不可落地
- 位置：injury-prevention.md 第 25–26 行、第 27–33 行（标尺从 6 岁起即用）。
- 原文引用：「让她自己说，不要替她判断。孩子的疼痛主诉很可靠，孩子说疼就是疼，问题只是疼到什么程度」；随后直接用 0–10 数字标尺。
- 问题：方案覆盖 6 岁起，但 6–7 岁儿童对 0–10 数字量表的理解与一致性很差，临床上需使用面部表情量表或由家长 / 观察者结合行为判断。文档断言「主诉很可靠」对「是否疼」成立，但对「疼到几分」不成立，且全文没有为低龄提供替代（如观察跛行、拒绝负重、哭闹、不愿活动）。
- 后果：低龄儿童把真实疼痛低估为「3 分」→ 照常练；或夸张报「10 分」→ 过度限制。最严重的方向是低估导致带伤活动。
- 依据类型：领域共识（学龄前 / 低年级儿童数字疼痛量表信度低）。

### R7　缺失横纹肌溶解（酱油色 / 浓茶色尿）的红线
- 位置：injury-prevention.md 红灯清单（第 74–87 行）。
- 原文引用：红灯清单无尿液颜色相关条目。
- 问题：儿童在突然加大离心负荷（如大量深蹲、波比跳、长途行军式徒步、高温下剧烈运动）后可发生运动性横纹肌溶解，表现为茶色 / 酱油色尿、肌痛、无力。这是可出现在「训练量突然增加」场景里的儿科急症（与本文反复强调的「加量太快」风险直接相关），但红线完全没提。
- 后果：家长把深色尿当成「喝水少」，延误肾损伤就医。
- 依据类型：领域共识。

### R8　缺失运动性热疾病的红线，与「每天户外两小时、风雨无阻」的安排冲突
- 位置：red-line 清单（第 74–87 行）；posture-and-habits.md 第 72–78 行「每天户外两小时」、weekly-rhythm.md 第 28 行「每天约两小时」均不分天气。
- 原文引用：红灯只有「红肿发热，还伴着发烧」（指向感染），没有高热、停止出汗、意识改变、皮肤干热等热射病表现。
- 问题：文档要求儿童「任何排不下的情况先保户外两小时」，且 weather 小节只说雨天换室内，没提高温。儿童体温调节能力弱于成人，热痉挛 / 热衰竭 / 热射病是真实风险。现行红线把「发热 + 红肿」当作感染框架，漏掉了运动性热急症。
- 后果：夏季高温下长时间户外，热射病早期被误判为普通中暑或脱水而延迟降温就医。
- 依据类型：领域共识。

### R9　「红肿发热还伴着发烧」门槛过窄，化脓性关节炎应无发热即就医
- 位置：injury-prevention.md 第 82 行。
- 原文引用：「红肿发热，还伴着发烧」
- 问题：儿童化脓性关节炎 / 骨髓炎早期可表现为关节红、肿、热、剧痛而尚未发热；文档把「发烧」作为并列条件，可能让家长等到发烧才就医。这类感染对关节 / 骨骺破坏快。
- 后果：延误抗生素与引流，造成永久性关节损害。
- 依据类型：领域共识（儿童化脓性关节炎属骨科急症，发热非必需出现）。

### R10　6–7 分「观察两周」与红肿 / 关节内等严重表现不兼容
- 位置：injury-prevention.md 第 32 行（6–7 分：停一项、两周不好转看医生）。
- 原文引用：「6–7 分 … 疼，做完之后还疼，第二天也疼 … 停这一项，改做不疼的动作，两周不好转就看医生」
- 问题：若 6–7 分疼痛伴随关节肿胀、明确扭伤或不能负重，按当前共识应较短时间内评估而非「两周不好转再看」。标尺把「时间」作为唯一推进条件，没有与「是否伴结构性体征」挂钩。
- 后果：韧带撕裂、骨折等被拖到两周后才评估。
- 依据类型：分不清（具体该几天就医无统一数字，但「两周」明显偏长属个人经验判断）。

### R11　晕厥红线仅限「运动中」，运动后 / 静息晕厥未被覆盖
- 位置：injury-prevention.md 第 87 行。
- 原文引用：「运动中胸痛、心慌、眼前发黑、晕倒」
- 问题：运动相关（含运动后即刻、运动诱发的）晕厥都需排查心源性原因；文档把晕厥限定在「运动中」，可能让家长把训练后或休息时的晕倒当成普通低血糖而忽略心脏评估。
- 后果：潜在心律失常 / 结构性心脏病被漏检。
- 依据类型：领域共识（运动相关晕厥需心脏评估）。

### R12　未提及运动诱发支气管收缩（运动性哮喘）
- 位置：全篇（injury-prevention、parents-and-school 告知老师部分）。
- 原文引用：无相关条目；parents-and-school.md 第 93 行只列「过敏、癫痫等需要应急处理的情况」，未含喘息 / 胸闷。
- 问题：运动性哮喘在儿童运动员中常见且常被误认为「体质差 / 不愿动」。文档未提示「运动中反复胸闷、喘息、咳嗽、恢复慢」应就医排查，也未提示家长应把这类情况告知教练 / 老师。
- 后果：未确诊的 EIB 儿童被误判为偷懒或体能不足，既影响参与也耽误用药管理。
- 依据类型：领域共识。

### R13　能量不足对骨密度的不可逆损害表述偏轻
- 位置：fuel-and-sleep.md 第 44、80–82 行；phase-15-18.md 第 95 行。
- 原文引用：「骨量在 20 岁前形成大部分，青春期是最后窗口」「这组表现里，月经是最重要的一个信号 … 月经乱了或停了，先考虑能量问题，再考虑别的」。
- 问题：文档把能量不足与月经、骨密度并列，但未强调青春期骨量的丢失在女性运动员三联征 / RED-S 中可能不可逆，且低骨密度 + 月经停止的青少年一旦发生骨折（尤其应力性骨折）风险显著升高。现行写法偏「可恢复」语气，弱化了对「停经即需尽快就医、而非先在家调饮食」的紧迫性。
- 后果：停经被当成「调调饮食就好」的家务事，延误内分泌 / 骨科评估。
- 依据类型：领域共识（青春期骨量丢失可部分不可逆）。

### R14　生长痛「只在小腿上」界定偏窄，且「自贴生长痛标签」有掩盖风险
- 位置：injury-prevention.md 第 108 行。
- 原文引用：「只在小腿上、只在夜里、只按不到点。只要偏离了这三条中的任何一条，就按损伤处理。」
- 问题：典型生长痛可累及小腿、大腿前侧及膝后，单侧亦可；文档把位置限定为「只在小腿上」，反而可能让家长在孩子诉大腿痛时不当作生长痛、或反过来在「小腿痛」时过度放心。更大的问题是整张表鼓励家长自行区分「生长痛 vs 损伤」，而生长痛是排除性诊断，需先排除器质问题（见 R4 的 SUFE 牵涉痛）。
- 后果：把本应就医的下肢痛自行归为生长痛。
- 依据类型：领域共识（生长痛为排除性诊断，分布不限于小腿）。

### R15　靠近关节的创伤未提示「骨骺 / 生长板」时间敏感性
- 位置：injury-prevention.md 红灯（第 80–81 行提及肿、变形、不能负重），但未点出儿童骨折靠近生长板。
- 原文引用：红灯含「受伤当时听到响声、或者立刻肿起来」「完全不能负重、走不到四步」「明显的变形」。
- 问题：儿童骨折多累及骺板（生长板），错误处理可致生长停滞 / 肢体不等长。文档用成人化语言写「变形 / 不能负重」，未提醒家长「儿童关节附近外伤即便看似不重，也应尽快影像评估」，也没有点出骨骺损伤这一概念。
- 后果：骨骺损伤被当作普通扭伤，延误固定，影响骨骼发育。
- 依据类型：领域共识。

## 四、偏离项

### R16　「抗炎药可能影响组织修复」的机制性断言证据并不统一
- 位置：injury-prevention.md 第 176 行（恢复手段表）。
- 原文引用：「抗炎药 | 可能影响组织本身的修复过程 | 不常规吃，有医嘱除外」
- 问题：NSAIDs 对肌腱、韧带、骨愈合的影响在文献中结论不一，急性期短期使用的利弊仍有争议。把「影响修复」作为确定性陈述略过强；不过「不常规吃、遵医嘱」的行动建议本身是安全且符合 PEACE/LOVE 精神的，故仅作为偏离而非阻断。
- 后果：轻微——可能让家长对偶尔一次止痛用药产生不必要恐惧，但不造成直接伤害。
- 依据类型：分不清（该机制证据存在分歧，我未在本次核对原始 RCT）。

### R17　急性:慢性负荷比 0.8–1.3 与「每周加量不超一成」被写成刚性规则
- 位置：injury-prevention.md 第 114–118 行。
- 原文引用：「看本周和最近四周平均量的比值，让它大致落在 0.8 到 1.3 之间。超了 1.3，就是危险区」「每周加量不超过一成」
- 问题：ACWR 阈值本身在运动医学界存在 methodological 争议，且儿童青少年更应关注绝对负荷与动作质量，而非简单套用成人训练学的比值。写成「危险区」式硬规则，可能让家长机械套用而忽略「这个孩子本次的绝对量是否已经过大」。作为科普启发可用，作为规则略偏离共识。
- 后果：轻微——过度依赖比值可能忽略绝对过量；或反之因比值「合规」而放松对单次大剂量的警惕。
- 依据类型：分不清（ACWR 阈值证据等级我未逐一核对）。

### R18　「波比跳（年龄够的话）」门槛模糊，对低龄是高水平冲击动作
- 位置：weekly-rhythm.md 第 120 行。
- 原文引用：「室内替代方案：跳绳、爬楼梯、靠墙静蹲、平板、波比跳（年龄够的话）、走廊里的熊爬。」
- 问题：波比跳包含落地冲击与俯卧撑支撑，对低龄儿童属高冲击、高协调要求的复合动作，仅以「年龄够的话」模糊带过，没有说明从什么年龄、什么退阶开始。违反「首次出现不给高剂量、要有门槛与退阶」的原则（CHANGE.md 风险缓解约定②）。
- 后果：轻微——低龄儿童直接做波比跳，落地姿势失控增加膝踝冲击。
- 依据类型：个人经验。

### R19　红线未包含骨筋膜室综合征 / 进行性神经血管损害
- 位置：injury-prevention.md 红灯清单（第 74–87 行）。
- 原文引用：清单含「麻、无力，伴颈部不舒服」，但未提「疼痛与损伤不成比例、肢体进行性肿胀发凉、搏动消失、感觉减退」。
- 问题：骨筋膜室综合征虽相对少见，但在儿童肢体创伤 / 绷带加压不当后可发生，且进展快、致残高。现行红线只在「伴颈部不舒服」语境下提麻无力，肢体本身的进行性神经血管恶化未被单独列出。
- 后果：轻微（发生率低），但一旦漏判致残率高。
- 依据类型：领域共识。
