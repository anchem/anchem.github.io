# 价值认知

本分组讨论价值本身的定义与生成机制——在讨论「对谁有价值」之前，先说清楚「价值到底是什么」。

## 包含内容

- [什么是价值](./what-is-value.md)：价值的定义、三重属性、使用价值与交换价值
- [价值链](./value-chain.md)：价值从创意到变现的传递路径，以及每个环节的增值与损耗

## 为什么先讲这个

「价值」在日常对话里被用得很随意：有时指收入，有时指用户满意度，有时只是指「我做了很多事」。概念不澄清，后面的商业价值、用户价值、价值度量就没有共同的地基，讨论会退化成各说各话。

## 建议阅读顺序

先读「什么是价值」建立定义，再读「价值链」把定义放进流程。
