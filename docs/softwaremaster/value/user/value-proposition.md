# 价值主张

价值主张用一句话说清：**为谁、解决什么问题、凭什么解决得比别人好**。它是从价值分析跨到需求实现的桥梁。

## 一句话结构

> 我们帮【主体】解决【问题】，通过【独特手段】，而其他方案做不到【差异点】。

三个空都填不满，说明价值主张还没成型。

## 合格的标准

1. **可证伪**：能指出一个具体场景，如果在该场景下这句话不成立，它就是错的。
2. **有替代方案对照**：不说「比别的更好」，而说「相比用户现在用的 X，在 Y 上更好」。
3. **不含形容词**：把「高效」「强大」「智能」这类词划掉，如果剩下的句子仍然成立，它才是真的。

## 常见错误

| 错误写法 | 问题 |
| --- | --- |
| 为所有人提供一站式解决方案 | 主体不清等于没有主体 |
| 业界领先的性能 | 无对照物，不可证伪 |
| 让工作效率提升 10 倍 | 缺少手段与对照，数字凭空而来 |

## 实践建议

- 把价值主张贴进需求文档的第一页。评审任何需求时先问它服务于哪一句，答不上来的需求要重新评估。
- 价值主张会随认识深化而修订，这是正常迭代。真正危险的是从不修订——那说明从未验证过。
