# 商业价值

商业价值回答：这件事对**组织**意味着什么。它是价值在商业语境下的展开，也是绝大多数软件项目存在的直接理由。

## 包含内容

- [商业模式](./business-model.md)：产品如何创造、传递并捕获价值
- [盈利能力](./profitability.md)：价值如何转化为可持续的财务结果

## 与用户价值的关系

商业价值与用户价值**长期一致、短期经常冲突**。

- 长期一致：没有用户价值支撑的商业价值不可持续，靠垄断或信息差赚的钱会随条件变化消失。
- 短期冲突：缩短免费额度能立刻提升收入，但会伤害体验；砍掉边缘需求能省成本，但会流失特定人群。

工程团队的常见误区，是把「商业价值」当成「老板的想法」而不予理会。实际上，理解商业价值是工程师判断技术方案取舍的前提——同一条技术路线，在不同的商业模式下优先级完全不同。
