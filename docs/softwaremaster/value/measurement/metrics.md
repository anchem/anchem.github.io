# 度量指标

指标的作用是让价值主张可被证伪。选错的指标比没有指标更糟——它会把人引导到错误的方向上，还提供「数据支持」。

## 常见指标类型

| 类别 | 示例 | 说明 |
| --- | --- | --- |
| 增长 | 新增用户、激活率 | 反映触达与传递 |
| 粘性 | 留存率、使用频次 | 反映真实的价值认可 |
| 质量 | 故障率、恢复时间、缺陷密度 | 反映交付与运维健康度 |
| 效率 | 需求交付周期、发布频率 | 反映组织能力 |
| 成本 | 单位用户成本、资源利用率 | 反映盈利能力 |

## 好指标的几个特征

1. **可对照**：有基线、有比较对象。孤立数字没有意义。
2. **难伪造**：能被轻易刷高的指标会立刻失真。把「提交次数」当效率指标，团队就会拆细提交。
3. **指向行为**：指标变化时，能明确知道该调整什么动作。
4. **成对出现**：单个指标几乎总能被以损害其他方面的方式优化。留存配成本、速度配质量、增长配合规。

## 古德哈特定律

> 当一个度量标准变成目标本身时，它就不再是一个好的度量标准。

这不是说不该设指标，而是说：指标要定期审定，且必须留出「用数据之外的方式做判断」的空间。

## 实践建议

- 为每个关键指标写下「如果它异常，我们会做什么」。答不上来，这个指标就不必上报表。
- 优先选择**结果指标**，过程指标只用于诊断。
- 保留一份「我们决定不度量什么」的清单，防止指标通胀。
