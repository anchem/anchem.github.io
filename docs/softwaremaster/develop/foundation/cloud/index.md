# 云计算

云计算的本质是**把计算资源变成可按需取用的服务**，让组织从「拥有基础设施」转变为「消费基础设施」。

## 包含内容

- [服务模型](./service-models.md)：IaaS / PaaS / SaaS 的责任边界
- [云原生](./cloud-native.md)：为云环境设计的应用形态

## 真正的变化在哪里

云计算改变的不只是成本结构，更是**工程决策的时间尺度**：

| 维度 | 自建 | 云上 |
| --- | --- | --- |
| 资源获取 | 周 / 月级采购 | 分钟级 |
| 成本形态 | 固定资本支出 | 变动运营支出 |
| 容量规划 | 按峰值准备，长期闲置 | 按需弹性 |
| 失败假设 | 机器很少坏 | 实例随时可能被回收 |
| 运维重心 | 维护硬件与机房 | 管理配置、权限与成本 |

其中最有深远影响的是最后两条：**云环境强制你把「失败是常态」写进架构**，这也是[云原生](./cloud-native.md)方法论的核心。

## 成本是新的架构约束

按量计费意味着架构决策会直接转化为账单。常见成本陷阱：

- 数据跨境与跨可用区传输费用；
- 闲置资源（未挂载的存储、未使用的预留实例）；
- 日志与追踪数据的长期存储；
- 过度冗余与过度分片带来的管理成本。

**成本应当作为架构的质量属性之一，与性能、可用性一起被评估。**

## 一条建议

云的抽象降低了入门门槛，但没有降低分布式系统的固有复杂度。遇到问题时仍然需要回到[网络](../network/index.md)、[操作系统](../operating-system/index.md)与[分布式](../distributed/index.md)的原理去解释现象。
