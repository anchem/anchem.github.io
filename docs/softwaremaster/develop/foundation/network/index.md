# 计算机网络

网络的本质是**在不可靠的介质上构建可靠的通信**。这个前提决定了几乎所有的网络现象：重传、超时、乱序、延迟抖动。

## 包含内容

- [TCP/IP](./tcp-ip.md)：分层模型、连接与可靠性机制、成本模型
- [HTTP](./http.md)：应用层协议与它的演进方向
- [网络安全](./network-security.md)：传输安全与网络层防护

## 为什么必须懂网络

| 现象 | 网络层原因 |
| --- | --- |
| 偶发超时 | 重传超时、拥塞窗口回退 |
| 服务间调用慢 | 往返次数过多、跨机房 |
| 连接数打满 | 连接状态生命周期与端口占用 |
| 长连接莫名断开 | 中间设备回收空闲连接 |
| 压测结果与生产不符 | 延迟不同导致并发模型表现不同 |

**网络的成本模型与内存完全不同**：一次同机房往返约在百微秒级，跨地域可达几十毫秒。这个差距意味着「减少一次远程调用」往往比「优化一整天本地代码」更有效。

## 核心认知

### 延迟与带宽是两个独立的问题

带宽决定能传多少，延迟决定要等多久。加大带宽无法减少延迟。小数据量的请求性能由延迟主导，大数据量传输才受带宽约束。

### 层与层之间是抽象而非隔离

分层的意义是每层只管自己的问题，但**排查问题时必须能穿透层级**：应用层超时可能是 TCP 重传，也可能是 DNS 解析慢。

### 可靠性的代价

TCP 的重传机制在延迟上仍然是不可靠的——它保证数据到达，不保证准时到达。因此超时与重试是应用层必须承担的职责。

## 与其他内容的关系

网络是[分布式系统](../distributed/index.md)的物理基础：分布式系统的一切难题，本质上都源自网络的不确定性与节点间的距离。
