# 离散数学

离散数学研究**离散结构**：集合、关系、图、逻辑、组合。计算机处理的正是离散对象，因此它是计算理论的地基。

## 四个核心部分

| 部分 | 内容 | 软件中的对应 |
| --- | --- | --- |
| 集合论 | 集合运算、基数、映射 | 数据类型、查询语义、去重与聚合 |
| 关系与序 | 等价关系、偏序、格 | 依赖排序、权限继承、多版本控制 |
| 图论 | 遍历、最短路、连通性、匹配 | 依赖分析、调度、推荐、路由 |
| 数理逻辑 | 命题与谓词逻辑、可满足性 | 约束校验、规则引擎、类型系统、SMT 求解 |

## 图论是最实用的一块

软件开发中大量问题本质上是图问题：

- **构建依赖**：有向无环图的拓扑排序，环检测。
- **服务调用链**：可达性分析与关键路径。
- **任务调度**：带约束的排序与分配。
- **状态机**：状态转移图，可达性与死锁检测。

识别出「这是一个图问题」，往往直接给出了可行算法与复杂度。

## 逻辑与约束

规则密集的业务（定价、风控、合规）本质是约束求解。把规则表达成逻辑命题后，可以借助 SAT/SMT 求解器做一致性检查——例如检测规则集中是否存在互相矛盾或永不可达的分支。这比人工评审可靠得多。

## 实践建议

- 建模时先问「这是不是图 / 是不是约束问题」，再考虑实现手段。
- 组合计数能力决定了你能否估算状态空间规模，这直接影响能否穷举。
- 不必记住定理，但要知道每种结构上「什么问题有已知的高效解法」。
