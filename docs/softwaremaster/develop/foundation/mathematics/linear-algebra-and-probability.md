# 线性代数与概率统计

这两块是**数据与不确定性**的语言，在人工智能、性能建模与实验分析中不可替代。

## 线性代数

核心对象是**向量与矩阵**，核心操作是**线性变换**。

| 概念 | 含义 | 软件中的用途 |
| --- | --- | --- |
| 向量空间 | 可加、可缩放的集合 | 特征表示、嵌入向量 |
| 矩阵乘法 | 线性变换的复合 | 神经网络前向计算、图算法 |
| 特征值 / 奇异值 | 变换的主要方向与强度 | 降维、推荐、稳定性分析 |
| 正交与投影 | 分解为独立方向 | 最小二乘、主成分分析 |

它之所以在机器学习中占核心地位，是因为**矩阵运算可以被高效并行化**——这是 GPU 加速的前提，也是模型能规模化的原因。

## 概率统计

它处理的是「不确定」这件事，而非给出确定答案。

| 概念 | 含义 | 软件中的用途 |
| --- | --- | --- |
| 随机变量与分布 | 取值的规律 | 请求到达建模、延迟分布 |
| 期望与方差 | 中心与离散程度 | 容量规划、SLO 设定 |
| 条件概率与贝叶斯 | 由证据更新判断 | 异常检测、风控、诊断 |
| 大数定律与中心极限定理 | 样本均值的收敛行为 | A/B 实验的样本量估算 |
| 假设检验 | 判断差异是否显著 | 实验结论的有效性 |

## 最容易犯的错

**用平均值描述长尾**。请求延迟、文件大小、用户活跃度都呈重尾分布，平均值几乎不携带信息——它既不能代表典型用户，也不能代表最差用户。这也是[性能需求](../../../requirement/analysis/nonfunctional/performance.md)必须约束分位数的原因。

## 实践建议

- 做容量规划时用分位数而非均值，并预留尾部余量。
- 做 A/B 实验前先估算所需样本量，否则得到的「显著差异」多半是噪声。
- 面对高维数据先想降维，再想算法。
