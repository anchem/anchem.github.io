# 数学基础

数学在软件开发中的作用不是「算出答案」，而是**提供精确描述问题的语言**。当一个问题能被数学地表述，它的难度、边界和解法空间往往同时变得清晰。

## 包含内容

- [离散数学](./discrete-math.md)：集合、关系、图、逻辑——计算机可计算对象的数学基础
- [线性代数与概率统计](./linear-algebra-and-probability.md)：向量、矩阵、分布与推断——数据与模型的语言

## 三个最常被实际用到的分支

| 分支 | 典型用途 |
| --- | --- |
| 图论 | 依赖分析、任务调度、最短路径、社交关系计算 |
| 逻辑与集合 | 约束表达、权限模型、查询语义、类型系统 |
| 概率统计 | 容量规划、异常检测、A/B 实验、机器学习 |

## 与其他学科的关系

- 数学是[算法与数据结构](../algorithm/index.md)的前提：复杂度分析本身就是数学。
- 概率统计是[人工智能](../ai/index.md)的直接基础。
- 图论渗透在[软件架构](../../development/architecture/index.md)的依赖治理中。

## 一条建议

不必追求系统性的数学训练，但要对**问题属于哪一类**有判断：一个约束求解问题、一个图论问题、一个概率问题，其解法形态完全不同。判断错了类别，再多工程努力也是白费。
