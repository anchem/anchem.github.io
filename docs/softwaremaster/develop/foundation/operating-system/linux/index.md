# Linux

Linux 是服务端事实上的标准运行环境。理解它的几个核心机制，是排查线上问题的基本功。

## 包含内容

- [Linux 安全](./security.md)：权限模型、隔离机制与常见加固手段

## 几个必须掌握的能力

| 能力 | 用途 |
| --- | --- |
| 进程与资源观察 | 定位 CPU、内存、IO 的异常来源 |
| 文件描述符与网络状态 | 排查连接耗尽、端口占用、TIME_WAIT 堆积 |
| 权限与用户模型 | 理解越权风险与最小权限落地 |
| cgroup 与 namespace | 理解容器行为的边界 |
| 日志与内核消息 | 发现 OOM、磁盘错误、网络丢包的根本原因 |

## 排查的通用顺序

1. 先看**现象的范围**：单机还是全局、持续还是突发。
2. 再看**瓶颈类别**：CPU、内存、IO、网络，四者必居其一。
3. 然后**下钻到进程与线程**，而不是直接读应用日志。
4. 最后回到**内核层**解释现象（页回收、调度、连接状态）。

跳过第 2、3 步直奔应用日志，是排查中最常见的低效路径。

## 与其他内容的关系

Linux 的实现细节是[容器技术](../../container/index.md)的基础：namespace 与 cgroup 正是容器隔离与限额的两大支柱。
