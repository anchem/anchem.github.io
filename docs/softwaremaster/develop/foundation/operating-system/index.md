# 操作系统

操作系统是程序**真实运行的环境**。很多「莫名其妙」的问题——进程被杀、内存涨、文件描述符耗尽、延迟抖动——答案都在这一层。

## 包含内容

- [进程与线程](./process-and-thread.md)：程序如何被调度与隔离
- [内存管理](./memory-management.md)：虚拟内存、分配与回收
- [文件系统](./filesystem.md)：数据的持久化组织与 IO 特性
- [Linux](./linux/index.md)：工程实践中最重要的操作系统实现

## 为什么工程上必须懂

| 现象 | 背后的操作系统机制 |
| --- | --- |
| 服务被 OOM Killer 杀掉 | 内存超限与内核的回收策略 |
| 压测时延迟周期性抖动 | 页回收、写回、GC 与调度的交互 |
| 连接数上不去 | 文件描述符上限、TCP 连接状态与端口占用 |
| 容器里 CPU 用不满 | cgroup 配额与 CPU 调度 |
| 磁盘写日志阻塞请求 | 页缓存与同步写语义 |

这些问题的共同点是：**应用层代码完全正确**，但结果不对。只读应用日志永远找不到原因。

## 三个核心抽象

1. **进程**：资源分配与隔离的单位。
2. **虚拟内存**：每个进程看到的独立地址空间，是隔离与抽象的基石。
3. **文件**：统一了磁盘、设备、管道、socket 的访问方式（一切皆文件）。

理解了这三个抽象，容器、虚拟化、性能调优就有共同的地基——[容器技术](../container/introduction.md)正是对这三个抽象的直接运用。
