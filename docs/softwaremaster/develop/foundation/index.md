# ICT 理论基础

这里收录支撑软件开发的基础原理。它们很少被直接调用，却决定了技术判断力的上限。

## 怎么用这个板块

不建议按顺序通读——基础理论的学习应当**由问题驱动**。更有效的用法是：

1. 遇到一个说不清的技术现象（为什么加了索引还是慢、为什么并发下数据不对），回到对应学科；
2. 从该学科的 index 找到相关条目；
3. 把结论带回去解释现象，而不是只记住结论。

## 一条原则

一个新技术的出现，一定是为了解决一个问题的，而一个问题的出现一定有其背景和历史。学习技术时不要忽略本原的问题而迷失在技术细节里——**先问它替代了什么，再问它怎么做到的**。
