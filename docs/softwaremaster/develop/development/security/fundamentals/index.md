# 安全基础

安全基础提供判断安全方案是否成立所需的**密码学常识**与**漏洞类别认知**。

## 包含内容

- [密码学应用基础](./crypto.md)：加密、哈希、签名与密钥管理的正确用法
- [常见漏洞类别](./owasp.md)：高频漏洞类目与它们的成因

## 为什么工程上必须懂

安全方案的失效**很少来自算法被攻破**，绝大多数来自用法错误：

| 错误用法 | 后果 |
| --- | --- |
| 用哈希直接存口令 | 离线爆破 |
| 使用 ECB 模式加密 | 结构泄露，相同明文产生相同密文 |
| 自行设计加密方案 | 几乎必然存在缺陷 |
| 密钥写死在代码或镜像里 | 随分发泄露 |
| 用加密代替完整性校验 | 密文可被篡改 |
| 使用不安全的随机数 | 密钥与令牌可被预测 |

这些错误有一个共同特征：**代码能跑、功能正常、测试通过**，问题只在被攻击时暴露。

## 学习方式

密码学的学习不必深入数学证明，但必须建立三组判断：

1. **什么场景该用什么原语**（加密 / 哈希 / 签名 / MAC）；
2. **哪些参数与模式是危险的**；
3. **什么时候必须使用成熟库而不是自己实现**。

第三条的答案几乎总是：**始终使用成熟库**。
