# Java

Java 是服务端应用最广泛的语言之一：强类型、跨平台、生态成熟，且提供了完整的并发与内存管理基础设施。它的工程实践高度依赖对运行时机制的理解。

## 包含内容

- [集合框架](./collections.md)：数据结构的选择与其代价
- [并发编程](./concurrency.md)：内存模型、同步机制与并发工具

## 几个必须理解的核心机制

| 机制 | 影响 |
| --- | --- |
| 垃圾回收 | 停顿与内存占用；堆大小与回收器选择直接影响延迟 |
| JIT 编译 | 运行期优化，因此需要预热；这也让基准测试容易失真 |
| 内存模型 | 定义可见性与有序性，是并发正确性的基础 |
| 对象模型 | 引用、继承、装箱、泛型擦除带来的一系列细节 |
| 类加载 | 启动时间、动态特性与运行时诊断的基础 |

## 工程实践要点

- **显式设置堆大小**：默认值基于物理内存推算，在容器中可能失准，导致 OOM 或资源浪费。
- **保留堆转储能力**：内存问题几乎无法靠日志定位，堆转储是必需的。
- **关注 GC 日志**：它是判断内存健康度最直接的数据来源。
- **谨慎使用反射与动态代理**：它们会削弱静态分析与编译期优化能力。

## 实践建议

- 应用要正确处理终止信号，实现优雅关闭，否则会有在途请求丢失。
- 依赖注入与配置外置是标准实践，避免在代码中硬编码环境信息。
- 明确线程池的来源与上限，不要用默认配置承载生产流量。
