# 父母与学校

## 一、父母要做的事，其实只有四件

**一、提供机会和时间。** 接送、器材、把时间从别的地方腾出来。孩子自己想动是没有用的，得有人把场地和时间准备好。这一件是纯执行，谁都替代不了。

**二、做榜样。** 家里有没有人在真的运动，孩子的运动量差得很远。这个影响不通过说教起作用，通过日常起作用：她看到父母换鞋出门跑步，比听一百遍“要多运动”有用。

**三、守住底线。** 睡眠优先于一切安排；吃够；红灯不许练。这三条是硬的，不能因为“今天有课”“教练说要去”而让步。

**四、管住嘴。** 不比较、不当场指挥、不评论身体。第四条听起来最容易，实际上最难，尤其是在场边看比赛的时候。

## 二、父母不该做的六件事

| 不该做 | 为什么 |
| --- | --- |
| 用运动当惩罚 | 一句话就能把运动变成刑具，之后再难变回乐趣 |
| 用奖励换运动 | 外部奖励会把内在动机挤出去，星星没了，运动也停了 |
| 替她做所有决定 | 事情都安排好的孩子，练得再好也只是执行者 |
| 在场边喊战术 | 干扰她，也架空教练 |
| 评论体重、身材、饭量 | 青春期前后这句话的杀伤力最大，而且会留下很久 |
| 拿她和别人比 | 比较给的是外部坐标，她需要的是自己的坐标 |

## 三、在家怎么落地：不需要专门场地

在家训练最容易失败的原因是“要求太高”——以为得有个健身房、得有一小时。其实在客厅那条两米长的过道上，可以完成大部分需要做的事。

**建议的器材，全部加起来不超过几百块：**

- 一根跳绳（最值的器材，练协调、心肺、节奏都靠它）
- 一个软球（练抛接、投掷、手眼配合）
- 一条弹力带（练拉的力量，也是肩部养护最省事的工具）
- 一块垫子（滚翻、支撑、爬行、地面动作）
- 一个可以悬挂的地方（固定式单杠最好。用卡在门框上的那种，要装在结实的门框上，装好先自己吊一吊确认不晃，下面铺点东西，她练的时候大人在场）

**十分钟清单**（从里面挑三到四项，一周换着来）：

- 熊爬或螃蟹爬，来回几趟
- 单脚站立，两边各三十秒（熟练后闭眼）
- 深蹲或单腿蹲，八到十次
- 靠墙俯卧撑或俯卧撑准备姿势，五到八次
- 悬垂或吊一会儿，累计三十秒
- 跳下停稳，五到八次（从台阶或矮凳上）
- 跳绳，一两分钟
- 抛接球，一分钟

在家的部分不求量、不求累，只求两件：**动作做像样，一周别断。** 详细的分龄剂量在[运动的整体安排](../../timeline/fitness-overview.md)和各阶段正文里。

## 四、学校这一边：怎么用，用到什么程度

学校体育是基础，但它不等于全部。一个孩子只靠体育课，运动量通常是不够的——一周两三节课，扣掉集合和讲解，真正动起来的时间有限。

**可以主动利用的几处：**

- **体育课。** 把它当成动作库的补充：课上学的东西往往比家里更系统，尤其是器械类项目。别把它当成唯一来源。
- **课间和大课间。** 这是最容易被浪费的十分钟到半小时。让她课间真的出去动一动，累计起来是一天里很大的一块。
- **校内社团和校队。** 如果学校有可以长期参加的项目，建议选一个。它的价值有一半在运动，有一半在同伴关系。
- **上下学。** 能走一段就走一段，能骑车就骑车。这是每天白送的二十分钟活动量。
- **运动会和集体项目。** 参与比名次重要得多。让她体验一次为集体出力，这样的机会不多。

**体质健康测试这件事，单独说一句。** 学校会测 50 米跑、坐位体前屈、仰卧起坐、跳绳、长跑这些项目，成绩会记录进档案。它的用途是筛查和督促，不是训练大纲。**不要为了它专门加练。** 把这五项对应到[身体素质的五个成分](fitness-components.md)里练，成绩自然会好；反过来，为了测试成绩去刷某一个动作，效率最低，也最容易把动作练坏。

## 五、怎么和体育老师、教练沟通

**频率**：每学期一次正式聊一聊就够，平时不用频繁打扰。

**问三件事：**

1. 她的动作和体能有没有明显短板？哪一项建议我们在家补？
2. 她在集体活动里的参与情况怎么样？有没有回避某类项目？
3. 有没有什么安全上的提醒需要我们注意？

**有几件事必须主动告诉老师：**

- 有旧伤，或者有还没完全好利索的部位
- 有慢性病、哮喘、心脏相关的病史
- 有过敏、癫痫等需要应急处理的情况
- 运动时容易胸闷、喘息或咳嗽。这可能是运动性哮喘，先查清楚，别当成体质差
- 最近睡眠或情绪状态明显不好

这几条不说是为了面子，而是万一出事的时候，老师需要知道。

**沟通的口径**要注意一点：不要用“我孩子应该多上场”这种说法开头。老师面对几十个孩子，公平是他们的专业判断。换成“她最近在家里练了什么、想多试试某个项目”，效果完全不同。

## 六、安全和装备

- **鞋。** 最该花钱的装备。跑跳多的时候穿有缓冲的跑鞋，练球类穿支撑好一点的鞋，别一双鞋穿所有场合，也别穿别人穿剩的、已经塌了的鞋。
- **护具。** 骑车、滑板、滑冰一定要戴头盔。泰拳和其他对抗项目按道馆要求配护具，牙套不要省。
- **水。** 每次出门自带水，比在外面买饮料好，也省事。
- **场地。** 家里练跳和落地，要挪开桌角、铺点垫子。户外优先选有缓冲的地面（草地、土路、塑胶场地），少在水泥地上做大量跳跃。
- **独自活动的边界。** 几岁可以自己下楼玩、可以骑多远、可以在哪里，提前定清楚，并且随着她长大逐步放开。这条边界和[成长时间轴](../../timeline/index.md)里写安全常识的部分是一件事。

## 七、一件事归谁管

| 事项 | 谁负责 |
| --- | --- |
| 安排时间、接送、买器材 | 父母 |
| 每天户外两小时、睡眠时长 | 父母（环境与规则） |
| 自己收拾装备、自己热身、自己记录 | 她（按年龄逐步交出去） |
| 动作怎么做对 | 教练或老师 |
| 判断今天疼得能不能练 | 她先说，父母复核，拿不准就问医生 |
| 出现红灯信号 | 父母，立刻停下来去医院 |
| 练不练、练到什么时候、要不要换项目 | 她，父母给信息不给决定 |

## 八、四个常见误区

**把体育课当运动量。** 一周两三节课撑不起一个孩子的活动量，课间、放学后和周末才是大头。

**报很多班。** 一周排四五个运动班，看起来运动量很大，实际每一项都练不透，孩子也累。两个项目加每天户外，比五个班好。

**盯着测试成绩。** 见第四节。测试是体检，不是目标。

**把“我陪她练”变成“我教她练”。** 陪她一起动是有效的，站在旁边纠正动作往往适得其反——尤其是我们自己也不是专业教练的时候，让专业的人做专业的事。
