# 运动与体能

这一部分回答一个问题：**为什么是这些运动。**

具体到某个年龄练什么、一周怎么排，在[运动的整体安排](../../timeline/fitness-overview.md)和各阶段正文里。这边管的是判断依据——同一个动作该不该练、练到多少、什么时候必须停，以及吃、睡、情绪这几件不在训练里、却决定训练效果的事。

## 二、三个前提

**目标不是练出一个运动员，是让她一辈子愿意动。**
练到 18 岁拿了多少块牌，和 40 岁时还愿意每周动三次，是两件事。前者靠天赋和运气，后者靠的是她心里那本账——运动这件事，对她到底是好玩的、有成就感的，还是被逼的、总是挨批的。这本账的基本调子，多半在 12 岁之前就定下来了。

**她不是缩小版的成人。**
儿童的骨骼、肌腱、体温调节、注意力时长都和成人不一样，所以剂量、恢复时间、能承受的负荷都不能按成人打个折就用。一句话：**成人练的是能力，孩子练的是能力背后的身体。** 骨骼还在长的时候，把成绩放在第一位，是最容易出事的方向。

**任何一项运动都只是载体，能力才是能带走的。**
她今天学泰拳，明天可能换成篮球、攀岩、跑步，也可能什么都不练。换项目不会把前面几年的东西清零——只要那几年练的是**动作能力、身体基础和习惯**，而不是某一个项目的套路。这也是这份方案不肯把全部赌注押在泰拳上的原因。

## 三、和三处内容的边界

- **和[运动的整体安排](../../timeline/fitness-overview.md)及各阶段正文**：那一边按年龄给动作、剂量、周模板和检核表，是可以直接照着做的部分；这边给的是为什么这么做，以及什么时候不能这么做。两边互相引用，遇到具体动作怎么做，去计划那一边。
- **和[成长能力树](../index.md)**：运动在这棵树里挂两处——根那一层的身体基础，以及[干](../index.md#dry)那一层里的自我照料与生活自理。它不是独立的一条，是给这两个条目提供具体做法的。
- **和[个人成长里的徒手健身手册](../../../selfdevelop/health/sports/fitnessplan/index.md)**：那一份是成年人的力量训练处方，剂量、门槛、进阶标准都按成人身体写的。**两者不可互相照抄**——同样的动作，在儿童身上该练什么阶段、练几组，差别很大。

## 四、怎么读

这份内容按“判断依据”排列，不是按阅读顺序排列。建议这样用：

1. **第一次看**：只读[伤痛预防与恢复](injury-prevention.md)和[身体素质的五个成分](fitness-components.md)。前者告诉你什么时候必须停，后者告诉你六岁这个阶段真正该练的是什么。
2. **准备开始跟练时**：补[身体素养](physical-literacy.md)，你会明白为什么计划里塞了那么多看起来和泰拳无关的动作。
3. **日常维护**：读[体态与日常习惯](posture-and-habits.md)和[吃与睡](fuel-and-sleep.md)。这两篇不需要专门抽出时间，改的是生活里的默认动作。
4. **遇到具体的坎**：输比赛、想退队、和教练闹别扭，翻[心理与社交](mind-and-social.md)。

:::tip[一句话记住这套方法论]

先让她**会动**，再让她**敢动**，最后她才会**愿意动**。顺序错了，前两步做得再多也留不下来。

:::
