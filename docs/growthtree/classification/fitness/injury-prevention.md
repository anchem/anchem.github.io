# 伤痛预防与恢复

这一篇是整套方案里最不该跳过的部分。原因很直接：**运动方案写错了，最坏的后果不是没效果，是受伤。** 而青少年运动损伤里，绝大多数不是意外，是可以用规则避开的。

这一篇只给三样东西：怎么判断严重程度、什么事都不做也要停下来、以及怎么让它自己好起来。它不诊断，也不治病。判断拿不准的时候，答案永远是同一个——去看医生。

## 一、先装一把尺子：疼痛 0 到 10 分

让她自己说，不要替她判断。孩子说疼就是疼，这一点不用怀疑；不确定的只是疼到什么程度、疼在哪里。

六到八岁的孩子还说不准数字，不要逼她打分。这个年龄改看行为：她是不是不肯用那条腿走或跳、走路有没有变样、夜里有没有疼醒、别人一碰那个地方就躲。这些表现比她自己报的分数可靠。

| 分数 | 她自己会怎么说 | 怎么办 |
| --- | --- | --- |
| 0 分 | 不疼 | 照常练 |
| 1–3 分 | 有点感觉，但能正常做动作 | 照常练，练完留意第二天 |
| 4–5 分 | 做动作时明显感觉得到，动作开始变形 | 先对照红灯清单；没有红灯才降量：负荷减半或降一级台阶，观察两周 |
| 6–7 分 | 疼，做完之后还疼，第二天也疼 | 先对照红灯清单；没有红灯时停这一项，改做不疼的动作，一周不好转就看医生 |
| 8 分以上 | 疼得不敢用、走路都躲着它 | 停练，尽快就医 |

配套一条更实用的规则：**看她做完之后的样子。** 第二天能不能正常跑跳、走路有没有变样、晚上有没有疼醒——这三条的权重比她自己打的分更高。

## 二、绿灯、黄灯、红灯

三级之间不用凭感觉分。按**位置 → 趋势 → 时间**的顺序判断，就能消掉大部分模糊地带。

**先记住一条优先级：红灯压过另外两级。** 只要命中下面的红灯清单，不管疼几分、在什么位置、趋势往哪走，都按红灯处理。三步判断只在没有红灯信号时，用来分辨黄灯和绿灯。

**第一步看位置。**
- 在肌肉的肚子上、按得到具体一块，两边大致对称：偏绿灯。
- 在关节里、在骨头的某个点上、在一根筋的走行上：先对照下面的红灯清单，没有红灯才算黄灯。
- 位置说不清，只说“膝盖疼”“整条腿疼”：偏黄灯。

**第二步看趋势。**
- 一天比一天轻：绿灯。
- 一直那样、没有好转也没有变重：黄灯。
- 一天比一天重：直接按红灯处理。

**第三步看时间。**
- 练完二十四小时内消失：绿灯。
- 二十四到七十二小时还在，但没有加重：黄灯。
- 超过七十二小时还有，或者影响睡觉：红灯。

### 绿灯：可以继续练

- 练完之后一两天出现的酸痛，位置在肌肉上，两边差不多，按下去有点酸胀，活动开之后会减轻。
- 处理办法：正常练，把量稍微降一点，多喝水多睡。不需要任何特殊处理。

### 黄灯：降量，先别停

任何一条命中就是黄灯：
- 疼痛到 4 分以上
- 同一处疼痛持续超过 48 小时没减轻
- 只在身体一侧出现
- 做某个特定动作才疼，其它动作没事
- 疼的位置在关节、骨头点或肌腱上

处理办法：**降一级台阶（或者负荷减半，取更保守的那个），量减半，观察两周。** 两周内好转就慢慢加回去；没好转或者变重，直接转红灯。

**降级的时候别只减主项。** 跟主项一起减的还有跳跃、冲刺、变向、投掷这些高冲击的部分；可以保留的是走路、单腿平衡、上肢的轻负荷动作和日常活动。这一点常被做错：主项停了，但每天还在追跑打闹，等于没降。

### 红灯：停练，去医院

以下任何一条，都要停下来，并且尽快去医院。不要先观察两周。

- 关节里疼，或者有关节卡住、打软、锁不住的感觉
- 局部骨头点上按压剧痛，或者夜里疼醒
- 受伤当时听到响声、或者立刻肿起来
- 完全不能负重、走不到四步
- 红肿发热，还伴着发烧
- 明显的变形，或者有开放伤口
- 胳膊或腿麻、无力，伴颈部不舒服
- **早上起来僵硬超过 30 分钟**——这一类不属于观察范围，建议尽早就医查清原因
- 头部被撞击后出现头痛、头晕、恶心、呕吐、反应变慢
- 运动中或运动后胸痛、心慌、眼前发黑、晕倒
- 突然的剧烈腹痛，或者下腹一侧的剧痛，尤其伴着呕吐或脸色发白
- 走路跛，同时喊髋部、大腿根部或膝盖疼。膝盖的疼有时源头在髋，这一条最容易漏
- 尿变成茶色或酱油色，同时肌肉酸痛无力。这可能是肌肉被大量破坏后的信号，别当成喝水少
- 高温下运动后出现高热、停止出汗、皮肤发烫发干、意识不清或说胡话
- 肢体越来越肿、发凉、发麻，疼得和受伤程度完全不成比例
- 关节红、肿、热、剧痛。发烧不是必须出现的条件，没有发烧同样要就医
- 运动中反复胸闷、喘息、咳嗽，或者别人跑完就缓过来了，她半天缓不过来

:::tip[孩子的骨折和成人不一样]

骨头还在长，靠近关节的地方有一层生长板。同样的摔倒，成人可能只是扭伤，孩子可能是生长板受伤，而生长板受伤会影响这条骨头以后长多长。所以**关节附近的外伤，即使看起来不重，也值得尽早做影像检查**，不要在家揉一揉、观察几天。

:::

:::danger[红灯要做的事只有两件]

一是停，二是去医院。**不要在红灯上做试验**：不用先休息两天看看情况，不用换个动作试试，不用等下一次复查。有些损伤的窗口期只有几天，过了的处理方式和结果完全不同。

:::

### 生长痛和损伤，怎么分开

这两种疼经常被混在一起，区分办法很稳定：

| 特征 | 生长痛 | 损伤 |
| --- | --- | --- |
| 出现时间 | 傍晚和夜里，白天没事 | 和活动相关，用的时候疼 |
| 位置 | 双侧、在小腿和大腿前侧、说不清具体一点 | 单侧、能指到一个点 |
| 按压 | 按着不疼 | 按到那个点会疼 |
| 肿胀 | 没有 | 可能有 |
| 走路 | 正常 | 可能跛 |
| 运动 | 不影响 | 影响，或者做完之后更疼 |

生长痛不需要治疗，也不需要停运动。但它有几条底线：**多在双侧、位置在小腿或大腿前侧或膝后、夜里出现、按不到一个具体的痛点，而且白天走路和运动都正常**。偏离了这几条中的任何一条，就按损伤处理。

还有一句更要紧的：**生长痛是排除出来的诊断，不是一眼看出来的。** 孩子喊腿疼又伴着走路跛，或者疼在髋部和大腿根部，先不要往生长痛上想。那有可能是髋关节的问题，而髋的问题常常只表现为膝盖疼。这种情况直接就医，别在家观察。

## 三、几乎所有慢性损伤的原因都是同一件事：加得太快

青少年运动损伤里，慢性的一类（肌腱、骨突、应力性骨折）绝大多数是负荷增加速度和身体适应速度不匹配造成的。说人话就是：**练的量涨得比身体变强快。**

运动队里有个常用工具，叫急性慢性负荷比，通俗说就是**拿本周的量去比最近四周的平均量**。它来自成人运动员的研究，用在孩子身上只能当粗线条的提醒，别当成精确仪表盘。真正好用的还是下面两条。具体做法：

- **每周加量不超过一成。** 这一条覆盖跑量、跳跃次数、训练时长，还有泰拳课的回合数。
- **一次只改一个变量。** 这周加时长，就不加强度；这周换新动作，就不加量。
- **这几个时点是高风险**，要主动减量：长假之后回训、换新项目、换新教练、刚换了新鞋、刚长高了一截、生病刚好。

## 四、热身和放松

### 热身：八到十二分钟，必须是动态的

- **升温**（2–3 分钟）：慢跑、跳绳、原地小步跑，让身体热起来。
- **活动关节**（3–4 分钟）：踝、膝、髋、肩、腕、颈，画圈、摆动，幅度从小到大。
- **逐步加快**（2–3 分钟）：小步跑、高抬腿、侧滑步、后退跑。
- **项目动作**（2–3 分钟）：把今天要练的动作做一遍低强度的版本。

**练前不做长时间静态拉伸。** 练前拉伸会把肌肉暂时拉得“松”，接下来十几分钟内的力量和爆发力会下降，受伤风险反而升高。静态拉伸放到练后。

泰拳课前要特别把髋、肩、踝、腕热开——这几个关节在踢、肘、箍颈和出拳里承担的压力最大。

### 放松：五分钟就够

练完先做五分钟慢下来的活动（走路、慢骑），让心率降下来，再做几分钟拉伸。拉伸每个部位二十到三十秒，感受是紧但舒服，不是疼。

## 五、女孩最该认真练的两个动作：落地和变向

这一条单独拎出来讲，因为它值得。

女孩在青春期前后，**膝关节前交叉韧带（ACL）的非接触性损伤风险明显高于同龄男孩**——不同研究给出的倍数从两倍到八倍不等，口径不一致，但方向是确定的。而且这类损伤的后果很重：往往需要手术，恢复期以月计，还有相当比例的人会影响以后的运动。

好消息是这类损伤在很大程度上是可以预防的。经过专门设计的神经肌肉训练（把平衡、落地、变向、核心控制编进热身里），能把它降低一半左右。不需要器械，也不需要额外课时，编进热身就行。

三个要点，让她记住三句话：

1. **屈髋屈膝落地。** 落地时臀部往后坐、膝盖弯，用大腿和臀部吸收冲击，不要直着腿砸下来。
2. **膝盖不往内扣。** 膝盖要对准第二个脚趾的方向，不要往里塌。
3. **落地要轻。** 家里练的时候，让她听自己落地的声音——越轻越好。这一条比任何测量都直观。

具体动作在[9 到 12 岁](../../timeline/phase3/fitness-9-12.md)那一段里。

## 六、生长突增期：最需要主动减量的那两年

女孩的生长突增通常发生在十到十二岁之间，初潮一般在突增之后一年多出现。这两年身体里有一件不好办的事：**骨头长得比肌肉和肌腱快。**

结果是：
- **协调性会暂时下降。** 手脚好像突然不听使唤，动作变笨，这不是她不努力。
- **柔韧性会下降。** 肌肉被拉长，会觉得紧。
- **骨突位置的伤会变多。** 膝盖下方疼、脚跟疼，多数与这个阶段有关。
- **关节承受的相对负荷变大。** 身高体重涨得快，同样的动作对关节的冲击更大。

对策不是停练，是**调整结构**：把跳跃和冲刺的总量降下来，保住技术训练和基础力量训练。这段时间练力量的人，突增期反而更稳。同时每三到六个月量一次身高，变化快的时候主动减量。

## 七、恢复：真正管用的只有几样

恢复手段里，能改变结果的很少，不能改变的很多。按重要性排：

| 手段 | 实际作用 | 怎么用 |
| --- | --- | --- |
| 睡眠 | 最大、也最被低估的一项 | 见[吃与睡](fuel-and-sleep.md)。睡不够的孩子受伤率更高 |
| 吃够 | 能量长期不够是伤病的第一推手 | 尤其青春期，别节食 |
| 主动恢复 | 走路、轻骑车这类低强度活动，比完全躺着好 | 大强度训练后的第二天安排 |
| 低强度活动与拉伸 | 帮主观感觉变好，让人舒服 | 可以，但别指望它加速修复 |
| 冰敷 | 急性期止痛可以，常规使用证据不足 | 只在急性外伤的头一两天用，每次不超过 15 分钟 |
| 抗炎药 | 对修复过程有没有影响，目前研究结论还不一致 | 不常规吃，有医嘱除外 |
| 按摩枪、按摩 | 改善主观感受，不改变恢复速度 | 不用于骨头点、红肿处和急性损伤 |
| 各种补剂 | 对健康青少年基本无必要 | 除医生诊断缺乏的情况外，不吃 |

还有一条容易被忽略的：**受伤了不要长期完全不动。** 现代的处理思路是尽早、安全地开始活动——只要不加重那个部位，其它地方照练，受伤部位的关节在无痛范围里尽早活动。长期躺着不动，反而是让它更难好。

## 八、撞到头之后

头部撞击要单独讲。它和扭伤拉伤不一样：症状可能过几个小时才出现，而且判错一次后果很重。练泰拳可能碰到，骑车摔倒、体育课上磕到也一样。

- **当天不继续练，不回场上。** 哪怕她自己说没事、哪怕当时神志清楚。这一条没有例外。
- **接下来一两天留意症状**：头痛、头晕、恶心或呕吐、看东西模糊、怕光怕吵、反应变慢、记不住事、情绪反常、特别想睡或睡不着。出现任何一条，去医院。
- **恢复要分步走，不是不疼了就上。** 顺序是先安静休息一两天，再做轻活动（走路），然后做不碰撞的训练，然后做有碰撞但不涉及头部的训练，最后才回到对抗。每一步至少隔一天，而且每一步都要在没有症状的前提下才能往下走。
- **回到对抗之前，要让医生看过。** 练泰拳这类有头部接触的项目，回场不能由家里或道馆自己决定。
- **还没恢复时又撞一次，是最危险的情况。** 宁可多等几天，不要赶。

## 九、万一受伤了，恢复期的三个阶段

**第一阶段：保护。** 头几天减少让伤处疼的动作，可以适当抬高、加压。这几天要做的是别让它更坏，不是练它。

**第二阶段：恢复活动。** 疼一减轻就开始逐步加负荷。判断标准是“做这个动作不加重”，而不是“完全不疼”。这个阶段最容易被做错的地方是**停得太久**——很多孩子一受伤就完全不练，两个月后发现力量和体能的损失比伤本身还麻烦。

**第三阶段：回到运动。** 回场有标准，不是不疼了就能上：

- 能完成项目里所有需要的基本动作，做的时候动作没有变形
- 受伤侧和健康侧的力量差距在可接受范围内（这个由康复师判断）
- 能全速跑、能跳、能变向，做完了第二天不疼不肿
- **最重要的一条：她自己敢做。** 如果她到场上还是怕那个动作，说明还没好，回去继续练

## 十、这一篇只想让你记住一句

**疼不是必须忍过去的关卡，它是身体在汇报情况。** 学会听懂它、按时给医生，比学会忍它重要得多。
