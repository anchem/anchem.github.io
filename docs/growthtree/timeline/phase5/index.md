# 第五阶段：从15岁到18岁

养育重心：把方向盘交出去，同时保证副驾驶的位置一直有人。

这一段整体要面对的功课——价值观开始成形、决策的重量真实起来、亲密关系进入真实世界、一边准备离开一边害怕离开——写在[成长时间轴](../index.md)的第五阶段那一节。

这个目录放的是这一段单独展开的规划：

- [15 到 18 岁运动安排](fitness-15-18.md)：把运动交到她手里，月经周期与训练怎么配合、竞技与减重的底线、为离巢做准备。
