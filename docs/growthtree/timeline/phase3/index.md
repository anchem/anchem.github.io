# 第三阶段：从6岁到12岁

养育重心：前半段让她觉得“我能学会”，这比“我比别人强”重要；后半段把判断力还给她，同时让她知道我们一直在。

这一段整体要面对的功课——执行功能、读写与数感在这六年成型、同伴关系开始有结构、女孩的青春期比男孩早一到两年——写在[成长时间轴](../index.md)的第三阶段那一节。这一段跨六年，前后变化不小，时间轴里也是按 6–9 岁与 9–12 岁两半写的。

运动安排用的是同一刀：6–9 岁把动作练宽，9–12 岁学技术、开始练力量，为生长突增做准备。为什么这样切、每一段练什么，见[运动与体能](../../classification/fitness/index.md)。

这个目录放的是这一段单独展开的规划：

- [布加勒斯特外派规划](study-and-live-abroad-planning.md)：2027–2030 的海外三年与回国衔接，含英语小学就学方案与家庭财务统筹。
- [6 到 9 岁运动安排](fitness-6-9.md)：动作窗口期练什么、在家和学校怎么落地、一周怎么排。
- [9 到 12 岁运动安排](fitness-9-12.md)：技术窗口与力量入门、为生长突增做准备、检核什么。
