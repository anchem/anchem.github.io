# 9 到 12 岁：学技术，开始练力量

## 一、她在长什么

这三年是很多能力的最后一个容易窗口。

- **学技术的效率在这一段最高。** 一个动作需要的重复次数明显少于以后，学复杂技术的时期就是现在。
- **力量开始有反应了。** 这一段练力量，长的主要是协调和神经控制，而不是肌肉体积——所以不会变壮，但会变强。
- **末尾开始出现生长突增。** 女孩通常在十到十二岁之间开始长个，有些孩子在这个阶段的尾巴上已经悄悄发育。身体的变化会比心理的准备先来。
- **学业自我概念开始定型。** 她对自己的定位（我擅长什么、我不擅长什么）在这一段稳定下来，之后不容易改。运动场上的定位也一样——如果她在这几年认定自己是“体育不行的人”，这个标签会跟很久。
- **友谊变深，也变得排他。** 小圈子、冷落、排挤在这一段最集中。

## 二、这阶段的运动重心：技术 + 力量

两件事并重，这是和前一段最大的区别。

**技术**：可以正式学一到两个项目的技术了。泰拳的组合动作、球类的运球投篮、游泳的泳姿，都是这一段学最省力。学技术的时机比什么都重要。

**力量**：从现在开始，力量训练要变成固定的、每周都做的事。理由不是“早点练早出成绩”，是**为即将到来的生长突增做准备**。生长突增期骨头长得比肌肉快，那两年身体会变得笨拙、关节负荷变大。提前把力量练起来的孩子，在那两年反而更稳。

剂量见[身体素质的五个成分](../../classification/fitness/fitness-components.md)：每周两次，每次二十到三十分钟，每组八到十五次，结束时留两到三次余力。

## 三、练什么、为什么是它

| 练什么 | 为什么是它 | 频次与剂量 |
| --- | --- | --- |
| 落地与变向 | 这是女孩最该认真练的一项。膝前交叉韧带的非接触性损伤风险在这几年开始升高，而专门训练能把它降低一半左右 | 每次训练前都做，每次五到八分钟 |
| 自重力量 | 引体、俯卧撑、深蹲、单腿蹲、平板，把基础动作做扎实 | 每周两次，每个动作二到三组 |
| 轻器械力量 | 弹力带、小哑铃、壶铃，开始有外部负荷 | 每周两次，与自重交替 |
| 项目技术 | 学效率最高的时期，别浪费 | 按项目课安排 |
| 短距离冲刺 | 神经系统的可塑性还在，反应和频率能练 | 每周一到两次，每次跑几组二十米，组间充分休息 |
| 跳绳与体操类 | 协调、节奏、上肢拉一次练到 | 每周三次，每次几分钟 |
| 持续有氧 | 有氧基础在这一段开始积累 | 每周一次，骑车、游泳、慢跑二十到三十分钟 |
| 柔韧与活动度 | 现在还不紧张，但习惯要建立 | 练后拉伸，每周两三次 |

## 四、需要在这几年提前做的两件事

这两件事都属于“等发生了再讲就晚了”。

**一、把落地和变向练成习惯。**
不是专门开一节课，而是编进每次训练的热身里。三个要点让她记牢：屈髋屈膝落地、膝盖不往内扣、落地声音要轻。具体动作：从矮台上跳下停稳、单脚落地保持三秒、侧向跳十次不晃、落地后立刻接一个小跳。这几年坚持做，是在给青春期最高风险的那几年上保险。

**二、提前讲月经和身体变化。**
初潮一般在生长突增之后一年多出现，也就是说，四年级前后就该开始铺垫了。用平常的语气讲，别搞成郑重其事的谈话——先讲身体会怎么变，再讲月经是什么、怎么处理，最后讲这期间运动照常做。

还要顺带讲一件事：**吃够不是“注意体重”。** 青春期的女孩很容易被“少吃一点”的念头找上，而运动量大的女孩一旦能量长期不够，最先出问题的就是月经和骨密度。家里在这件事上的口径要提前统一：不称重、不算热量、不说减肥，只看有没有力气、有没有精神。见[吃与睡](../../classification/fitness/fuel-and-sleep.md)。

## 五、在家怎么练：两次，各二十分钟

| 次数 | 内容 | 说明 |
| --- | --- | --- |
| 每周第一次 | 上肢拉 + 推：悬垂或引体、俯卧撑、划船（弹力带）；核心：平板，或死虫（躺平、四肢抬起，对侧手脚交替伸直再收回） | 每组八到十五次，做二到三组，留余力 |
| 每周第二次 | 下肢：深蹲或单腿蹲、髋铰链动作（臀桥、单腿硬拉姿势）、提踵；落地与平衡 | 同样二到三组，做的时候看动作形状 |
| 每次都做 | 热身里的落地与变向五到八分钟 | 这项不能省 |

加上每周两到三次的项目课和每天户外，这一阶段的运动量就成立了。

## 六、在学校怎么用

- **体育课要认真上。** 这一段的体育课开始有球类和器械项目，是学技术的好机会，比在家自己摸索效率高。
- **校队或社团可以正式参加了。** 有规律训练和比赛的那种。她会第一次遇到“为集体出力”和“为输赢难过”这些事，都是好东西。
- **体测依然不用专门加练。** 但如果某一项长期明显偏低（比如柔韧或耐力），说明对应的成分被忽略了，要去补那一项，而不是补那一个测试动作。
- **课间动一动、上下学走一段，仍然照做。** 这些是每天的基础量。

## 七、一周怎么排

| 星期 | 内容 |
| --- | --- |
| 一 | 力量二十分钟（上肢拉与推）＋ 落地变向热身 |
| 二 | 项目课 |
| 三 | 户外有氧三十到四十分钟 |
| 四 | 力量二十分钟（下肢与核心）＋ 落地变向热身 |
| 五 | 项目课 |
| 六 | 长时间户外：跑、爬、球类。不排项目课 |
| 日 | 休息或轻松活动 |

落地与变向的热身，在每次训练前都做，包括项目课之前。

跨阶段共用的四条排课规则和特殊情况处理，写在[运动的整体安排](../fitness-overview.md)里。

## 八、父母要配合什么

- **把力量训练正式排进日程。** 这一阶段最容易发生的事是：项目课排得满满的，力量训练因为“没时间”被挤掉。结果是青春期一到，身体变得笨拙，项目进步也卡住。每周两次、每次二十分钟，是必须留的。
- **学会看动作，而不是看重量。** 这一阶段她不需要加重，需要把动作做对。我们自己不懂的时候，宁可问她教练。
- **给她一个自己的领域。** 她在这一段开始需要“有一件事是我说了算的”。让她自己选项目、自己定小目标、自己记录。
- **别把成绩单的焦虑搬到运动上。** 学业成绩已经够有压力了，运动场不该是第二个考场。
- **留意她在队里的处境。** 小圈子和冷落在这一段集中出现。她被排在外面的时候，先听她说，别第一时间冲去找教练。
- **家里保持一条约定**：遇到不舒服的事先说，我们保证不先骂你。运动里的不舒服（被教练羞辱、被队友欺负、身体被碰得不舒服）也算。

## 九、这阶段的检核点

每半年过一遍，一次二十分钟，找她状态好的一天做。这份表是体检表，不是门槛——没碰到的项，意思是“还没接触过”，不是“不达标”。怎么用、多久进下一阶段，见[运动的整体安排](../fitness-overview.md)。

| 检核项 | 有没有 |
| --- | --- |
| 俯卧撑、深蹲、单腿蹲动作规范 | |
| 悬垂累计能吊三十秒以上 | |
| 落地与变向受过专门训练，不是自然形成的样子 | |
| 每周有固定的力量训练，没断过 | |
| 能连续跑二十分钟不停 | |
| 会至少一项需要技巧的运动 | |
| 能说出自己身体正在发生的变化，也说得清月经是什么 | |
| 有一项她自己选的运动，并且喜欢 | |
| 能在不舒服或疼痛时主动说出来 | |

这一阶段要单独盯的只有一项：**力量训练有没有真的排进每周的日程。** 它最容易被项目课挤掉，而它恰好是下一阶段最需要的东西。

## 十、红线与停下

- **生长突增的部分信号要早认。** 膝盖下方疼、脚跟疼，尤其是跑跳之后加重，属于这个年龄段的常见信号，别硬练，按[伤痛预防与恢复](../../classification/fitness/injury-prevention.md)的黄灯降量并观察。
- **单侧、固定点、夜间痛**，直接按红灯处理。
- **月经的事不回避。** 周期非常乱、或者迟迟不来超过十五岁，去看医生，先考虑能量和营养的问题。
- **别让专项课的次数无限上涨。** 每周专项训练时长（小时）不宜超过年龄这个数量级。

[12 到 15 岁](../phase4/fitness-12-15.md)那一段变化最大，建议提前半年先读一遍。
