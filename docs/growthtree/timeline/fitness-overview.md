# 运动的整体安排

这一篇是运动这条线上跨阶段的部分：四个阶段各自的重心、一周怎么排、特殊情况怎么处理、怎么检核。

具体练什么、在家和学校怎么落地，写在对应的阶段目录里——[6–9 岁](phase3/fitness-6-9.md)、[9–12 岁](phase3/fitness-9-12.md)、[12–15 岁](phase4/fitness-12-15.md)、[15–18 岁](phase5/fitness-15-18.md)。各阶段那几篇是可以直接照着做的部分，这一篇出跨阶段共用的规则，为什么这么练则在[运动与体能](../classification/fitness/index.md)那一边。

## 一、四个阶段一页速览

| 阶段 | 她正在长什么 | 运动重心 | 一周大致怎么排 |
| --- | --- | --- | --- |
| [6–9 岁](phase3/fitness-6-9.md) | 动作协调快速进步，开始有正式的评价体系 | 把动作练宽，不追项目深度 | 项目课 2 次 + 家练 2 次 + 每天户外 |
| [9–12 岁](phase3/fitness-9-12.md) | 学技术的效率最高，末尾开始出现生长突增 | 学技术 + 开始系统练力量 | 项目课 2–3 次 + 力量 2 次 + 每天户外 |
| [12–15 岁](phase4/fitness-12-15.md) | 身体先一步长大，协调暂时变差，月经开始 | 安全地练力量，降低冲击总量 | 项目课 3 次 + 力量 2–3 次 + 有氧 1 次 |
| [15–18 岁](phase5/fitness-15-18.md) | 力量与耐力接近成人，开始独立决策 | 练成可以自己维持的习惯 | 按她自己的安排，父母退后 |

## 二、这四段和成长时间轴的五个阶段怎么对应

运动能力的发育窗口和心理社会分期本来就不完全重合，所以这里切四段，和[成长时间轴](index.md)的五个阶段不是一一对应：

| 本计划的分段 | 对应的成长阶段 | 为什么这么切 |
| --- | --- | --- |
| 6–9 岁 | 第三阶段前半（6–9 岁） | 动作学习的最优窗口，且还没有发育带来的身体剧变 |
| 9–12 岁 | 第三阶段后半（9–12 岁） | 技术学习的最优窗口，同时是生长突增的前夜 |
| 12–15 岁 | 第四阶段（12–15 岁） | 生长突增、月经、损伤风险最高的三年，运动安排要整体改结构 |
| 15–18 岁 | 第五阶段（15–18 岁） | 身体接近成人，运动从“被安排”切换到“自己安排” |

## 三、四个阶段共用的一条主线

不管哪一段，这四件事都在做，只是做法随年龄变：

- **动作要宽。** 从六岁到十五岁，始终要保留跑、跳、爬、投、接、变向这些基础动作的练习。项目可以换，动作不能丢。理由见[身体素养](../classification/fitness/physical-literacy.md)。
- **力量始终要练。** 区别只在形式和剂量：六岁用爬和攀，九岁用自重和轻器械，十二岁以后加负荷。见[身体素质的五个成分](../classification/fitness/fitness-components.md)。
- **睡眠和吃永远优先。** 训练可以缺席一次，睡眠和饭不能。见[吃与睡](../classification/fitness/fuel-and-sleep.md)。
- **红灯永远停。** 不分年龄。见[伤痛预防与恢复](../classification/fitness/injury-prevention.md)。

## 四、怎么读这几篇

1. **先看她现在在哪一段**，把对应的那一篇读完。里面有这个阶段该练什么、为什么、怎么排。
2. **再看下面的一周怎么排**，把项目课、家练、户外、学校这几块拼成一个真实的周表，包括考试周、假期、天气不好的时候怎么调整。
3. **检核表每半年过一遍**，只是看哪些还没碰到，不打分也不排名。
4. 到了下一段的开头，**提前半年**读那一篇，做些准备——最典型的是 12 岁那一段，有些事必须在初潮之前就开始做。

:::tip[如果只能记住一句]

每个阶段都有一条**当期最值得投入**的动作类别。把它做够，比把每件事都做一点更值。

:::

## 五、一周怎么排

这一节把各阶段里散着的安排拼成一张能用的周表，也回答那些一定会遇到的问题：考试周怎么办、假期怎么办、生病刚好怎么回、天气不好怎么办。

### 先把四份时间预算摆在一起

她的每周运动时间来自四个地方，只盯其中任何一块都会失衡。

| 来源 | 一周大约有多少 | 谁安排 |
| --- | --- | --- |
| 学校体育与课间 | 体育课两到三节加每天课间，累计四到六小时 | 学校 |
| 每天户外 | 目标是每天约两小时，可以分段累计 | 家庭的环境与规则 |
| 项目课（如泰拳） | 两到三次，每次一到一小时 | 教练 |
| 在家短练 | 两到三次，每次十五到二十五分钟 | 我们和她一起 |

注意这里面的数字关系：**每天户外那两小时是最大的一块**，比任何一节课都大。它同时也是[体态与日常习惯](../classification/fitness/posture-and-habits.md)里说的视力投资。所以排不下的时候，先保它，别先砍它。

同时要说实话：每天两小时是个目标，不是考核。上下学走路、课间、放学后在小区里跑，这些都能算进去；实在凑不齐的日子，保住四十分钟以上也算达标。把它写成非做不可的硬指标，反而会让做不到的家庭干脆放弃整件事。

四个阶段各自的周模板（具体到星期几练什么），写在对应阶段目录的正文里。

### 四条排课规则

**一、睡眠优先，训练让路。**
训练安排和睡眠冲突时，砍训练。这一条在任何年龄都成立，在青春期尤其明显——那几年她本来就缺觉。

**二、高负荷之间留出四十八小时。**
同一种能力（尤其是下肢的跳跃、冲刺、大重量）不要连着两天练。如果一周里必须相邻两天都练，那把其中一天降成轻负荷。相邻两天同时练下肢与跳跃，是最容易踩的坑。

**三、高冲击的动作排在训练的前半段。**
跳跃、冲刺、变向这类动作要在人精神、肌肉还没累的时候做。放在训练末尾，动作质量掉下来，风险就上去了。

**四、一次只改一个变量。**
这周加时长，就不加强度；这周换了新动作，就不加量。同时改两个，出问题时不知道是哪个引起的。

## 六、特殊情况怎么办

**考试周**
砍掉家练和额外的项目课，保留两样：**每天户外四十分钟以上，和每次十分钟的轻活动**。原因是这两样恰好是考试最需要的——运动和睡眠对记忆与注意力的作用，在这一周里比任何补习都实在。

**假期**
假期是把短板补上的最好时机，用一半时间做三件事：游泳或骑车这类持续有氧、器械类的技术、以及平时排不进日程的长距离户外。另一半时间留给她自己安排，不要排满。

**生病刚好**
按症状退回去：只是轻微鼻塞，可以照常做轻活动；有发烧、乏力、咳嗽明显，就等到完全好再练。恢复的顺序是先轻活动，再技术，最后才是强度和量，每一步之间隔一天看反应。

**天太热**
夏天的高温时段不安排大强度户外。孩子的散热能力比成人弱，把活动挪到早上或傍晚，中间补水；出现头晕、恶心、停止出汗、走不动，立刻到阴凉处降温并停下来。具体信号见[伤痛预防与恢复](../classification/fitness/injury-prevention.md)的红灯清单。

**天气不好**
室内替代方案：跳绳、爬楼梯、靠墙静蹲、平板、走廊里的熊爬。这些能把一天的量补上大半。下雨不是不动的理由，只是换个地方。

波比跳看着方便，但它一次就包含下蹲、撑地、起跳和落地，对协调和冲击的要求都高。**十二岁之前不建议做**；真要用就先退阶，去掉跳的那一下，改成撑地后站起来。

**搬家、长途旅行、回老家**
如果这期间正好赶上外派，学校、场地、语言那几件事在[布加勒斯特外派规划](phase3/study-and-live-abroad-planning.md)里单独写过，这里只补运动这一块。
最低维持方案是三件：每天走路或户外活动、每周两次五分钟的徒手动作（深蹲、俯卧撑、平板、单脚站）、保证睡眠。这三件在任何地方都能做到，能保住大部分状态。

**她说今天不想练**
先分清是不想练，还是不舒服。前者可以顺她一次，但要约好下一次；后者直接按[伤痛预防与恢复](../classification/fitness/injury-prevention.md)的黄灯处理。如果“不想练”变成连续几周的常态，那要处理的不是训练，是原因。

## 七、排课容易做错的地方

### 最容易被牺牲的三块

按牺牲频率排，前三名是这三块，而它们偏偏是最不能砍的：

1. **每天户外。** 最先被作业挤掉，损失也最大。
2. **在家那两次短练。** 因为它不像课，没有固定时间和人等着，最容易消失。
3. **热身。** 赶时间的时候第一个被省，而它正是最不该省的那一项。

对付它们的办法不是意志力，是**固定到日程里**：户外排在写作业之前，家练贴在固定的两个晚上，热身写进课表跟着课一起走。

### 四个常见误区

**把周表排满。** 一张每天都有安排的周表，能坚持两个月就算久。留出空白的那一天，是让整张表能活下去的部分。

**用周末补平时的欠账。** 周一到周五不动，周六猛练三小时，是受伤的经典配方。运动量要摊匀，攒不了也补不回。

**跟着项目课走，忘了别的事。** 项目课加得越多，家练和户外越容易被挤掉，而后面这两块恰恰是项目课补不了的部分。

**计划一变就整张表作废。** 一周里被打乱两次是常态。真正有用的不是完美的周表，是“被打乱之后怎么接回来”——从下一次能练的时候接着排，不用补课。

## 八、检核点怎么用

分阶段的检核表写在各自阶段目录的正文里，每段一张，只列这一段的项目。

### 它不是什么

- **不是考试。** 不打分，不和同龄人比，也不和自己的过去比着用责备的口吻。
- **不是门槛。** 没做到的项，意思是“这项还没接触过”，不是“她不达标”。
- **不是进度条。** 每个孩子的时间表都不一样，早会晚会不会改变最终能不能做到。

它只用来看两件事：**哪些能力还没接触到，以及哪些能力最近退步了**。前者照着补，后者先想原因。

频率是每半年一次，一次二十分钟，找她状态好的一天做。

### 每个阶段都看的四项

这四项不分年龄，每次都看：

| 看什么 | 怎么看 | 什么算好 |
| --- | --- | --- |
| 睡眠 | 最近两周实际睡多久，和她自己的基线比 | 达到年龄建议范围，且起伏不大 |
| 吃 | 三餐有没有主食、蛋白、蔬菜，训练前后有没有补 | 不需要算，看有没有明显的缺口 |
| 红灯 | 有没有正在疼、有没有瞒着不说的痛 | 没有红灯，黄灯在处理中 |
| 乐趣 | 她还想不想去练 | 愿意去，偶尔偷懒但整体正向 |

第四项经常被漏掉，但它其实是这四项里最关键的。一个孩子如果身体指标都好、但每次去训练都像上刑，那这份计划在长期上是失败的。

### 做自测时的四条注意

如果要做一些能记下来的测试（比如看能跳多远、能吊多久），注意四条：

- **选状态好的日子。** 累了或者睡不好的日子测，数字没有意义，还会让她以为自己退步了。
- **同一时间段测。** 下午和早上差别很大，前后要一致。
- **先热身。** 任何测试前都做十分钟热身，否则数字既不准也不安全。
- **只和她自己比，且只和同类条件比。** 记录的意义是看她自己有没有进步，不是给别人看。

**不要做的一件事**：把测试成绩挂到墙上或者当成任务指标。一旦变成指标，她就会为了数字去练，而为了数字练是动作变形的第一条原因。

### 记录方式：一页纸就够

不需要软件，一张纸，按季度记四行：

| 记什么 | 举例 |
| --- | --- |
| 这半年她做到的新动作 | 能单脚蹲了、能连续跳五十下 |
| 身体出过的问题 | 几月膝盖疼了几天，怎么处理的 |
| 睡眠与运动的大致情况 | 平均每天睡几小时、每周动几次 |
| 她自己说过的话 | “今天教练夸我了”“我不想去” |

最后一行看起来最不像记录，其实最有用。几年之后回头翻，你会看到她的态度是怎么变的，而这比任何数字都有信息量。

### 什么时候可以进下一阶段

判断标准不是年龄到了，是这三条件基本成立：

1. **这一阶段的主要能力都接触过了。** 不要求做得多好，要求出现过。
2. **上一阶段没留下未处理的伤病。** 有伤在观察中就先处理完。
3. **她的态度是正向的。** 愿意去，偶尔抱怨但不抗拒。

三条都成立就可以往下读，不必等到生日。年龄只是参考，发育的节奏个体差异很大。后面两段开头写的那些注意事项（月经、生长突增、能量不足的信号）尤其要提前半年看。

### 什么情况下这份计划需要改

这份计划是为一个特定的孩子写的，也受她的身体条件和家庭条件限制。出现下面这些情况，就该调整，而不是硬按计划走：

- **她被诊断出某种疾病或旧伤**，需要按医嘱改训练内容
- **她明显不喜欢这项运动了**，而且不是一时情绪
- **家里的时间条件变了**（搬家、转学、我们工作变动）
- **她进入竞技方向**，需要专业教练做单独的周期安排
- **身高变化特别快**的那几个月，主动减量
- **她自己提出想换个项目**

:::tip[记住这三条]

这份计划里的所有数字都是参考，只有三条不是：**睡够、吃够、红灯停**。其余的都可以商量。

:::

## 九、和另外几处内容的边界

- **[各阶段正文](phase3/fitness-6-9.md)**：按年龄给动作、剂量、周模板和检核表，是可以直接照着做的部分。这边给的是跨阶段共用的规则。
- **[运动与体能](../classification/fitness/index.md)**：判断依据、伤痛红线、吃睡、心理。这边所有“为什么”都指向那里。
- **[成长时间轴](index.md)**：养育的整体安排。运动只是其中一块，和阅读、家务、睡眠、社交是并列的。
- **[个人成长里的徒手健身手册](../../selfdevelop/health/sports/fitnessplan/index.md)**：那是成年人的力量训练处方，剂量、门槛、进阶标准都按成人的身体写的。两边不可互相照抄——同一个动作放在孩子身上，该练什么阶段、练几组，差别很大。
