# 第四阶段：从12岁到15岁

养育重心：从“管理者”退到“安全基地”。她要的是一个随时可用的父母，不是一个随时在场的父母。

这一段整体要面对的功课——身体的变化几乎全部发生在这三年、睡眠相位后移、同伴的评价权重大过我们、开始问“我是谁”——写在[成长时间轴](../index.md)的第四阶段那一节。
