# 第二阶段：从3岁到6岁

养育重心：把“我来”让给她，同时把边界立清楚。

这一段整体要面对的功课——假装游戏是她这一阶段最重要的工作、情绪的词库在这一段搭起来、她开始意识到自己是女孩、同伴第一次比大人更重要——写在[成长时间轴](../index.md)的第二阶段那一节。

这一阶段的运动底色仍然是玩。每天两小时户外，跑跳攀爬之外可以引入一项需要协调的运动；跳绳这类动作做不好很正常，慢慢来就好。什么时候引入什么、动作怎么练宽，见[运动与体能](../../classification/fitness/index.md)。

这个目录放的是这一段单独展开的记录与规划：

- [升班规划](promotio-plan.md)：让她在混龄班再滋养一年的决定，以及这个决定背后的判断。
