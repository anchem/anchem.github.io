# 第一阶段：从出生到3岁

养育重心：让她确信，她的信号发出去一定有人接住。

这一段整体要面对的功课——依恋在这三年成型、大脑连接的生成速度是一生中最快的、大运动从躺到爬再到走、语言从单音走向短句——写在[成长时间轴](../index.md)的第一阶段那一节。

这一阶段的运动底色是自由的玩。爬、走、跑、攀爬、光脚踩草地，都在这个窗口里；不做器械化的训练，也不排课表。睡眠和户外是这一段最值得守住的两件事。

到了这一段的末尾，可以给出第一项需要协调的运动作为起点。动作发展分哪几类、窗口期怎么算、什么样的练法算过量，见[运动与体能](../../classification/fitness/index.md)。
