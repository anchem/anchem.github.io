# 时间与人生意义

起点是三句很朴素的直觉：时间只往一个方向走，走过去的就再也回不来；过去、现在、将来其实不在外面，只在心里，分别是回忆、注意和期望；时间像一把收束刀，把无数种可能一点点固定成改不了的过去，而这件事之所以悄无声息，是因为正是这种流动让生命得以存在。

这三句话里藏着五个可以被单独拿出来检验的命题。围绕它们，我沿着七条线索梳理了三千年里最有分量的时间观，立了六个坐标轴把各家摆到同一张桌子上，分出三处真分歧与五处假分歧，最后收束成五条结论并逐条划清边界；再把结论翻译成八套有验收标准的动作，配上一份按处境选路的方案。
