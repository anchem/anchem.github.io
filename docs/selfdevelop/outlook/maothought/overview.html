体系地图：一条主线与三个基本方面

先做一个实验。

把《毛泽东选集》里能直接当方法用的条目抄下来：《实践论》的两次飞跃、《矛盾论》的主要矛盾、《反对本本主义》的没有调查就没有发言权、《论持久战》的三阶段、《党委会的工作方法》的十二条、《目前形势和我们的任务》的十大军事原则……抄完会得到一张三十多条的清单。

这张清单看起来收获很大，实际上是没用的。因为它没有告诉你这些条目的先后关系：什么时候该先调查、什么时候该先定战略、什么时候该先统一内部认识。清单给你的是零件，干事需要的是装配顺序。

这一篇的任务就是画出那张装配图。

一、主线的名字叫“结合”​

先说清这一段为什么值得你花三分钟：接下来几十年，这套方法每一次被逼出来，形状都和你熟悉的那个场景一样——手上的时间、人手和钱，永远少于该做的事，而选错方向的代价由做决定的人自己承担。1927 年那次失败，本质是一次“照抄别人成功案例”的失败。这个错误你今天还在犯，只是规模小得多。

整套东西的起点是一个很具体的困境。

二十世纪二十年代末，中国革命照着别人的路子走，接连失败。照搬的结论是“先在城市里发动武装起义”，因为那是当时唯一成功的样本。可中国的产业工人只有几百万人，城市里敌人的力量最集中，照搬一次失败一次。

1927 年之后，从井冈山开始的实践给出了另一条路：把重心放到农村，建立根据地，用农民的土地要求动员人。这条路在当时被讥为“山沟里的马克思主义”。

后来的结论是：马克思主义要在中国用，必须和中国实际结合。 这句话听起来像一句口号，其实是一个很高的技术要求——它要求同时做三件事：

  1. 真的懂这套理论（不是背条目，是懂它的方法）；
  2. 真的懂自己的情况（不是印象，是调查得来的事实）；
  3. 有勇气在两者冲突时，以事实为准去修正理论的用法。

第三件最难。因为前两件只需要下功夫，第三件要承担“你是不是不懂理论”的指责。

这一条主线是整个体系的地基：所有具体方法，都是这条主线的不同侧面。凡是丢掉“结合”二字的用法，都会退化成它原本反对的东西——教条，或者经验主义。

二、三个基本方面：它们回答三个不同的问题​

1981 年的《关于建国以来党的若干历史问题的决议》把毛泽东思想的活的灵魂概括为三个基本方面：实事求是、群众路线、独立自主。

这三个词经常被并列着念，念久了就变成三个标签。它们其实是三个不同层面的问题，缺一个，另外两个都做不成。

基本方面回答的问题一旦缺了会怎样
实事求是我怎么知道事情到底是什么样判断建立在印象与愿望上，越努力偏得越远
群众路线这件事靠谁做、为谁做方案漂亮但没人执行，或者执行成另一件事
独立自主我以什么为立足点跟着别人的评价标准走，方向随外部风向摆动

实事求是是认识论。 “实事”是客观存在的一切事物，“是”是它们的内部联系即规律性，“求”是去研究。三个字拆开，正好是一次完整的认识过程：先承认有客观事实，再承认事实背后有规律，最后承认规律要靠自己去求。它的反面不是“不诚实”，而是“用想出来的东西代替查出来的东西”——这个毛病有个正式名称叫主观主义。

群众路线是主体论。 它包含两层：一切为了群众（目的是谁），一切依靠群众（力量在哪）。很多人只记得第一层，把它读成一句道德要求；真正有操作价值的是第二层——力量在别人身上，你一个人做不完的事，只能靠让别人愿意做。这一层的技术形态是“从群众中来，到群众中去”，后面单独一篇讲。

独立自主是立场论。 它说的是：判断的立足点必须是自己这边的实际条件与长期利益，而不是外部给的评价、承诺或模板。抗战初期关于“独立自主的山地游击战”的争论，争的不是战术细节，是在统一战线里还要不要保留自己的判断权。

三者是咬合的：

  • 没有实事求是，群众路线会变成迎合——你不知道群众真正要什么，只能猜，猜出来的往往是好听的。
  • 没有群众路线，实事求是会变成个人聪明——你查得再准，也只有你一个人在推。
  • 没有独立自主，前两个都会被外部标准劫持——调查的方向、团结的对象，都由别人替你定。

三、方法层：七个部件和它们的接口​

三个基本方面是原则层，落到操作还要有方法层。方法层里有七个部件，各自接着不同的口。

调查研究 接在“实事求是”下面，解决“事实从哪来”。它是整条链的入口，也是最容易被跳过的一步——因为跳过它不会有即时的痛感，代价在半年后才出现。

矛盾分析 接在调查研究之后，解决“事实里哪个最要紧”。调查给的是材料，材料本身不告诉你优先级。矛盾分析就是把材料变成排序的那道工序。

战略与战术 接在矛盾分析之后，解决“力气往哪压、压多久”。知道了主要矛盾，还要决定是速决还是持久、是全面铺开还是集中一点。

统一战线 接在战略之后，解决“和谁一起做、和谁保持距离”。任何需要多人协作的事，都会遇到“立场不完全一致但可以合作”的人，处理这类关系需要专门的分寸。

群众动员 接在战略之后，解决“怎么让人真的动起来”。它把方案变成别人的意愿，再把别人的反馈变成方案的修正。

实践与认识 接在动员之后，解决“做完了怎么知道自己对不对”。它是闭环的最后一环，也是唯一能把前面五环从“自说自话”里救出来的一环。

组织与自我要求 接在所有环节的下面，解决“这套程序靠什么持续运转”。反对自由主义、批评与自我批评、党委会的工作方法，都是给这台机器上润滑油和装刹车。

七个部件的关系不是并列的，是一条闭环加一个底座：

调查 → 矛盾 → 战略 → 分清敌友 → 动员 → 检验与修正 → 回到调查，底座是组织纪律与自我校正。

注意这条链和侧边栏的顺序一致：第三篇讲调查、第四篇矛盾、第五篇战略、第六篇动员、第七篇分清敌友、第八篇检验。读书的顺序就是这条链的顺序，唯一例外是《实践与认识》被放在第八篇——因为它的位置在闭环的末端，而它讲的东西（怎么检验、怎么修）用到时你手上已经有前六环的材料了。

四、形成脉络：为什么它的形状是这样的​

要理解一个体系，得看它被什么问题逼出来。

1925 年前后，第一道题是“跟谁站在一起”。《中国社会各阶级的分析》开篇那句“谁是我们的敌人？谁是我们的朋友？这个问题是革命的首要问题”，问的是力量从哪来。

1927 到 1934 年，第二道题是“路走不通时怎么找新路”。农村包围城市这条路的成型，不是先有理论再有实践，而是实践反复失败之后才被确认的。

1935 年遵义会议，第三道题是“内部判断出错时怎么纠正”。这次会议的意义在于确立了一种机制：军事与组织的判断由了解实际情况的人来做，并为此后在全党范围内总结历史经验留出了空间。

1937 年的《实践论》与《矛盾论》，是把前十年用血换来的经验上升为认识论与方法论——先有做法，后有成体系的解释，这个顺序很重要。

1941 到 1945 年的整风与七大，第四道题是“怎么让一整套方法被一个组织真正掌握”。整风针对的三样东西——主观主义、宗派主义、党八股——恰好是方法在传播中最容易变形的三种方式。

此后还有《党委会的工作方法》（1949）这类极其实用的东西，讲的是掌权之后怎么开会、怎么当班长、怎么做到“胸中有数”。

这里必须写清一件事。 1981 年的决议说，毛泽东思想是中国共产党集体智慧的结晶，并紧接着说，毛泽东同志的科学著作是它的集中概括。两个半句要连起来读：它是以毛泽东同志的科学著作为集中概括、凝聚全党集体智慧的立场、观点、方法。

这不是一句客气话，它决定了读法：书里的判断不是某个人凭空想出来的灵光，而是一个组织在长期试错中沉淀、并由主要创立者集中概括出来的立场与方法。所以读它的时候，要问的是“这套立场和方法为什么能反复产出正确判断”，而不是“这个人为什么这么聪明”。

后者是英雄史观；前者才是这套东西真正的价值所在。

五、失效边界​

第一，当零件库用。 把十条原则背下来，遇到问题挑一条套上去，是最常见的用法，也是最坏的用法。零件抽掉了接口就装不起来：集中优势兵力用在错误的主要矛盾上，只会让你更快地在错误方向上耗尽资源。

第二，把三个基本方面当口号。 念“实事求是”不需要成本，做到它需要承认自己之前的判断是错的。凡是把这三句话当结论而不是当工序的地方，它们都会退化成标语。

第三，把形成期的结论直接搬到今天。 1927 年的阶级结构、1940 年的敌我态势、1949 年的组织条件，今天都不在了。可以迁移的是判断的程序，不是判断的结论。每次迁移都要写出“哪些条件相同、哪些不同”。

第四，把体系读成完备。 这套东西本身是开放的。它处理的是“如何在约束条件下做对判断”，没有处理“如何在信息过载、注意力被系统性争夺的条件下做对判断”——那是今天的新条件，得自己补。

第五，只读方法层，不读底座。 七个部件里最不起眼的是“组织与自我要求”，最容易砍掉的也是它。但砍掉之后，前面几个部件都会退化成一次性灵感：没有纠错机制，调查会变成找证据支持既有结论，批评会变成互相攻击。

第六，把它读成价值中立的工具箱。 这是最隐蔽的一种失效。抽掉“为了谁”这一层，所有方法都能被反向使用：调查研究可以用来更精准地操纵，群众动员可以用来更高效地收割，集中兵力可以用来更狠地压榨。方法的正当性不来自它的效率，来自它指向谁。

六、这张图怎么用​

下次遇到一个复杂决定，按这张图自查一遍，五问：

  1. 我手上的事实是查来的，还是想出来的？
  2. 这些问题里，哪一个解决了其它几个会跟着松动？
  3. 我的力气是集中在一个点上，还是摊在五个点上？
  4. 需要谁一起做？他们为什么要做？我给的方案里有没有他们真正在意的东西？
  5. 我打算什么时候、用什么信号判断自己错了？

顺序上有个现实提醒：前三问答得出来就可以动手，不要把五问全通当成开工条件。 第四问和第五问在动手前常常只能靠行动才能得到答案，硬要等它们也会造成两种坏结果——拖延，或者走形式写两句假答案，然后整套自查失去可信度。

所以后两问允许写成待补项，并约定第一次补答的时间（比如一周后）。“不知道，我打算这样去知道”是一个合格答案。

答不出来也不必停工，缺哪一环就翻哪篇。
