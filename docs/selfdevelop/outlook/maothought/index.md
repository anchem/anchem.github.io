# 毛泽东思想：一套判断问题的顺序

年初定了三个目标，年底回头看，完成了一个半。复盘时写下的原因通常是“执行力不够”“时间没管好”“意志力不行”。

但如果把这一年的几个关键决定摊开看，问题多半不在执行：你选的那个目标，本来就不是今年最该解决的那一个；你把七成力气投在了看得见回报的小事上；你在三月就该改方向的时候，因为已经投入了两个月而选择继续；你判断“领导想要什么”用的依据，是去年的一次会议上的一句话，而不是这半年他真正在为难的事。

这四个错，都不是努力能补的。它们是判断的顺序错了。

**这类问题有一个共同的形状**：在信息不全、资源不够、时间有限、后果真实的情况下，怎么判断先做什么、不做什么、什么时候改主意、改到什么程度。

## 这套东西为什么值得认真读 {#why}

《毛泽东选集》四卷，大部分篇目写于极端不利的条件下：队伍小、装备差、信息慢、内部还有分歧。作者面对的问题，和今天一个项目经理、一个创业者、一个带孩子的家长面对的，在最抽象的层面是同一类——手上的资源远少于想做的事，而错的代价由自己承担。

所以这本书里最有价值的部分，不是结论，是**在约束条件下做判断的程序**。哪些结论今天还成立、哪些已经不成立，正是这套程序要处理的事。

不过这里必须立刻加一句限定，否则“程序”二字会滑向一个错误的读法。

**这套程序不是价值中立的。** 1981 年《关于建国以来党的若干历史问题的决议》的完整表述是：毛泽东思想是马克思列宁主义在中国的运用和发展，是被实践证明了的关于中国革命的正确的理论原则和经验总结，是中国共产党集体智慧的结晶；毛泽东同志的科学著作是它的集中概括。

只取“集体智慧的结晶”而丢掉“正确的理论原则和经验总结”“科学著作是集中概括”，会得到两个坏结果：一是把它变成一套任何主体都能拿来用的通用决策学，包括与人民利益无关的主体；二是把“集体智慧”读成匿名的组织算法，反而抹掉了决议肯定的主要创立者的作用。**它的主体是中国共产党和中国人民，指向是民族独立与人民解放。离开这个主体与指向，剩下的只是一般决策学。**

这一系列做三件事，按顺序：

1. **提炼**：把散落在各篇的方法整理成一套互相咬合的体系，而不是语录摘编。
2. **解剖**：用历史事件和当代现实事件各做一次深度剖析，说清这些方法在什么条件下成立、条件变了会怎样失效。
3. **转译**：给出普通人可执行的原则、方法与最佳实践，落到工作与生活的具体场景。

验收标准只有一条：**读完能拿走一套判断问题的顺序，而不是一堆形容词。**

## 主线：一句话 {#mainline}

整套方法可以压成一条链，五个环节，首尾相接：

**从事实出发 → 找出此刻的主要矛盾 → 把力气集中到一点 → 靠人做成 → 在行动中检验并修正，然后回到第一步。**

五个环节各自对应一组问题，也正是后面各篇的分工：

- **① 从事实出发**：你掌握的是一手事实，还是别人转述的印象？——[调查研究](./investigation.md)
- **② 找出主要矛盾**：一堆问题里，哪一个解决了其它几个会跟着松动？——[矛盾分析](./contradiction.md)
- **③ 集中到一点**：力气不够时，凭什么在一个点上做出压倒性？——[战略与战术](./strategy-and-tactics.md)
- **④ 靠人做成**：一个人做不完的事，怎么让别人愿意做、并且做得对？——[群众路线](./mass-line.md)与[分清敌友](./united-front.md)
- **⑤ 检验并修正**：怎么知道自己错了，错了以后改什么？——[实践与认识](./practice-and-cognition.md)
- **底座**：这套程序靠什么在自己身上持续运转？——[自我要求](./self-discipline.md)

第五环之所以放在最后，是因为它同时管两件事：一是第①环到第②环之间的加工（零散材料怎么变成判断，这是《实践论》讲的第一次飞跃），二是第④环之后的对账（做了之后怎么知道判断对不对，这是第二次飞跃）。**它不是一个可以跳过的收尾，它是让前四环不至于自欺的那道闸。**

一句话的主线之外还有一句提醒：**这五个环节不是流水线，是循环**。走到第五步不算完，要退回第一步重新看事实。谁把它当流水线走一遍就交差，通常会在第三步之后走偏。

## 边界声明 {#boundary}

三条，都写在前面。

**第一，研究对象的界定。** 本文研究的是作为科学体系的毛泽东思想。历史评价一律以 1945 年《关于若干历史问题的决议》与 1981 年《关于建国以来党的若干历史问题的决议》为准，**不另立与这两个决议相悖的评价**；对历史事件只作方法层面的分析，不作功过是非的新判断；对当代政策只引公开文件与官方数据，不作政策评价。

**第二，这不是党史读物，也不是政治评论。** 不写秘闻、不写内幕、不引用未经证实的回忆材料。

**第三，方法是有条件的。** 任何一条抽掉它成立的条件都会变成教条，而教条恰恰是这套思想最先反对的东西。所以每一篇都单独写一节失效边界——只讲有效等于骗人。

版本口径：引文只标篇名与写作年月，《毛泽东选集》依人民出版社 1991 年第 2 版四卷本；页码无法一手核实的一律不写。文中凡写作“原文”处，指该节前文已标明的篇目；跨篇转引会单独注明。

## 怎么读 {#howtoread}

先说清我怎么选材，以及砍掉了什么。

十篇里没有一篇讲军事战术细节，也没有一篇讲党史过程的完整叙事——这两样书里都有，但迁移不到日常。砍掉它们是因为一个判断：**读者能带走的是判断的顺序，不是历史的知识量。** 所以每篇只保留一条方法、一两个案例、一节失效边界。案例选得偏向“条件差、信息不全、还要在有限时间里做决定”这一类，因为它们和你手上的事最像；胜利本身不在选材标准里，这一点在[案例解剖室](./casebook.md)第六节有专门交代。

三条路线，按你手上有多少时间选。

**十五分钟**：读这一页 ＋ [落地总纲](./principles.md)的十四条原则。够你在下一个决定上用一次。

**一个下午**：再读[调查研究](./investigation.md)、[矛盾分析](./contradiction.md)、[战略与战术](./strategy-and-tactics.md)三篇。这三篇覆盖了绝大多数“判断失误”的成因。

**一个月**：按顺序通读十篇，每读完一篇，用当周一个真实决定做一次练习，把结论写下来。读到第八篇时回头看第六、七篇——那两篇讲的是人，做练习时最容易只剩自己的声音。

:::tip 一个不推荐的读法
从头到尾划重点、摘金句、存进笔记软件。这套方法的门槛不在记住，在于你愿不愿意在下次做决定之前，先去问三个具体的人，而不是先想出一个漂亮的说法。

还有一句：如果读完这套东西，你对自己更苛刻了，那是用法错了，不是学得不够。方法提高的是胜率，不是给你的品格打分。
:::
