# 矛盾分析：找那个决定全局的问题

手上同时压着五件事：季度目标差一截、组里两个人在闹矛盾、一个重要客户在犹豫、家里老人生病需要安排、自己想考的证还有两个月。

（如果你手上没有下属和客户，把前两件换成“一个拖了很久的跨部门请求”和“一个迟迟不回你消息的房东”——排序的难处是同一种。）

五件事都急，五件事都重要。你的做法是每天先处理最响的那件——谁催得急先做谁。一个月下来，五件事都推进了一点，没有一件解决。

这不是时间管理问题。时间管理的所有方法都默认“你已经知道该做哪件”，而你不知道。你缺的是排序的依据。

《矛盾论》给的就是这个依据。它写于 1937 年 8 月，是《实践论》的姊妹篇：一篇讲认识怎么形成，一篇讲事物为什么这样运动。

## 一、先承认一件事：矛盾是常态 {#universality}

《矛盾论》开篇就把对立统一法则定为唯物辩证法最根本的法则。这个提法听起来抽象，落到日常其实是一句大白话：**事物的内部本来就有互相拉扯的两面，正是这种拉扯推动它变化。**

这个判断有一个很实用的推论：**没有问题才是异常状态。**

一个团队没有冲突，通常不是因为它健康，是因为没人说真话；一个项目没有风险，通常不是因为它顺利，是因为风险还没被发现。把“有矛盾”当成故障来消除，会使你一直在压制症状，而不去处理产生症状的结构。

顺着这条往下，是矛盾的两种属性：

- **普遍性**：任何事物、任何阶段都有矛盾，没有例外。
- **特殊性**：每个事物的矛盾都有自己的质，不同质的矛盾，只有用不同质的方法才能解决。

特殊性这一条比普遍性更有用。它是“具体问题具体分析”的理论出处，也是照搬模板必然失败的根因——模板是从另一个质的矛盾里长出来的，用在你的矛盾上，最多治个表面。

## 二、两个不同的问法：主要矛盾，还是主要方面 {#principal}

这是《矛盾论》里最容易混的一对概念，混了就会用错。

**主要矛盾**问的是：在同时存在的多个矛盾里，哪一个的存在和发展规定或影响着其它矛盾的存在和发展。

**矛盾的主要方面**问的是：在同一个矛盾内部，对立的两面里，哪一面在当下起主导作用、决定这个事物的性质。

| | 主要矛盾 | 矛盾的主要方面 |
| --- | --- | --- |
| 比较的对象 | 多个矛盾之间 | 一个矛盾内部的两面 |
| 回答的问题 | 先动哪一个 | 这件事现在算是什么性质 |
| 例子 | 产品有留存低、成本高、团队散三个问题，其中留存低决定了另外两个能不能解决 | 留存低这个矛盾里，是“用户没需求”为主，还是“有需求但没被满足”为主 |
| 判断错了的后果 | 力气花在次要问题上，主要问题继续恶化 | 方案对症但不对因，反复治反复犯 |

用错这两个问法，会得到两种典型的失败。

**只找主要矛盾，不辨主要方面**：你知道要让用户留下来，于是加了一堆功能。但如果你没判断出这一矛盾的主要方面是“有需求没被满足”还是“根本没需求”，加功能只是在错误的方向上加码。

**只辨主要方面，不排主要矛盾**：你把留存低这件事研究得很透，但成本高已经让公司在三个月内断粮。研究得越透，越没机会用上。

正确的顺序是：**先横着排（多个矛盾里选一个），再竖着切（选中的那个矛盾里辨主次）。**

## 三、内因与外因：谁决定，谁只是条件 {#internal}

原文的判断很干脆：外因是变化的条件，内因是变化的根据，外因通过内因而起作用。后面跟的那个比喻更有名：适当的温度可以使鸡蛋变成小鸡，但温度不能使石头变成小鸡。

这条在日常里最有用，因为它直接处理“把什么都归到环境上”这个习惯。

公司不给资源、领导不懂业务、行业在下行——这些都是真的，也都是外因。但外因要通过内因起作用，意味着同样的环境里，不同的内因会得到不同的结果。**所以分析的第一步不是控诉环境，是找出自己这边那个“能被环境推动”的部分。**

但在往下走之前，先过一道闸门：**外因是否已经越界。** 涉及人身安全、健康、法律权利、基本生存中的任何一项，这个阶段的正确动作就是处理外因——求助、取证、就医、离开——内因分析暂缓。

说自己被环境卡住，不必然是推责。很多时候它是求助、设边界、找同伴的前置条件。**要先允许这层存在，才谈得上找“自己这边能动的那一格”。**

过了闸门之后还有一层技术性的好处：外因你改不了，内因你能改。把注意力放在内因上，不是道德要求，是效率选择。

但这里必须立刻补一句，否则这条会被用歪：**强调内因不等于否定外因的作用。** 《论持久战》里对国际形势的判断、抗战时期争取外援的努力，都是把外因当真实变量在处理。内因决定的是“变化的根据在你这边”，不是“你不需要帮助”。

一句话的判别法：**内因决定你能不能变，外因决定你变得快不快、代价大不大。** 把两者搞成二选一，两边都会失真。

## 四、矛盾会转化：所以排序要重做 {#transformation}

《矛盾论》里还有一条常被忽略的判断：矛盾的主要和非主要的方面互相转化着，事物的性质也就随着起变化。

这句话的意思是，**今天的主要矛盾，三个月后可能变成次要矛盾；今天的次要矛盾，可能在你解决主要矛盾的过程中升级成新的主要矛盾。**

举个身边的例子。一个家庭的主要矛盾是收入不够，于是两个人都在加班。收入上来之后，主要矛盾变成了“家里有没有人真的在管孩子”。

这里要先问的不是“谁该退”，而是“这件事此前是谁在默默兜着”。往往是某一个人的加班被悄悄减掉了，只是没人把它写进账本——而这一步通常不计入家庭账本，也就不会被当成代价。这个默认如果一直不被说出来，新矛盾会以“我付出这么多你还不满意”的形式爆开，而不是以“我们重新分工”的形式解决。

所以“找主要矛盾”不是一次性动作，是一个**定期重判**的动作。重判的触发条件应该是事件，不是日历：

- 你为解决主要矛盾投入的那件事，边际效果明显下降了；
- 出现了一个新的、会让其它问题一起恶化的因素；
- 原来那个主要矛盾的关键指标已经进入可接受区间。

三个条件出现任何一个，就把清单重排一遍。**不重排的代价是：你用一套已经过期的排序，高效地做错事。**

## 五、三步定位法 {#howto}

把上面的东西压成一个能在纸上做的动作，三步，一次二十分钟。

**第一步：把矛盾写成对立的两面，不写成待办事项。**

“要提升留存”是待办，不是矛盾。矛盾要写成“用户想少花时间，产品想多占时间”这种拉扯。写成拉扯的好处是：它自带张力，能推出解法；写成待办只会有无穷的加法。

**第二步：横着排，问“解决它之后，哪些问题会跟着松动”。**

对每个矛盾问一句：如果这个解决了，其它几个里哪几个会自动好转、哪几个仍然不动。会自动好转最多的那个，大概率是主要矛盾。这个问法比“哪个最重要”有效，因为“最重要”是主观判断，“会带动几个”是可数的。

**第三步：竖着切，问“这个矛盾现在算是什么性质”。**

在选中的矛盾里，判断哪一面在当下起主导作用。这一步的产出应该是一句“这件事现在的性质是 X，不是 Y”。比如“现在的性质是供给不足，不是需求不足”——有了这句话，方案就唯一了：加供给，不做促销。

三步做完，你会得到一句排序＋一句性质判断。**这两句话就是你这个阶段的工作说明书。** 后面所有的取舍，都拿它们当依据，而不是拿“谁催得急”当依据。

## 六、迁移：四个场景 {#transfer}

**职场优先级。** 五件事同时压来的时候，用第二步的问法：解决哪一件，会让另外两件变得不重要或者变简单。通常答案是那个“结构性的”问题——比如把需求评审流程定下来，而不是把五个需求都赶完。

**产品需求。** 一堆需求排队时，先辨主要方面：现在的性质是“用户不知道有这个功能”还是“知道了但不好用”。前者做增长，后者做体验。搞反了，两边都白做。

**家庭冲突。** 夫妻为一件小事吵得厉害，那件小事通常不是主要矛盾。它是主要矛盾的表现形式。主要矛盾更可能是“分工没有被明确约定，所以每次都要现场谈判”。谈那件小事谈不出结果，因为真正要谈的是规则。

**个人成长。** “什么都想学”的困境，本质是没排主要矛盾。判断标准还是那个问法：学会哪一项，会让其它几项的学习成本下降。答案往往是某一项底层能力（表达、逻辑、英语），而不是某一门热门技能。

## 七、失效边界 {#limits}

**第一，把主要矛盾当成唯一矛盾。** 主要矛盾是“规定和影响其它矛盾”的那一个，不是“唯一需要处理的”那一个。其余矛盾可以暂时不管，但不能不知道它们在哪——因为它们随时可能转化。只盯一个、其余全盲，是这句方法最常见的误用。

**第二，解决完不放手。** 主要矛盾转化了，人还按旧的排。这种失误在顺境里最常发生：正因为上一个判断成功了，才更不愿意承认它过期了。

**第三，把自己不喜欢的事判成次要。** 判断“哪个是主要矛盾”需要一个外部校验：把你排出来的顺序讲给一个会反对你的人听，看他能不能指出你在维护什么。自己一个人排，几乎必然会把自己擅长且喜欢的那件事排到前面。

**第四，用“内因决定”否定求助。** 前面说过，这是对原文的窄化。更坏的用法是拿它劝别人：“问题都在你自己。”这句话在安慰场景里几乎总是错的，它把一个需要外部条件的问题，变成了一个人的道德缺陷。

**第五，把矛盾分析用在人身上，把对方变成“敌我”。** 这是最需要警惕的一条。

矛盾分析处理的是**事**的内部张力。一旦套到**人**身上，很容易滑成一句话：他是矛盾的主要方面，所以他是问题。

这时候你做的不是分析结构，是找责任人。用在夫妻、亲子、同事身上，这种滑法会造成真实伤害。

它最常出现的样子，是你在心里说：我这是在理性分析。

判别法很简单：**分析完，你的方案里有没有对方能接受的一步？** 没有，说明你分析的不是矛盾，是敌意。

## 八、留下的三样东西：三步定位法、两句产出、重判条件 {#takeaway}

一句话：**先横着排，再竖着切，排完还要定期重排。**

三步定位法留在手上：把矛盾写成对立的两面 → 问“解决它之后哪几个会松动”→ 问“它现在的性质是什么”。三步的产出是两句可执行的话，不是一堆分析。

排序有了，下一步是决定怎么打：力气往哪儿压、压多久、什么时候该换打法。
