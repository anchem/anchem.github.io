# 知识管理

知识管理解决的问题是：**让学过的东西在需要的时候找得到、调得出、用得上**。它管的是知识的存放、连接与提取，不管“要不要学”——那是学习本身的事。

## 概念

### 动机

- 信息从来不缺，缺的是提取。收藏了几百篇，需要的时候一篇都想不起来，等于没收藏。
- 没有体系的知识不成其为知识，只是一堆互不连接的碎片。
- 知识的价值不在拥有，在调用。判断一份知识管理做得好不好，看的是“需要它的时候，多久能找到并敢用”。

### 范围

- 知识管理解决的问题是：**知识怎么存、怎么连、怎么提**。
- 知识管理不解决的问题有两类：一是“要到哪里去”，那是[目标管理](./targetmanagement.md)的范围；二是“这件事怎么交付”，那是[项目管理](./projectmanagement.md)的范围。三者常被混着谈，混着谈就一定做不好。

### 四个环节

```txt
收集 -> 加工 -> 连接 -> 输出
  ^                      |
  |_____ 回顾（把输出的反馈变成下一次收集的筛选条件）_____|
```

- **收集**：把外部信息变成自己的素材，关键动作是**判断值不值得收**。
- **加工**：把素材变成能说清的一段话，关键动作是**用自己的话重写**。
- **连接**：把新知识挂到已有的结构上，关键动作是**找到它的邻居**。
- **输出**：把它交给一个真实的人或一件真实的事，关键动作是**接受检验**。
- **回顾**：回头看哪一条真的用上了，据此收紧下一次的收集门槛。

## 原则

### 原则一：编码方式决定提取速度

存的时候按什么维度组织，取的时候就只能按什么维度找。按来源归档，就只能按来源找到它；按问题归档，才可能在做这件事的时候碰到它。**分类的标准应当是“我什么时候会需要它”，而不是“它从哪儿来”。**

### 原则二：连接比收集重要

知识的力量来自相互连接，不来自单条的数量。同一个概念被你从三个不同场景里遇见过、并且互相链起来，它才真正属于你。

### 原则三：只有写下来的才是你的

读过、划过线、点头同意过的，都不算。能用自己的话讲一遍、并且能举出一个反例的，才算。判断标准很朴素：**你能不能不看原文，把它讲给一个外行听懂。**

### 原则四：面向复用，而非面向收藏

每收一条，多问一句：“我打算在什么时候用它？”答不上来的，就别收。收藏这个动作本身会给大脑一个虚假的完成感，这是知识管理里最贵的错觉。

## 方法

### 第一步：定义你的问题域

先写下你长期关心的三到五个问题，它们是筛选器。没有问题域的人，收什么都是随机的。

### 第二步：建立最小的存储结构

不要一上来就搭一个复杂的体系。一个够用的结构，通常长这样：

| 层 | 装什么 | 判断标准 |
| --- | --- | --- |
| 收件箱 | 一切还没处理过的素材 | 只进不出的是垃圾场，要定期清空 |
| 主题笔记 | 按问题域聚起来的成篇内容 | 每篇有一个明确的问题 |
| 索引页 | 只放链接与一句话摘要 | 是入口，不是仓库 |
| 产出 | 文章、方案、课程、代码 | 唯一能证明体系活着的部分 |

### 第三步：加工成能复述的一段话

每条笔记落到“三句话”：它说了什么、怎么证明的、我准备怎么用。三句写不出来，说明还没读懂，回到原文。

### 第四步：主动制造连接

每加一条新笔记，至少给它接上一条已有笔记：是支持它、反对它，还是补充它？这一步最费时间，也最值钱。

### 第五步：按输出倒推维护

不要为了维护而维护，交给真实产出决定谁该留。每写一篇东西，就顺手修一遍你用过的那几条笔记。

## 习惯

- 收到素材先入库，不立刻整理，但规定一个清空收件箱的固定时间。
- 每读一本书或一份长材料，只强制自己写一条笔记：**它改变了我的哪个判断。**
- 每周挑一条旧笔记回看，问一句“它现在还算数吗”。
- 每季度看一次索引页，删掉再也不会打开的那几层。

## 与相邻能力的关系

- 与[目标管理](./targetmanagement.md)：目标决定知识管理的方向。没有目标，问题域定不下来，筛选器就是空的。
- 与[项目管理](./projectmanagement.md)：项目是知识管理的验货现场。做项目时被卡住的那几处，恰好告诉你哪些知识还没真正掌握。
- 与[项目式学习](../../cognition/learning/projectbasedlearning.md)：真实项目会替你淘汰掉大量“看着有用其实用不上”的收藏。
- 与[成长能力树](../../../growthtree/classification/index.md)：孩子那一侧对应的是“把每次经历变成可复用的经验”，做法比成年人简单得多，核心是让他自己讲一遍。
