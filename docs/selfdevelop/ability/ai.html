AI 使用能力

AI 不是替代人的智能，而是放大人能力的杠杆——同样的认知与目标，借助 AI 能产出 10 倍结果。本分类记录普通人（非技术从业者）学习和使用 AI 的方法论，聚焦日常场景，不讲技术原理。

一、从这里开始：三份材料的关系​

本分类下的材料分四层，建议按顺序阅读。前三层是“从零学到能用”的学习路线，第四层是“用起来之后怎么不失控”的方法层，两者可以并行看：

顺序材料给谁读完你会得到
1人人都能学会的 AI 学习规划（写给初学者）完全没接触过 AI，或只会简单提问听得懂的基础认知、15 分钟上手清单、五条安全守则、六步学习路线
2一人公司的 AI 实战进阶计划（AI Agent 学习路线）已会基本提问与判断，想用 AI 做出真东西一条 12～13 周的主线：从认知装备到规模化，六个阶段的路线图与过关标准
3六份阶段学习材料（下表）已决定按第 2 份执行的人每阶段的工具、方法、提示词模板、逐日清单、产出模板与自测题
4AI 协作方法论：锚点循环与五件套工具箱已在用 AI 做长周期项目的人一套可复用的协作流程与工具箱：认知锚点、五步循环、三条车道、五件套模板、四个度量指标

进阶版的六份配套学习材料​

一人公司进阶计划只给“学什么、达到什么标准”；下面六份材料给“具体怎么做”——每一份都可以直接照着做。

阶段材料主题时长阶段产出
一阶段一学习材料（认知与装备）Agent 是什么、工具选型、任务书写法、试运行第一位“员工”约 1 周公司构想一页纸 + 1 个跑通的调研 Agent
二阶段二学习材料（找对方向）带来源调研、竞品分析、用户访谈、付费意愿探测约 2 周产品机会卡片 + 用户研究档案
三阶段三学习材料（创造 MVP）需求拆解、无代码/AI 编程、包装、上线、可用性测试约 3 周可用的 MVP + 一页产品说明书
四阶段四学习材料（找到第一批用户）内容流水线、渠道选择、合规、自动化获客、冷启动约 2 周5 条内容 + 线索流程 + 首批反馈
五阶段五学习材料（运营与迭代）客服自动化、用户声音分析、北极星指标、迭代飞轮、停损约 3 周2～3 轮迭代记录 + 3 份决策周报

每份材料的结构是一样的，可据此跳读：零、开始之前 → 一、本阶段学习目标 → 二、工具选型 → 核心方法若干章 → 逐日任务清单 → 阶段产出与模板 → 配套练习与自测题 → 自检清单 → 带到下一阶段的资产 → 附录。

核心策略：每一层只留一个主力。 同层多开是新手最常见的失败原因——注意力被分散，每个工具都只用懂两成。

三、贯穿全流程的学习机制​

3.1 三种时长节奏：先定自己能投入多少​

所有阶段材料的逐日清单都按每周约 8 小时设计。开始前先给自己定位，然后照对应方式用材料：

节奏每周投入怎么用逐日清单纪律
保命档约 5 小时用每份材料的“最小版本”，把清单合并到 2～5 天一周最多用 2 周，第三周回到标准档
标准档约 8 小时按逐日清单走打卡率 ≥ 80%
加速档12 小时以上提前完成清单，加做练习与外部复核注意别为了快而跳过“找人真用一遍”

两条铁律：

  1. 不追进度，追完成度——清单拖长没关系，跳过关键动作不行；
  2. 每周复盘写三行——“我学会了什么 / 卡在哪里 / 下一步做什么”。

3.2 每阶段统一的两个动作​

动作位置作用
进入前的检查每份材料 零、开始之前确认你带着上一阶段的产出进来，不空手开工
带到下一阶段的资产每份材料倒数第二章把阶段产出变成下一阶段的输入，形成链条而不是六个孤岛

四、能力自评表（随时可做）​

这套计划真正训练的是五项通用方法加上两项经营能力。建议在阶段一开始前和阶段六结束后各打一次分，对比才是重点。

能力通俗说明自评（1～5）能证明它的产出
提问与对话能把模糊需求变成可执行的任务书
任务拆解与委托能把一件事拆成可委托的步骤
检索与验证会要求来源并抽查核验
工作流编排能分清 Agent / 工作流 / 自动化并组合使用
评估与把关能验收 AI 产出、识别幻觉与跑偏
判断与决策能在信息不全时做决定并写下理由
经营意识会算账、会定指标、知道何时收手

分数不重要，“证据”栏能不能填才重要——有证据的分数才是真的。

五、方法论与场景应用索引​

贯穿全流程的协作方法已经成篇：AI 协作方法论：锚点循环与五件套工具箱——认知锚点（全量 / 增量）、五步锚点循环、三条车道、五件套模板、四个度量指标与五个常见坑。其余更细的方法论与场景文章仍在整理中，先占位如下：

通用方法论​

  • 提问与对话：任务书四要素（角色 / 目标 / 约束 / 验收标准）与“先确认”技巧 —— 见阶段一 第四章
  • 任务拆解与委托：需求拆解四步法、开发委托模板 —— 见阶段三 第三章、第四章
  • 检索与验证：来源抽查、口径比对、证据分级 —— 见阶段二 第三章、第六章
  • 工作流编排：Agent / 工作流 / 自动化三词辨析与输入输出契约 —— 见阶段六 第三章、第四章
  • 评估与把关：验收记录、指标定义（分子分母时间窗）、反向指标 —— 见阶段一 5.3、阶段五 第五章

场景应用​

  • 写作与表达：内容流水线（选题 → 初稿 → 改稿 → 分发）与两条红线 —— 见阶段四 第三章
  • 学习与复盘：迭代飞轮、AI 周报与人只写三行 —— 见阶段五 第六章、第七章
  • 决策与规划：机会卡片、“做 / 不做”判断、停损判据 —— 见阶段二 第七章、阶段五 第八章
  • 生活与事务：方法迁移（检索验证、委托编排、兜底安全）—— 见阶段六 14.3

AI 技术原理见软件大师 · 人工智能，本分类只讲「普通人怎么用」。方法论答「怎么用」，场景应用答「为这个目标怎么取舍」。
