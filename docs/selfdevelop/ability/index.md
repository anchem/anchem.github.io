# 能力

能力是把认知转化为结果的中介——知道「是什么」和「为什么」之后，还要能把它做出来。本板块记录四类可训练的通用能力。

- [管理能力](./management/index.md)：目标、知识、项目与精力的管理，调配自身资源
- [成事能力](./getthingsdone/index.md)：从目标到执行的五步成事法
- [决策能力](./decisionmaking/index.md)：在不确定中做出高质量选择
- [展示能力](./presentation/index.md)：表达、演示与呈现，让好想法被理解和接受

四类能力是一条链：管理调配资源，成事贯穿始终，决策决定方向，展示放大成果。
