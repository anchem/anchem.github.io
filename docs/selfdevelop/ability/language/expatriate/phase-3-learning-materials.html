阶段三学习材料：口语输出（第 3 个月）

本材料是《英语进阶学习计划（外派罗马尼亚 · 6 个月）》第三阶段的配套学习内容，按四周推进：第一周影子跟读过渡 → 第二周复述训练与首次外部反馈 → 第三周 PREP 观点表达 → 第四周录音复盘方法论。阶段主题是口语输出，前两个月（语音节奏、精听）打的是「耳朵」与「节奏」的地基，这个月把积累真正说出口。

本阶段的定位

第三阶段不追求「说得完美」，追求「开口有章法」：①把「跟读」升级成「影子跟读」，让嘴跟上真实语速；②用「复述」把听到的内容用自己的话讲出来；③用「PREP」框架让即兴表达有结构、不卡壳；④用「录音自评」把错误找出来并改掉。这四件是后面三个月所有场景实战的输出能力地基。

二、第一周：影子跟读过渡​

2.1 从「跟读」到「影子跟读」​

核心概念：跟读（repeat）是先听一句、暂停、再模仿；影子跟读（shadowing）是不暂停、不重来，像影子一样跟在原声后面半拍说出来。

对比项跟读影子跟读
停顿每句暂停不暂停，连续进行
滞后无滞后滞后 0.5～1 秒（延迟跟随）
文本可看稿不看文本，凭听
训练目的模仿单句语音训练节奏、意群切分、短时记忆、输出流畅度
难度低高

过渡方法（三步走）：

  1. 第一步（第 1～2 天）：先正常跟读 2 遍，熟悉内容与语音，再进入影子跟读。
  2. 第二步（第 3～5 天）：正式影子跟读，滞后 0.5～1 秒、不看文本。跟不上没关系，保持节奏不断最重要——宁可含糊带过，也不要停下来重来。
  3. 第三步（第 6～7 天）：录音自评，用同步率法（见 2.2）数意群同步情况。
滞后感怎么找

影子跟读的「滞后 0.5～1 秒」指的是：你开始说某个意群时，原声大概已经把这个意群读完一半。你是在「跟着复述」，不是在「和原声同时抢着说」。刚开始可以故意晚半拍，练熟了自然就会找到合适的滞后。

2.2 同步率怎么数（示例）​

数法：取 1 分钟材料，把它切分成 10 个意群，逐群对比你与原声——每个意群只要出现「漏词」「错词」「节奏错位」中的任意一种，就计这个意群不同步。

同步率 = 同步的意群数 ÷ 10 × 100%

示例材料（1 分钟技术类播客片段，切为 10 个意群）：

① When we deploy a new software version /  ② the first thing we check /  ③ is the monitoring dashboard. /  ④ If any alarm shows up /  ⑤ with a severity above a warning, /  ⑥ we open a ticket immediately /  ⑦ and start a diagnosis. /  ⑧ The root cause is usually found /  ⑨ within a few hours. /  ⑩ Then we apply a fix and verify the result.

学生影子录音对比示例：

意群原声学生影子判定
①When we deploy a new software versionWhen we deliver a new software version错词（错）→ 不同步
②the first thing we checkthe first thing we check同步
③is the monitoring dashboardis the monitoring dashboard同步
④If any alarm shows upIf any alarm show up（漏了 s）错词 → 不同步
⑤with a severity above a warningwith a severity above a warning同步
⑥we open a ticket immediatelywe open a ticket immediately同步
⑦and start a diagnosisand start a diagnosis同步
⑧The root cause is usually foundThe root cause is usually found同步
⑨within a few hourswithin a few hours同步
⑩Then we apply a fix and verify the resultThen we apply a fix and verify the result同步

同步 8 个意群，同步率 = 8 ÷ 10 = 80%，达标（≥ 80%）。注意：第②④的「错词」哪怕只是单复数（show up 漏 s）也算该意群不同步——同步率衡量的是「整体跟上没跟上」，不是「大概意思对没对」。

2.3 意群怎么切分​

切分意群是影子跟读的基础。意群（chunk）= 一个语法或语义完整的小单位，通常是一个短语或一个分句。

切分规则例子（/ 处为停顿）
介词短语自成一组We met / in the meeting room / yesterday.
从句自成一组If the alarm is high / we escalate it.
并列成分分开We checked the logs / and the configuration.
主谓宾完整句可成一组The system recovered / after the reboot.
常见误区

影子跟读不是「默读」也不是「背稿」。默读不练嘴，背稿不练「跟」。影子跟读必须出声，且跟着原声的节奏走——你的目标是「贴着原声」，不是「抢在原声前面」把整句背出来。

三、第二周：复述训练与首次外部反馈​

3.1 听后复述框架​

核心概念：复述（retell）不是逐句背诵，而是用自己的话把听过的内容讲出来。它是「听力 → 输出」的关键桥梁：证明你真的听懂了，而不是只是跟读出来了。

听后复述五要素框架（时间 / 地点 / 人物 / 发生了什么 / 结果）：

要素要回答的问题示例（例会通报）
时间 When什么时候发生Last night around 11 p.m.
地点 Where发生在哪个系统/网元on NE123, the core network element
人物 Who涉及谁/哪个团队my team and the on-call engineer
发生了什么 What核心事件是什么a high-severity alarm went off
结果 How it ended最后怎么解决we applied a workaround and it's stable now

复述三步流程：

  1. 听：完整听一遍材料，抓住五要素，允许做简单笔记（时间/名词/数字）。
  2. 说：不看笔记，用自己的话把五要素串成 3～4 句话讲出来。用简单句，不追求原词。
  3. 对：对比原材料的要点，看有没有漏掉关键信息；再重听一遍补漏。

示例（复述一段 1 分钟的例会汇报）：

原声大意：昨晚 11 点 NE123 网元出现高优先级告警，值班工程师排查后确认是配置错误，采用临时规避方案后系统恢复稳定，永久补丁将在下次维护窗口部署。

学生复述：A high-severity alarm went off on NE123 last night around 11. The on-call engineer found it was caused by a configuration error. We applied a temporary workaround and the system is stable now. The permanent fix will be deployed in the next maintenance window.

复述时用你自己的话，不必复现原声的表达；只要五要素齐全、逻辑通顺即可。

材料类型时长用途频率

生活类短视频1 分钟复述生活话题每天 1 段
复述和听写的关系

前两月你练的「精听五步法」是把内容写下来，复述是把内容说出来。写下来检验「听清了没有」，说出来检验「能讲明白没有」——两者配合，听力才算真正内化。

3.3 首次外部反馈（必做）​

核心概念：自评容易「自我感觉良好」，需要真人反馈来校准。从第 2 周起，每 2 周 1 次真人反馈，必做——平台用 italki 或 Cambly，约 ¥100～150/次。

反馈流程：

  1. 课前准备：选好材料（1 段影子录音 + 1 段话题演讲），明确「这次想解决什么问题」（比如「我的时态总错」或「我说话卡顿太多」）。
  2. 课中呈现：给外教放你的录音，或直接对话；请对方按反馈记录表的维度给评价。
  3. 课后记录：当天就把反馈填进反馈记录表，落实改进动作。

反馈记录表怎么用（模板见附录）：重点是「改进动作」和「下次复查」两列——反馈不落到动作就等于白听。比如外教说「你过去式总用成原形」，你的改进动作就是「每天复述时专门检查 5 处过去式」，下次复查时请外教再听 3 句过去式。

为什么「必做」

真人反馈是阶段三硬性里程碑（至少 2 次），不是可选加分项。它解决的是自评失真的问题——你录音时以为「还不错」，但真实对话场景下对方可能根本听不懂。第 2 周和第 4 周各做 1 次，正好覆盖本月两次。

四、第三周：PREP 观点表达​

4.1 PREP 框架​

核心概念：PREP 是即兴发言的四步结构，让任何话题都能「有观点、有理由、有例子、有收尾」：

步骤英文中文作用时间占比
PPoint观点开门见山亮明立场10%
RReason理由给 1～2 个支撑理由30%
EExample例子用具体案例或数据证明40%
PPoint重申观点收尾回扣观点20%

示例（话题：远程办公好不好？）：

P（观点）：In my opinion, remote work is a good idea for most software teams.

R（理由）：Because it saves commuting time and lets people focus on deep work.

E（例子）：Last year our team worked from home for three months, and we finished more tickets with fewer interruptions. The only downside was that communication took more effort.

P（重申）：So overall, I think remote work helps productivity as long as the team keeps clear communication.

4.2 观点库话题清单​

本月 PREP 训练围绕四类观点库话题，覆盖你未来的工作与生活场景：

类别话题示例
工作 Work① 为什么软件维护要重视文档；② 问题单处理中最难的是什么；③ 升级前要不要做回退演练
家庭 Family④ 我如何看待父母参与育儿；⑤ 周末家庭活动怎么安排
育儿 Parenting⑥ 孩子学外语越早越好吗；⑦ 国际学校 vs 本地学校怎么选
赴罗生活 Life in Romania⑧ 我期待在罗马尼亚体验什么；⑨ 到一个新国家最需要准备什么；⑩ 我如何帮助女儿适应新学校

观点库怎么用：每天从观点库抽 1 个话题，先口头用 PREP 讲 3 分钟，再录音。观点库不是用来背答案，是用来逼自己在「没准备」的情况下也能讲出结构——即兴表达练的就是这个。

4.3 衔接词清单​

衔接词是让表达连贯的「路标」。PREP 的每一步之间用衔接词过渡，能明显减少卡顿和「嗯/啊」。

功能衔接词例句
亮观点In my opinion / I believe / From my perspectiveIn my opinion, documentation is crucial.
给理由because / since / the reason isThe reason is it saves us time later.
举例子for example / for instance / such asFor example, we had a P1 alarm last week.
并列补充moreover / also / in additionMoreover, it reduces miscommunication.
转折however / but / on the other handHowever, it takes extra effort.
让步although / even thoughAlthough it takes time, it's worth it.
因果therefore / so / as a resultTherefore, we decided to do a rollback.
顺序first / then / finallyFirst we diagnose, then we fix.
收尾重申in short / overall / to sum upIn short, I think it's worth doing.
争取时间let me think / well / actuallyLet me think... I'd say yes.

争取时间的话术：即兴发言时卡住很正常。与其干愣着（停顿 > 2 秒会计入卡顿点），不如用「Let me think for a second」「Actually, that's a good question」「Let me put it this way」争取 1～2 秒组织思路——既不卡顿，又显得自然。

五、第四周：录音复盘方法论​

5.1 录音自评四问​

核心概念：录音自评是「没有外教时」最有效的纠错手段。录完一段输出后，用四问系统复盘，把模糊的「感觉还行」变成明确的改进点。

问题具体检查例子
① 卡顿点在哪停顿 > 2 秒、重复修正发生在哪「…and we, and we (重复) looked into…」
② 语法错了几处时态、单复数、介词「Yesterday we look (应为 looked) at the log」
③ 词汇是否地道是否用了中式的直译「make a call to the network」→「call the network」
④ 节奏是否自然重音、意群停顿、是否蹦豆全句一字一顿 → 缺意群停顿

四问落地：每段录音复盘时，把四问的结果写进反馈记录表的备注或自评栏，形成「问题 → 动作」闭环。

5.2 常见口语错误清单​

结合你的工作场景，下面是 B2 学习者最常踩的 5 类口语错误。每周复盘时对着清单自查：

错误类型常见错误正确说法场景
时态Yesterday we find a bugYesterday we found a bug汇报历史问题
时态I worked here since 2020I have worked here since 2020讲述经历
单复数There are many alarmThere are many alarms描述告警
单复数The information are correctThe information is correct说明数据
介词I will discuss about the issueI will discuss the issue例会发言
介词We depend of the dashboardWe depend on the dashboard说明依赖
中式直译open a meetinghave / hold a meeting会议安排
中式直译give an example to explaingive an example of ...解释说明
改错闭环（最重要）

改错不是「知道了就行」，要形成闭环：① 录一段 → ② 用四问找错 → ③ 把最高频的错误列成 3 条 → ④ 下一段录音前专门练这 3 条 → ⑤ 复查这 3 条是否还犯。 每两周循环一次，错误会肉眼可见地减少。

5.4 月末标准怎么测​

影子跟读同步率：取 1 分钟材料，切 10 意群，逐群对比漏/错/节奏错位，同步 ≥ 8 个即达标（≥ 80%）。方法见2.2 同步率怎么数。

3 分钟 PREP 话题：抽 1 个观点库话题，用 PREP 讲 3 分钟并录音。数「停顿 > 2 秒」+「重复修正」次数，卡顿点 ≤ 4 达标。计数示例（沿用卡顿点法）：

I think documentation is important.（2.5 秒——计 1 点）because, because（重复修正——计 1 点）it saves us a lot of time. ...

共 2 点，达标。注意：正常想词间隙（< 2 秒）不计入。

六、配套练习与自测题​

使用说明

练习 1～3 建议在第一至三周内完成，练习 4 在第四周作为阶段自测。所有答案见参考答案与解析。先做，再对答案，最后看解析——直接看答案会失去训练价值。

练习 1：影子跟读同步率计数​

取下面 10 意群材料做一次影子跟读并录音，然后逐群对比，判断每个意群是否同步，计算同步率。

① We received a new trouble ticket this morning. /  ② The severity was high, /  ③ so the team started working on it right away. /  ④ We looked at the logs /  ⑤ and found the root cause. /  ⑥ It was a configuration error /  ⑦ on the core network element. /  ⑧ We applied a temporary workaround /  ⑨ and the network is stable now. /  ⑩ A permanent patch will go live next week.
  • 同步的意群数：____ / 10
  • 同步率 = ____%（≥ 80% 达标）

练习 2：听后复述（五要素）​

听下面这段 1 分钟例会通报（或找人读给你听），用自己的话复述，并填写五要素。

Yesterday around 9 p.m., the monitoring system sent a warning about high CPU usage on NE45. The on-call engineer found a log file was filling up the disk. He cleared the log and added a rotation rule. The system is back to normal now. The permanent fix will be reviewed in the next team meeting.

练习 4：综合自测（第四周做）​

一、单项选择

  1. 影子跟读相比跟读，最大的区别是：
    • A. 需要看稿　　B. 不暂停、连续、滞后跟读　　C. 语速更慢
  2. 影子跟读的滞后时间通常是：
    • A. 0.1 秒　　B. 0.5～1 秒　　C. 5 秒
  3. 同步率计数时，一个意群「漏了一个 s」算：
    • A. 同步　　B. 不同步　　C. 无法判断
  4. 听后复述五要素不包括：
    • A. 时间　　B. 价格　　C. 结果
  5. PREP 中 E 指的是：
    • A. Explain　　B. Example　　C. End
  6. 卡顿点计数时，停顿超过____秒计 1 点：
    • A. 1 秒　　B. 2 秒　　C. 5 秒
  7. 真人外部反馈的频率要求是：
    • A. 每月 1 次　　B. 第 2 周起每 2 周 1 次　　C. 可做可不做

  1. 影子跟读必须看着文本才能跟得上。（　）
  2. 即兴发言卡住时，用「Let me think」争取时间是合理的衔接技巧。（　）
  3. 录音自评四问只用来听发音，不用管语法。（　）

  3. B（漏一个 s 属于漏/错词，该意群判不同步）
  4. B（五要素是时间/地点/人物/发生了什么/结果，不含价格）
  5. B（E = Example）
  6. B（2 秒）

七、本阶段自检清单​

  • 影子跟读同步率 ≥ 80%（用同步率计数法连续 3 次达标）；
  • 3 分钟 PREP 即兴话题表达，卡顿点 ≤ 4（用月末测法）；
  • 完成至少 2 次真人外部反馈（第 2 周 + 第 4 周，italki/Cambly），反馈记录表填写完整；
  • 完成 10 段影子录音；
  • 完成 10 段话题演讲录音；
  • 新增词汇 300 个（口语动词短语 + 衔接词，Anki 月测正确率 ≥ 90%）；
  • 录音自评四问流程已形成习惯；
  • 本月打卡率 ≥ 80%。
未达标怎么办

未达标的项目顺延到第四阶段补，不要中断主线。比如「同步率 < 80%」→ 第四个月第 1 周影子跟读加量、材料不升级；「外部反馈没做」→ 下月第 1 周必须补做（真人反馈是硬性项）。先保住每日口语输出习惯，再谈补短板。
