# AI 使用能力

AI 不是替代人的智能，而是放大人能力的杠杆——同样的认知与目标，借助 AI 能产出 10 倍结果。本分类记录普通人（非技术从业者）学习和使用 AI 的方法论，聚焦日常场景，不讲技术原理。

## 二、工具选型总表（2026 年 9 月推荐）{#tool-stack}

:::warning 工具会变，方法不变
这张表是**当下实践效果较好、且国内可直接使用**的一套组合。每个工具的具体能力、免费额度、界面位置都会在几个月内变化，**价格与授权请以官网为准，注册后立刻记进你自己的工具箱清单**。表里给的“降级方案”是为工具变化预留的退路。
:::

| 环节 | 主力选择 | 为什么 | 降级方案 |
| --- | --- | --- | --- |
| **总管家（贯穿全程）** | **WorkBuddy** | 桌面端通用智能体，能直接读写本地文件、跑任务、交付成品而非只给建议 | 手动整理 + 对话应用 |
| 日常问答与写作 | 豆包 | 中文语感自然、响应快、免费额度充足 | 通义千问 / 文心一言 |
| 带来源的调研 | 秘塔 AI 搜索 | 引用标注最细，能输出带大纲的研究报告 | 豆包“深度研究”（快但引用较粗） |
| 微信生态检索 | 腾讯元宝 | 可检索公众号、视频号内容 | Kimi 长文本 |
| 长文档处理 | Kimi | 长文本总结与问答强 | 元宝 |
| Agent 编排与对外发布 | 扣子（Coze） | 零代码、节点编排成熟、可发布到部分官方渠道 | 腾讯云 ADP / 阿里百炼 / Dify（自部署） |
| 自动化工作流 | 扣子工作流 / n8n | 定时触发、条件分支、跨系统串接 | 手动 SOP + 日历提醒 |
| AI 编程 | Trae（SOLO 模式，免费） | 中文友好、对零基础最友好 | 通义灵码 / CodeBuddy / CodeGeeX |
| 无代码生成应用 | 秒悟 Meoo / 百度秒哒 | 一句话生成含前端后端的应用并一键上线 | 凡科轻站 / 腾讯微搭 / 简道云 |
| 图像 | 即梦 | 角色一致性较好，有免费额度 | 通义万相 / Canva 可画 / 稿定 |
| 视频 | 即梦（生成）+ 剪映（剪辑） | 出片质量靠前 + 剪辑与字幕能力强 | 可灵 / 只做图文 |
| 表格与看板 | 飞书多维表格 / 金山表格 / 简道云 | 免费额度够用，支持视图与统计 | 一张 Excel |

**核心策略：每一层只留一个主力。** 同层多开是新手最常见的失败原因——注意力被分散，每个工具都只用懂两成。

## 三、贯穿全流程的学习机制 {#mechanisms}

### 3.1 三种时长节奏：先定自己能投入多少 {#rhythm}

所有阶段材料的逐日清单都按**每周约 8 小时**设计。开始前先给自己定位，然后照对应方式用材料：

| 节奏 | 每周投入 | 怎么用逐日清单 | 纪律 |
| --- | --- | --- | --- |
| **保命档** | 约 5 小时 | 用每份材料的“最小版本”，把清单合并到 2～5 天 | 一周最多用 2 周，第三周回到标准档 |
| **标准档** | 约 8 小时 | 按逐日清单走 | 打卡率 ≥ 80% |
| **加速档** | 12 小时以上 | 提前完成清单，加做练习与外部复核 | 注意别为了快而跳过“找人真用一遍” |

**两条铁律**：
1. **不追进度，追完成度**——清单拖长没关系，跳过关键动作不行；
2. **每周复盘写三行**——“我学会了什么 / 卡在哪里 / 下一步做什么”。

### 3.2 每阶段统一的两个动作 {#per-phase}

| 动作 | 位置 | 作用 |
| --- | --- | --- |
| **进入前的检查** | 每份材料 `零、开始之前` | 确认你带着上一阶段的产出进来，不空手开工 |
| **带到下一阶段的资产** | 每份材料倒数第二章 | 把阶段产出变成下一阶段的输入，形成链条而不是六个孤岛 |

## 四、能力自评表（随时可做）{#self-assess}

这套计划真正训练的是五项通用方法**加上**两项经营能力。**建议在阶段一开始前和阶段六结束后各打一次分**，对比才是重点。

| 能力 | 通俗说明 | 自评（1～5） | 能证明它的产出 |
| --- | --- | --- | --- |
| 提问与对话 | 能把模糊需求变成可执行的任务书 | | |
| 任务拆解与委托 | 能把一件事拆成可委托的步骤 | | |
| 检索与验证 | 会要求来源并抽查核验 | | |
| 工作流编排 | 能分清 Agent / 工作流 / 自动化并组合使用 | | |
| 评估与把关 | 能验收 AI 产出、识别幻觉与跑偏 | | |
| 判断与决策 | 能在信息不全时做决定并写下理由 | | |
| 经营意识 | 会算账、会定指标、知道何时收手 | | |

**分数不重要，“证据”栏能不能填才重要**——有证据的分数才是真的。
