阶段一学习材料：认知与装备（约 1 周）

本文是《一人公司的 AI 实战进阶计划（AI Agent 学习路线）》第一阶段的配套学习内容，按七天推进：前两天读懂 Agent 与工具地图 → 第三天写任务书 → 第四至六天搭起并打磨第一位「员工」 → 第七天复盘与验收。

本阶段唯一的成功标准

不是“我读懂了”，而是“我派出去一个任务，它做完了，我能说清它哪里做对、哪里跑偏”。所有阅读、选型、对比，都是为这一个动作服务的。

零、开始之前：三件事先确认​

0.1 前置检查​

  • 你能写出“你是谁 + 做什么 + 要什么样”的提示词（基础篇水平）；
  • 你有“AI 会犯错、重要信息要核实”的意识，不会把 AI 的回答直接当结论；
  • 你准备好每周投入 5 小时以上，且能接受“某周完全没时间”；
  • 你愿意在没有回报的情况下先做一个月——这一阶段是纯投入期，产出是文档不是收入。

四项目前有两项不成立时：先回到基础篇补完提示词与验证习惯，再回来。这不是退步，是省时间。

0.2 三种时长节奏​

本材料的七天逐日清单是按每周约 8 小时设计的。其它两种情况这样调：

节奏每周投入怎么用这份材料必须做的动作
保命档约 5 小时把七天清单合并成 2～3 天（见5.4 最小版本）跑通一次调研 + 写验收记录
标准档约 8 小时按七天清单走全部
加速档12 小时以上提前完成清单，多出的时间加做练习题与第二次试运行全部 + 加做一次同类任务对比
两条节奏纪律
  1. 保命档一周最多用 2 周，第三周必须回到标准档；
  2. 不追进度，追完成度——七天清单拖成 10 天没关系，跳过“试运行”不行。

一、本阶段学习目标​

维度一周后达标线对应本材料章节
认知不看资料，2 分钟内讲清 Agent 的“四件套”和两个典型翻车点第三章 观念校准
选型能说出至少 6 个国内工具分属哪一层、各自适合什么任务第二章 工具地图
表达写出一份四要素齐全、可直接执行的任务书第四章 任务书
实操配好并跑通 1 个“市场调研员”Agent，产出可核查的调研成果第五章 试运行
产出完成《我的一人公司构想》一页纸（允许粗糙）第六章 产出模板
本阶段的定位

第一阶段不追求做出产品。它只做三件事：①把“Agent 能干什么、不能干什么”的预期校准到真实水平；②把工具箱装好，后面不再为“用哪个”反复纠结；③把任务书这个贯穿全程的手艺练到能用。

二、工具地图：先看清有哪些“员工”可选​

2.1 三层能力 vs 五层工具​

规划里说过“Agent / 工作流 / 自动化”三者不同，选型表又分了五层。把这两件事叠在一起看，就是下面这张总图：

工具层你要它干的事2026 年国内代表一句话定位

新手最常见的错误是同时开八个工具，结果每个都只用懂 20%。 本计划的策略是：每一层只留一个主力，其余留作备选。下面的推荐就是“只留一个”的结果。

2.2 本计划的推荐配置​

如果你不想研究工具，直接用这一套。它覆盖了本计划六个阶段的全部场景，且总成本可以做到 0 元。

角色推荐工具为什么选它成本
一号员工（总管家）WorkBuddy桌面端通用智能体，能直接读写你电脑上的文件、跑命令、生成文档与网页，可交付成品而不只是“给建议”；本阶段的试运行就用它有免费额度，按量计费

对外发布的 Agent扣子（Coze）零代码、节点编排成熟、能发布到微信/网页挂件，阶段四、五、六主力免费额度够用
长文档与合同Kimi长文本总结与问答最强免费
微信生态与公众号内容腾讯元宝可直接检索公众号、视频号内容，结论口径相对诚实免费

图像即梦角色一致性最好，免费额度每日可用免费额度
视频即梦 / 剪映 AI即梦出片质量靠前，剪映负责剪辑与字幕免费额度
工具会变，方法不变

上面每个工具的具体能力、免费额度、界面位置都会在几个月内改变。所以本材料在每个关键动作旁都写了**“这一步在做什么”**，而不只是“点哪个按钮”。工具换了，你照样能做。

2.3 如果你只想用一个工具​

完全不想装新工具的人，走这条路：

WorkBuddy 一个工具，跑完全部六个阶段。

WorkBuddy 能覆盖检索、写作、编程、文件处理、数据整理这些环节。它做得不够好的地方有两个，需要补充：

  1. 对外发布型 Agent（让陌生人直接和你的机器人对话）——这一环需要扣子这类平台，或者退一步用“手动回复 + WorkBuddy 起草”替代；
  2. 真实出图/出视频——这一段需要即梦/剪映，或者退一步用文字方案 + 免费图库替代。

这两处缺口不影响主线推进，材料里都给了“降级方案”。

2.4 三层概念的辨析表​

概念通俗解释判断口诀例子
Agent会“想”的决策者，看情况决定下一步步骤不固定客服 Agent 判断“这个问题要不要转人工”
工作流提前排好的步骤链，顺序固定步骤固定，节点可拖收到表单 → 自动发欢迎信 → 记入表格
自动化由时间或事件触发的执行有触发条件每天 8:00 自动跑一遍数据汇总

一句话记住：Agent 决定“怎么做”，工作流规定“按什么顺序做”，自动化决定“什么时候开始做”。三者常常叠在一起用——一个客服 Agent（想）调度一条工作流（顺序），由用户发消息触发（自动化）。

2.5 成本粗估：先会算账，再谈规模​

规划把它列为五条边界之一（“有成本”）。你不需要精确到分，但要知道量级，否则某天会看到意料之外的账单。

概念通俗说法粗估方式
token计费单位，中文大约 1 个汉字 ≈ 1～2 个 token一篇 1000 字中文 ≈ 1500～2500 token
一次调研任务多轮检索 + 输出约 2000 字大约几万 token 量级
一次长文写作输入资料 3000 字 + 输出 2000 字大约 1 万 token 量级
一次 30 轮客服对话含知识库检索大约几千到几万 token，视上下文长度而定
三条估算提醒
  1. 上下文越长越贵——把整个历史对话反复塞回去，成本会成倍上升。任务做完就开新对话；
  2. 价格差异极大——不同模型单价可能相差十倍以上。简单任务（分类、打标、格式转换）用小模型，这是最有效的一招控本手段；
  3. 具体单价与免费额度随时会变，不要在材料里记价格，而是记在你自己的 00-工具箱.md 里：每个工具的免费额度是多少、超量怎么计费、在哪看账单。

阶段一的成本预期：基本可以做到 0 元。 有正收益之前不要为工具付费——这条原则贯穿全计划。

三、观念校准：Agent 的四件套与五条边界​

3.1 四件套​

组成部分通俗说法缺了它会怎样
大模型大脑它不懂你说什么，也做不了推理
规划能力做计划的人你给一个大目标，它只会回你一个通用答案，不会拆步
工具调用手脚它只能“说”，不能“做”——查不到、改不了、发不出
记忆记事本每轮对话都从零开始，你的偏好和项目进度全部丢失

自检方法：随便找一个你用过的 AI 应用，问自己“它这四样各是什么”。例如豆包：大脑是豆包大模型，规划体现在“深度思考”模式，工具是联网搜索与图片生成，记忆是它的对话历史与用户偏好设置。

关于“记忆”，一个常见的误解

很多工具的“长期记忆”其实只是你的偏好设置 + 最近若干轮对话，并不是真的记住了整个项目。跨会话、跨工具的长期记忆，通常需要你自己维护——这也是为什么本计划从阶段一就要求你建“我的一人公司”文件夹：你的文件夹，就是这套系统最可靠的那份记忆。

实践建议：每个阶段结束，把关键结论（公司构想、机会卡片、指标定义）单独存成一份**“项目事实”文档**，每次开新对话时先把它贴给 AI。这一招能显著减少“它又忘了”的挫败感。

3.2 五条边界与它们的“现场表现”​

规划里给了五条现实。这一节把每条现实翻译成你一定会遇到的具体现象，以及遇到时该做什么。

现实你会看到的现场你该做的动作
会出错、会幻觉它给出一份“2025 年市场规模 47 亿元”，但点开来源发现是另一回事要求它逐条给链接，你抽查 2～3 条；数据只用来定方向，不用来下结论
工具调用会失败搜索超时、代码报错、接口 403，它卡住后开始“猜”把报错原文贴回去，明确说“先解决这个报错，不要继续往下做”
会曲解指令你要 800 字报告，它给你 3000 字还附了 PPT 大纲验收时对着任务书逐条核对，多做的删掉、少做的补上
越复杂越需要人盯前 3 步都对，第 7 步开始悄悄改了你的假设在关键节点设卡：调研完成先看结论，再让它写正文
有成本连续跑几小时，月底账单超出预期先免费额度、后付费；长任务前先问一句“这个任务大概要消耗多少”
阶段一就要建立的三个肌肉记忆
  1. 要来源：任何事实性数字，都要它给链接；没有链接的数字，一律写“待核验”。
  2. 设卡点：长任务拆成 2～3 段，每段结束先验收再继续。
  3. 留退路：让它改动文件之前，先确认有备份，或者让它新建文件而不是覆盖原文件。

3.3 你的新角色：派活的人​

旧角色（对话助手时代）新角色（Agent 时代）
我该怎么说它才懂我该怎么把这件事讲清楚
它答得对不对它交的活能不能用
一次对话解决一个问题一次委托推进一件任务
出错了就重问出错了先定位是哪一步错的

一个立刻能用的转换公式：把“帮我看看这个”改成“你要交付什么、给谁看、什么范围内、做到什么程度算合格”。

四、任务书：把目标讲清楚的手艺​

4.1 四要素模板​

【角色】你是______，服务于______。
【目标】请完成______，最终交付______（格式：______）。
【约束】只使用______；不要______；必须______；字数/时长______。
【验收标准】做到以下条件视为合格：
  1. ______
  2. ______
  3. ______
【先确认】开始之前，先用三句话复述你理解的
  任务目标、交付物和边界；我确认后你再动手。

最后一条【先确认】是新手最值得加的一句提示词。它把“跑偏了才发现”变成“动手前就发现”，性价比极高。

4.2 三份完整任务书示例​

示例一：市场调研员（本阶段试运行用，可照抄）

【角色】你是一名严谨的行业研究员，为一位准备做"面向小学生的 AI 编程课"的
        独立创业者服务。
【目标】调研中国"小学生 AI 编程教育"市场现状，交付一份 800～1200 字的
        调研简报（Markdown），结构为：市场规模与增速 / 主要玩家与模式 /
        家长付费决策的关键因素 / 三条对创业者可执行的机会判断。
【约束】只使用可公开查证的来源；每一个事实性数字后面必须标注来源链接；
        查不到的数据写"未找到公开来源"，禁止推测填充；不写客套话；
        不使用"我们认为"这类无依据的表述。
【验收标准】
  1. 至少 8 个事实性数字，每个都带可点击来源；
  2. "主要玩家"一节至少覆盖 4 家，含各自模式与定价区间；
  3. 三条机会判断每条都能追溯到简报中的某组数据；
  4. 全文不超过 1200 字。
【先确认】开始之前，先用三句话复述你理解的任务目标、交付物和边界；
          我确认后你再动手。

示例二：文案改写员（阶段四会用到，先熟悉结构）

【角色】你是一位小红书账号的内容编辑，账号定位"教上班族用 AI 省时间"。
【目标】把下面这段 400 字的产品介绍，改写成 3 条小红书笔记，每条
        150～250 字。交付格式：每条含标题（不超过 20 字）、正文、
        3～5 个话题标签。
【约束】口语化、第一人称、不用"赋能/闭环/抓手"这类词；不承诺效果
        （不写"保证""一定"）；不使用夸张数字；不出现联系方式。
【验收标准】
  1. 三条笔记切入角度互不重复（如：痛点场景 / 对比实测 / 清单干货）；
  2. 每条都有具体的场景细节，不空谈；
  3. 没有一条出现夸大宣传用语。
【素材】______（把产品介绍粘在这里）

示例三：数据整理员（阶段五会用到）

【角色】你是一位数据分析助理。
【目标】读取 attached 的 30 条用户反馈（CSV），交付一份归纳报告：
      好评集中在哪 3 类 / 吐槽集中在哪 3 类 / 被提到但产品没做的隐藏需求 /
      建议优先处理的 2 件事及理由。
【约束】每条结论后面标注它来自哪几条反馈的编号；不得加入文件中没有的
        信息；不得把"用户客气话"（如"整体不错"）归入好评。
【验收标准】
  1. 每条结论都能指到原始反馈编号；
  2. 隐藏需求至少 2 条；
  3. 优先处理建议给出排序理由（影响人数 × 严重程度）。
用【先确认】省下半数返工

把上面三份任务书都加上【先确认】，你会发现 AI 经常在复述阶段就暴露了理解偏差——这一步不花时间，省的是后面全部重做的时间。

4.3 任务书的三个常见毛病​

毛病反面例子改法
目标含糊“帮我调研一下这个市场”补上：给谁看、交付什么格式、多少字、含哪几节
只有约束没有验收“要严谨、要专业”换成可数的标准：至少 8 个数字、每个带链接、不超过 1200 字
一次塞十个要求一条任务书里同时要调研、写方案、做图、写代码拆成 3～4 次委托，每次一个交付物

操作步骤（逐步照做）

我目前最不确定的是：______
一个被低估的动作

把“我最不确定什么”写下来。 阶段二的全部工作，本质上就是去回答这个不确定。写清楚了，你就不会在访谈时问一堆跟假设无关的问题。
