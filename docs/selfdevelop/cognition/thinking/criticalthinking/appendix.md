# 书目地图、书单真相与一页速查卡

这一篇是三样收尾的东西：**书单里最容易骗到你的地方，每本书各自的位置，以及一页可以抄走的速查卡。**

## 书单里的三处分歧与三处容易混成两处 {#conflicts}

### 先说容易混成两处的：它比分歧更容易骗到你

你以为自己读了两个来源、两个作者、两本书，其实其中两对是同一本著作的两个中译版本；剩下一对虽然确实是两本书，却共用同一套框架，同样不构成两个独立来源。

| 看似两处 | 实际关系 | 说明 | 怎么用 |
| --- | --- | --- | --- |
| 《精准决策》与《哈佛商学院判断与决策心理学课》 | 同书异名 | 同一本著作（Bazerman & Moore 的 *Judgment in Managerial Decision Making*）的不同中译版本，作者、框架、七种纠偏策略都一样 | 读一本即可，别以为读了两个来源就交叉验证过了 |
| 《创造力：心流与创新心理学》与《创造性：发现和发明的心理学》 | 同书异名 | 同一著作的不同中译版本，个人—领域—学界的框架与心流概念一致 | 同上 |
| 《批判性思维》与《思辨与立场》 | 同框架，两本书 | 同为保罗 & 埃尔德，但原书是两部不同的作品：前者对应 *Tools for Taking Charge of Your Learning and Your Life*，后者对应 *Tools for Taking Charge of Your Professional and Personal Life*；两书共用思维八要素 + 判断标准 + 思维特质这套框架 | 择一精读，另一本当工具书查。共用框架不等于内容相同，别把它们当同一本书，也别当两个独立来源 |

前两对是**同一本书的两个译本**，第三对是**同一套框架下的两本书**。

两者的共同点是都不能算两个独立来源；区别在于，只有前两对能“读一本即可”，第三对确实有两本书的内容，所以做法是择一精读。

### 再说分歧：三处不是谁错，是适用范围不同

双方说的是不一样的场合，本身谈不上矛盾；但如果只读了一家，你就会拿一个片面的结论去套所有情况。

| 分歧 | 一方主张 | 另一方主张 | 整合建议 |
| --- | --- | --- | --- |
| 偏误清单有没有用 | 《清醒思考的艺术》《决策与判断》给出几十条偏误清单，暗示“知道就能防” | 《思考，快与慢》《噪声》的结论是知道名字不能消除偏误（作者本人在自己研究的偏误上照样中招） | 清单不当自我提醒用，当流程设计用：不指望自己当场清醒，而是让判断必须经过一个结构化步骤。个人练体感信号（[八个体感信号](./guards.md#tool-signal)），组织靠流程与结构 |
| 该慢想还是该快想 | 《思考，快与慢》《精准决策》要求警惕直觉、调用慢思考 | 契克森米哈赖与《思维突破》都在说：放松、酝酿、心流状态下的自动运作才是产出的高峰 | 按任务类型分：有标准可核的判断用慢思，没有标准答案的产生用快想，把批判性思维放到“评价”阶段（见[它和创造力、AI 的关系](./creativity-ai.md)） |
| 凡事要证据吗 | 《学会提问》《超越感觉：批判性思考指南》《独立思考》都要求主张必须有证据 | 摩尔 & 帕克把道德、法律、审美推理单列成不同章节——说明它们不能套同一套证据标准 | 先分类主张（事实 / 价值 / 政策），再选尺子（见[一次好判断是怎么发生的](./judgment-flow.md#framework)）。对价值主张用“理由是否一致、能否普遍化”，不要追问“有没有数据证明” |

### 还有一处不算分歧，但是个陷阱

《如何阅读一本书》主张**先完整理解再评价**，而信息流环境要求你必须**三秒筛掉大部分**。

这两条放在一起看好像互相矛盾，其实它们针对的是不同成本的阅读。整合办法是按档位分开——高成本、会进入决策的材料用“先理解后评价”，其余用三秒分诊（见[信息六问末尾的分诊规则](./checks.md#tool-info)）。

:::info[关于这份书单的两个提醒]

**一、书单共 28 本书，上表就是 28 行，一一对应。** 其中两对是同一本著作的两个中译版本：Bazerman & Moore 的两本、契克森米哈赖的两本。另一对是同作者、同一套框架的两本不同作品：保罗 & 埃尔德的两本。两种都已在上表并列标注。

买到两个译本、或者买到同一套框架的两本书，都不等于你有了两个独立来源。**这是信息评估里最基础的一类错误：把同一处来源数成了两处。**

**二、有两本通俗读物只按主题采信**（表中已标出）：《一读就上瘾的逻辑学》与《思维的陷阱》。它们的内容框架与经典著作一致，但本手册没有引用它们的具体表述或数据。

表中其余各条的归属都到“这本书主张什么”这一层，未逐字核对原文。全部十篇没有摘抄任何原文，所有内容都是对可执行部分的重新表述。

:::

## 一页速查卡 {#cheatsheet}

```text
总纲：批判性思维不是态度，是流程
  分类 → 证据 → 论证 → 换位 → 记账

最小可用四问（时间不够时只用这个）
  1. 这是事实、预测，还是评价？
  2. 证据是什么，什么等级？
  3. 什么情况下我会改主意？
  4. 这个决定可逆吗？

清单一 · 信息六问
  它是什么 / 谁说的 / 他为什么现在说 / 证据什么等级 / 过期没有 / 反向搜一次
  先做三秒分诊：会进入判断或决定的，才值得走完六问

清单二 · 论证六步
  论题 / 结论 / 理由（哪条是主梁）/ 假设（没说出口的）/ 概念（是否同一件事）/ 反例
  谬误是给自己的报警，不是给别人的弹药

清单三 · 决策
  前：可逆吗 / 最贵的代价在哪个单位 / 我在替谁做 / 什么会推翻我 / 标准先写
  中：至少三个选项 / 先独立后聚合 / 事前验尸 / 换三副眼
  后：决策质量与结果质量分开 / 对照记录而非记忆 / 算清运气那份

清单四 · 八个体感信号
  "我早就这么想" "大家都这么说" "这次不一样" "已经投了这么多"
  "我先找找支持这个说法的资料" "我现在就要定" "这数字看着挺有道理" 状态不佳

清单五 · 沟通八条
  先复述再回应 / 打最强版本 / 分清事实价值政策 / 人与话分开
  标出把握程度 / 举证责任对等 / 判决与讨论分开 / 连着被驳就回头查自己

三处容易数成两个来源的（别把一处来源当成两处）
  同书异名：精准决策 = 哈佛商学院判断与决策心理学课
  同书异名：创造力（契克森米哈赖）= 创造性：发现和发明的心理学
  同框架两本书：批判性思维（保罗&埃尔德）与思辨与立场（择一精读）

三处分歧的整合
  偏误清单：不当自我提醒用，当流程设计用
  快想慢想：有标准可核的用慢思，没标准答案的用快想
  要不要证据：先分事实 / 价值 / 政策，再选尺子

三样不能砍的（21 天版也要留）
  决策日志 / 事前验尸 / 每周复盘
```
