# 它和创造力、AI 是什么关系

这一篇处理两个容易被搞混的关系：一个是老关系——它和创造力；一个是新关系——它和 AI。

两者的共同点是：**批判性思维在这两件事里都不是主角。** 它只负责其中一个位置，搞错了位置，两边都会落空。

## 与创造力：不是对立，是分工 {#creativity-ai}

- **产生一个想法只是第一环。** 有一组关于创造力的研究，把创造力放在“个人—领域—学界”三者的系统里看。一个想法要被同行承认、过得了领域内既有的标准，才算数。批判性思维在这里扮演的角色，就是那个**被内化的标准**——你要能自己扮演那个挑剔的同行，在想法还没交出去之前先替他把关。
- **它只属于五个阶段中的一个。** 创造性过程通常分五段：准备、酝酿、洞见、评价、落实。**批判性思维只属于“评价”那一段。** 如果把它提前挪到“酝酿”和“洞见”那两段去用，它会把刚冒头、还不成形的想法直接掐死。这是[八个常见误用](./pitfalls.md)里要反复防的一个坑。
- **AI 时代的位置更清楚了。** 有一种说法对这一点特别对症：**AI 擅长“从一到无穷”的迭代，人的位置在“从零到一”。** 而“从零到一”最需要的，恰恰是先允许自己提一个不成熟的问题，再慢慢把它磨成能站住的判断。前半段需要放松，后半段才需要批判——顺序颠倒，两边都做不成。
- **阻碍常常不是能力，而是障碍。** 关于思维的另一类研究给的是反面：阻碍创造力的往往不是能力不够，而是若干**思维障碍**（感知、情感、文化、环境、表达）。这和偏误清单高度重叠——**很多“想不出来”，其实是“不敢想”。**

## 与 AI：先分清它能给什么、不能给什么

- **它给的是候选，不是结论。** 它一次能给你十个版本，但哪一个能用，它不知道，也不为结果负责。你否掉了哪几版、为什么否，才构成你的判断力（延伸阅读见[AI 时代，人该重点培养哪些能力](../../../outlook/humanity/human-abilities-in-ai-era.md#ceiling)）。
- **它最危险的用法，是当确认偏误的加速器。** 你可以让它专门为你的既有立场找理由，它会照做，而且说得漂亮、条理清楚。你以为自己得到了“被论证过的”确信，实际上只是把原来的偏见重新包装了一遍。
- **更好的用法是让它当反方。** 把它的角色固定成“给我最强的反对意见 + 我这套说法最弱的一环 + 什么证据能推翻它”。这样它就从你的放大器，变成了你的对手。
- **它的产出必须走完两张清单才算数。** 尤其是其中的数字、引用与“研究表明”。它可能给你一个真实存在但被曲解的研究，也可能给你一个根本不存在的引用，而这两者的语气一样自信。相关做法见[信息六问](./checks.md#tool-info)与[论证六步](./checks.md#tool-argument)。
- **不要把判断外包出去。** 一句“AI 说可以”，同时省略了三样东西：理由、责任、可检验性。省掉的恰好就是判断力本身。**核查的责任不会因为产出变方便而转移。**

```text
和创造力

  给的是候选不是结论 / 别让它当确认偏误的加速器
  让它当反方（最强反对 + 最弱一环 + 推翻条件）

```
