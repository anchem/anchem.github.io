# 要拍板了：前中后十二问

做决定时最常见的错误，不是选错，而是**顺序反了**：先纠结选哪一个，再回头补标准。可等你补标准的时候，标准早就被第一个方案带偏了。

所以下面十二个问题分成三段，**顺序不能反**：

- 先问清这件事值不值得认真对待（前五个）；
- 再谈怎么选（中间四个）；
- 最后才谈怎么复盘（最后三个）。

不必每件事都问满。日常小事跳过前面几个直接选，反而是对的——把注意力省给真正重要的决定。

这套提问吸收了四种已有做法：

- 《精准决策》的七种纠偏策略；
- 《对赌》的时间旅行与置信度记账；
- 《噪声》的决策卫生；
- 《批判性思维：高效决策和解决问题的方法与工具》的“分析—结论—创新—决策”四段式。

具体出处见篇末。

## 决策前：这件事值不值得认真对待 {#tool-decision}

### 1. 这件事可逆吗？

做错了能不能撤回？

- 能撤回的（一次试验、一版草稿、一个临时方案）→ 快做。做的成本低于反复想的成本。
- 撤不回的（公开发言、签字、伤人的话、健康、信誉）→ 慢做，并且自己做。

判据就一句：**能撤回的可以交给工具，撤不回的留给自己。**

### 2. 最贵的代价落在哪个单位？

时间、钱、关系质量——这三样不能相加，也不能互换。

你在比较方案时最容易犯的错，就是把它们塞进同一列去比大小。把“损失两小时”和“损失一次信任”换算成一个数字去权衡，比出来的结论一定是错的，因为你强行给关系定了一个假的价。

### 3. 我在替谁做决定？

只替自己，还是也在替家人、团队、客户做决定？

范围一变，标准就要跟着变。替自己，你可以接受“我愿意”；替别人，你必须能说清“为什么这样对他也好”。说不清，你就是在用别人的代价试自己的判断。

### 4. 什么会让我改主意？

在开始选之前，先写下：出现什么情况，我就改主意？写下来之后，再回头看现在的证据够不够支撑结论。

写不出推翻条件，说明这还不是一个可以决策的问题，只是一个你自己还没想清楚的倾向。

### 5. 标准先写，选项后看

先单独拿出一张纸，写下“对我来说，什么算好”，再去看摆在面前的方案。

顺序反过来的代价很具体：你一定会被看到的第一个方案锚住，之后每个方案都在以它为参照物。锚定效应连专业谈判者都躲不过——**先看到的东西，会替你定义什么叫“贵”和“便宜”。**

## 决策中：怎么选 {#q-during}

### 6. 至少三个选项

只有两个选项的时候，你是在做选择题，对错全看这两个里哪个更好；有三个以上，才回到真正的判断题——这时你会发现，原来的两个可能都不是最优，甚至可以不选。

第三个选项最常见的两个来源是“什么都不做”和“换个问题”。

### 7. 各自独立写，再开会

三四个人的会议，先让每个人**各自**写下自己的结论和把握程度（0 到 100 分），收齐之后再一起公开。

原因是：**第一个开口的人会锁住后面所有人的判断**，其他人要么顺着他调整，要么花力气反驳他，总之都不再是从零想过了。

这是决策卫生里最便宜的一条：所谓决策卫生，就是用固定的流程和顺序，消除判断中那些与事情本身无关的波动。它几乎不花钱，只需要改一下发言顺序。

### 8. 假设它已经失败了

问一句：“一年后这件事彻底搞砸了，最可能的三个原因是什么？”

这一步叫事前验尸。它的作用是把人从“论证它会成功”的状态里拽出来。**人一旦开始想怎么成功，就很难同时想它为什么失败**，所以这两件事必须分两次做。这比出了事再追责有用得多。

### 9. 换三副眼睛看一遍

依次用三个不同的身份，重看同一个决定：

- **反方**：最希望你错的人，会从哪里攻击？
- **局外人**：完全不懂这件事的人，会问什么傻问题？
- **三年后的自己**：到那时他最不在乎什么，又最在乎什么？

三个视角给出的答案常常互相打架。**这种打架本身就是信息**——它说明你面前的方案在某个维度上其实站不住。

## 决策后：怎么复盘 {#q-after}

### 10. 先把两件事分开

决策质量与结果质量是两件事：**好决定可能坏结果，坏决定可能好结果。**

用结果倒推判断，是复盘里最常见的污染源。一旦结果好就认定当初对，你就再也学不到东西了——因为这次的好运气被你记成了能力。

### 11. 对照当时的记录，而不是对照现在的记忆

复盘要翻当时写的字，不要靠回忆。

记忆会自动改写你当初的想法（后见之明偏误）：一旦知道了结果，你会觉得“我早就料到了”。只有写下来的字不会跟着结果改口。

### 12. 算清运气那份

结果里有多少来自能力、多少来自运气、多少来自别人的帮助，尽量分开估一估。

实在算不清，就写“算不清”，别默认都是自己的本事。这一条和上一条是配套的：不分开算，你就分不清哪些判断值得重复、哪些只是运气好。

## 时间不够时：五分钟最小集 {#tool-minimal}

事情没那么重、或者时间真的不够，只问下面四个问题就够了。它们是前面几组问题的最小交集，能拦住大部分明显的错误：

```text
1. 这是事实、预测，还是评价？
2. 证据是什么，什么等级？
3. 什么情况下我会改主意？
4. 这个决定可逆吗？
```

四个问题各管一件事：

- 第一问决定要不要认真对待（事实、预测、评价的检验方式不一样）；
- 第二问决定该信几分（证据等级不同，可信度就不同）；
- 第三问决定这个观点成不成立（说不出推翻条件的，先不算观点）；
- 第四问决定现在做还是先试（可逆的快速做，不可逆的慢慢来）。

## 带走的清单

```text
决策前   可逆吗 / 最贵的代价在哪个单位 / 我在替谁做 / 什么会推翻我 / 标准先写
决策中   至少三个选项 / 先独立后聚合 / 事前验尸 / 换三副眼
决策后   判断质量与结果质量分开 / 对照记录而非记忆 / 算清运气那份
```
