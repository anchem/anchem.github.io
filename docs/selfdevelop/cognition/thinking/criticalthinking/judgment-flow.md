# 一次好判断是怎么发生的

前面几篇给了一堆问法。这一篇把它们收成两条路径和一套流程，让你在脑子里装得下一个整体形状。

- **评估一条信息或一段论证**，走两条可复用的路径（第一条路径）；
- **做一个完整决定**，走九步（第二条路径）。

九步的顺序大致不能换，因为后一步依赖前一步的产出。而顺序之所以重要，原因很朴素。**大多数人一上来就跳到“找方案”那一步**，结果是在解一个错的问题，或者用一个自己都没想清楚的标准在挑东西。

## 两条路径：一条评信息，一条评论证 {#framework}

### 路径一：评估一条信息——真、准、全、新鲜、相关

- **真**：有没有一个可以查的来源，还是全靠“据说”；
- **准**：数字与限定词有没有在转述里被改掉（“多数情况下”被说成“都是”）；
- **全**：它省略了什么对照信息；
- **新鲜**：时效性，三年前的结论现在还成不成立；
- **相关**：它到底支持哪个结论。

最后一条最容易被忽略：**很多材料本身是真的，只是不支持别人拿它去支持的那句话。**

### 路径二：评估一段论证——主张、理由、假设、反例

论证的结构其实很朴素：**论证 = 主张 + 理由。** 其余所有的检查，都是给这两样做体检。

这里有个常被忽略的提醒：修辞技巧好的论证听起来更有道理，而**说得好不等于说得对**。流畅、自信、有例子，都不是证据。

### 换尺子：这一步最省事，也最容易漏

很多人吵不出结果，就是因为拿事实的尺子去量价值主张。所以，先看主张的类型，再选检验方式。

| 主张类型 | 该用什么检验 | 不该用什么 |
| --- | --- | --- |
| 事实主张 | 证据、样本、可重复性 | 立场与情绪 |
| 价值主张 | 理由是否一致、能否普遍化、成本由谁承担 | 有没有数据支持 |
| 政策主张 | 目标、手段、代价、副作用、替代方案 | 单一道德口号 |

用错尺子的典型场面是这样的。有人提出一个价值主张——“这么做不公平”。对方回一句“你拿数据出来”，对话立刻死掉。

价值主张本来就不靠数据成立，它靠的是理由能不能前后一致、能不能普遍适用、代价由谁承担。反过来，用价值口号去回应一个事实主张，也是同样的错位。

## 九步：一个完整决策的样子 {#decision-flow}

把几本决策相关的书放在一起看，一个完整的决策流程可以排成九步：

```text
1 定问题     我到底在决定什么？（常常一开始问错了问题）
2 定标准     什么算好？先写下来，再找方案
3 找选项     至少三个，其中一个必须是"什么都不做"
4 估概率     写区间而不是点估计；用期望值而不是最好结果
5 查代价     时间 / 钱 / 关系，各归各的单位
6 独立判断   多人决策先各自写，再聚合
7 事前验尸   假设已失败，回头看原因
8 定记录     写下结论、理由、置信度、推翻条件
9 结果复盘   分开决策质量与结果质量，对账
```

第 1 步有个具体提醒：“**现实**”和“问题”是两件事。 眼前发生的是一堆事实，而“问题”是你从这堆事实里挑出来的那个待解的题目。挑错了题目，后面八步走得再标准也没用。这一步的做法见[责任圈思维模型](../responsibilitycycle.md)。

最容易漏的是第 1 步和第 2 步。多数人一上来就跳到第 3 步找方案，结果是在解一个错的问题，或者用一个自己都没想清楚的标准在挑东西。

## 四处关键分寸

下面这四条不是步骤，而是这套流程的**边界条件**。越界了，流程会反过来害你——所以它们需要单独说清。

### 期望值不是赌博的借口

期望值教的是用小成本去换大把握，把那些长期重复做一定划算的事一直做下去。

这条思路有个前提：**你还能再来一次。** 只要还能重复，单次输赢就不重要。

它有一条不能越过的边界：**如果一件事不可逆、且后果致命，就不能靠“概率低”过关。** 因为这类风险没法用平均收益去摊平——九十九次小赢，抵不过一次彻底出局。

所以“长期看是正期望”这句话，只在“输得起、还能再来”的前提下成立。

### 直觉不是全错

直觉没那么可靠，但也不是一概不能用。

它在**规律稳定、反馈及时、练过很多次**的领域里相当管用——老司机判断车距、有经验的护士判断病人情况，都属于这一类。

但在**低效度环境**里（选股、预测长周期趋势、判断刚认识的陌生人），规律本来就不稳定、反馈又慢又少，直觉基本等于偏见。

这里的“效度”，说的是环境里的线索和结果之间有没有稳定关系。效度低，就是线索预示不了结果。

所以真正要判断的不是“该不该用直觉”，而是**你现在处在哪一种环境里**。

### 决策是选择，不是解方程

不少人把决策流程当成一个公式，好像输入对了就能输出唯一正确答案。

可做决定的是人。人受动机、情绪、群体影响，还有各种说不清的偏好。所以流程的作用是**减少犯错的概率，不是保证正确**——它让你少犯那些本来能被提前预见到的错，而不是让你每次都猜对。

### 判断力不能悬空练

这条边界必须说清楚：**在完全不懂的领域里，你的判断力约等于零。** 只要听起来有道理，你就会信，因为你没有可用来对照的东西。

所以判断力必须挂在具体的、有真实反馈的事情上。

[30 天启动计划](./plan.md)用的都是低风险的日常决策，那是**起步，不是终点**——它的作用是让你先熟悉流程，而不是让你变成一个什么都懂的人。

真正把判断力练强，需要真实项目和真实后果：练的载体见[“真实项目”](../../../outlook/humanity/human-abilities-in-ai-era.md#pbl)，和工具怎么分工见[“分工不是替代”](../../../outlook/humanity/human-abilities-in-ai-era.md#division)。

## 带走的清单

```text
评信息    真 / 准 / 全 / 新鲜 / 相关
评论证    主张 + 理由 + 假设 + 反例（论证 = 主张 + 理由）
换尺子    事实 / 价值 / 政策，三类主张三种检验

九步      定问题 → 定标准 → 找选项 → 估概率 → 查代价
          → 独立判断 → 事前验尸 → 定记录 → 结果复盘

四条边界  期望值要"还能再来" / 直觉要看环境效度
          流程只减少犯错概率 / 判断力不能悬空练
```
