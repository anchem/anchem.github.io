# 判断之外的两个干扰源：自己，和讨论

前面两张清单管的是“信息”，这两张管的是**判断发生的现场**。

现场有两个干扰源：一个是你自己（情绪、状态、惯性），一个是你身边的人（讨论、争论、群体压力）。这两样很少出现在论证里，却经常直接决定结论。它们不需要你更聪明才能防住，只需要你提前认识它们长什么样。

## 清单四：八个体感信号 {#tool-signal}

先把话说在前面：**偏误清单背得再熟，也拦不住偏误**（为什么，见[书单真相](./appendix.md#conflicts)里的第一处分歧）。

真正能当场起作用的，不是那些名词，而是**体感信号**——你会先觉得哪里不对劲，然后才去想它叫什么名字。所以下面这份清单的用途不是背概念，而是认出那种“不对劲”的手感。

出现下面任意一条，就暂停当前的判断：

- “**我早就是这么想的。**”——事后诸葛亮偏误在报警。这句话一旦冒出来，说明你已经站到了结果的立场上，这时候再看新证据，你只会挑支持自己的部分。
- “**大家都这么说。**”——从众偏误与可得性偏差。注意：人多只说明这条说法传播得好，不代表它真。你听到的是音量，不是证据。
- “**这次不一样。**”——通常是计划谬误和过度自信合在了一起：你既低估了时间与成本，又高估了自己的判断。越聪明、越自信的人越容易中这一条，因为他们把直觉当成了才能，而不是需要被检查的缺陷。
- “**已经投了这么多了。**”——沉没成本在说话，并且往往带着承诺升级：投入越多，越不肯承认选错，于是继续加注。记住一句：**已经花掉的钱和精力，在决定“接下来怎么办”时不该有任何权重。**
- “**我先找找支持这个说法的资料。**”——这句话几乎就是确认偏误的原文。正确的动作是反着来：先去搜最强的反方，看自己扛不扛得住。
- “**我现在就要定。**”——先给自己打个情绪分（0 到 10）。超过 7 分，就把决定写下来，明天再看一次。多数让你后悔的决定，都是在情绪最高的那一刻做出来的，而情绪峰值通常撑不过一夜。
- “**这数字看着挺有道理。**”——叙事偏误：人偏爱连贯、自洽的解释，一个好故事能让一组普通数字显得可信。所以看到“数据 + 故事”的组合时，要单独把数字拎出来，看它的来源。
- **状态不佳**：饿了、困了、刚被打断、正在赶时间——这些都是情境噪声。同一个人在不同状态下，对同一件事会给出不同判断。所以重要判断要么放在状态稳定的时候做，要么至少记下当时的状态，方便事后修正。

这八条不需要全记住。**记住你自己最常犯的两条就够了**——月度复盘会把这两条挑出来（见[复盘模板](./review.md)）。

## 清单五：与人讨论时的八条原则 {#tool-talk}

这八条解决的是同一个问题：**怎么让一场分歧往前走，而不是原地打转或者变成争吵。**

| 原则 | 具体做法 |
| --- | --- |
| 先复述，再回应 | 开口反驳之前，先用一句“我听到你说的是……，对吗”把对方的观点复述回去；对方说“对”，你再回应；说“不对”，就请他讲清楚，你重新复述一遍。多数争吵其实是没听懂 |
| 打最强版本 | 挑对方最弱的说法去攻击，赢了也不算赢，那只证明你能挑软的。改用他最强的那一版来回应；如果最强的那版你驳不倒，就要认真考虑改自己的看法 |
| 分清分歧类型 | 先判断争的到底是事实（可以查）、价值（不必强求一致），还是政策（要在几个代价里选一个）。三类分歧的解法不同，混着吵永远吵不完 |
| 分清人与话 | 反对一个观点不等于否定说这话的人；反过来，被反对的人也要主动说一句“这条我接受”，让对方知道这不是针对他 |
| 标出把握程度 | 用“我 70% 确定”代替“显然”，把不确定性摆到台面上。允许自己说“我不知道”是一种能力——业余选手才什么都敢下断言 |
| 举证责任对等 | 谁主张谁举证，这条对双方都适用。不接受“你证明不了它是错的，所以它是对的”这种要求 |
| 判决与讨论分开 | 先把双方的话都听完、说完，再下结论。边听边判，你听进去的就只剩支持自己的那部分了 |
| 连续两次被驳回就回头查 | 如果同一件事你说服不了任何人，先别怪对方固执，回头怀疑自己最初的表述是不是有问题——很多时候不是观点错，是话没说清 |

最后一条在长周期协作里也用得上，那套做法见[锚点循环与五件套工具箱](../../../ability/ai/ai-collaboration-methodology.md)。

## 带走的清单

```text
八个体感信号
  "我早就这么想" "大家都这么说" "这次不一样" "已经投了这么多"
  "我先找找支持这个说法的资料" "我现在就要定" "这数字看着挺有道理" 状态不佳

沟通八条
  先复述再回应 / 打最强版本 / 分清事实价值政策 / 人与话分开
  标出把握程度 / 举证责任对等 / 判决与讨论分开 / 连着被驳就回头查自己
```
