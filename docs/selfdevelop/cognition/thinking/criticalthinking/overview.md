# 批判性思维实战手册

这份手册只做一件事：**把“判断”从一个态度，变成一套能照着走的流程。**

它来自一份 28 本书的书单，从《思考，快与慢》一直到《噪声》《对赌》《拐点》。书单本身不解决问题——记住三十个名词，不等于下次做决定时能少错一次。所以这里不留读书笔记，只留三样东西：**能当场问出口的清单、能挂在日常里的动作、能事后对账的记录。**

十二篇各写一件事，可以跳着读，也可以只读其中一篇。

## 先划边界：它管什么，不管什么 {#boundary}

**它管的是“这个说法可不可信、这个决定该不该做”。**

**它不管“想法从哪来”。** 前者是筛选，后者是产生，两者用的不是一种能力，需要的心境甚至相反。产生想法要靠创造力、靠大量输入，而且往往是在放松、不设防的时候才冒出来；批判性思维管的是后半段，它的任务是把不行的筛掉。在需要想点子的场合开批判模式，两边都会落空。

站内另一篇[批判性思维](./index.md)给的是一张检查清单。这份手册是它的展开版：那份说该问什么，这份说怎么问、什么时候问、问到什么程度算完。

## 五张清单：这套系统的全部零件 {#os}

五张清单看起来分属不同领域，其实只是同一套流程在五个位置上的展开：

- 看到一条信息，先筛它；
- 决定认真看了，再拆它；
- 要拍板时，保证标准写在结论前面；
- 平时靠第四张防自己；
- 与人讨论时靠第五张让分歧能往前走。

| 清单 | 用在什么时候 | 一句话目的 | 在哪一篇 |
| --- | --- | --- | --- |
| 一、信息质量检查 | 刚看到一条信息 | 先决定值不值得花时间 | [先筛，再拆](./checks.md) |
| 二、论证拆解 | 决定要认真看之后 | 找到最脆弱的那一环 | [先筛，再拆](./checks.md) |
| 三、决策前中后提问 | 要拍板时 | 保证标准先于结论 | [拍板前后十二问](./decide.md) |
| 四、偏误预警信号 | 随时随地 | 认出自己正在犯错的体感 | [两个干扰源](./guards.md) |

这五张不必背，用的时候回来查就行。

## 总纲：五步，一句话 {#thesis}

全篇的操作骨架只有五步，遇到任何信息、观点、决定都可以往上套：

```text
① 分类   这是什么主张：事实 / 价值 / 政策
② 证据   它靠什么支撑，够不够，是什么等级
③ 论证   结论 + 理由 + 隐藏假设，哪一环最脆
④ 换位   反方最强的说法是什么，局外人怎么看，一年后怎么看
⑤ 记账   我此刻的结论、理由、置信度，写下来，事后对账
```

五个字：**分类、证据、论证、换位、记账。**

顺序不能乱。先分类，才知道该用哪把尺子；再查证据；然后拆论证；接着换位；最后记账。跳过第一步直接去查证据，最常见的后果是拿事实的标准去审一个价值问题，白花力气。
