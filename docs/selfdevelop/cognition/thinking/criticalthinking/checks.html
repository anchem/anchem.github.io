看到一条信息：先筛，再拆

一天里从你眼前过去的信息，大多数不值得动用判断力。真正的问题不是“怎么分析它们”，而是先分出哪几条值得分析。

所以这一篇讲两步：

  1. 筛——用六个问题，两分钟内判断这条信息值不值得花时间；
  2. 拆——如果值得，用六步找出它最脆弱的那一环。

拆论证的目的不是驳倒对方，而是决定自己要不要改看法。这一点很重要：你拆的是别人的论证，真正服务的对象却是你自己的判断。

清单一：信息真伪与质量检查（六问，两分钟）​

拿到任何一条你想相信的信息，按顺序问下面六个问题。只有一条要求：只要有一个问题答不上来，就先不下结论，只把它标记成“待核”。

所谓待核，就是先存疑——既不采信，也不否定，等真的需要用到它的时候再回头查。这六问不是给信息打分的考卷，它的作用很朴素：防止你“还没想就信了”。

第一问：它是什么？​

一个事实陈述、一个预测、一个评价，还是一个情绪表达？

四种东西的检验方式完全不同：事实可以核，预测只能等，评价要先看标准，情绪只能先承认。 把一条预测当成事实来处理，你会白等；把一段情绪当成评价来反驳，你会白吵。

《学会提问》要求的第一件事就是分清论题与结论。理由是：分不清之前，你根本不知道该拿什么去检验它。

第二问：谁说的？​

是一手（当事人、原始数据、原始论文），二手（转述），还是三手（“据说”“有研究显示”）？

《独立思考》把证据等级当成一个独立话题来讲。理由很实际：一句一手表述在转述过程中最先丢掉的，往往是“什么时候、对谁、在什么条件下”这类限定词。 而这些限定词恰恰是结论能不能成立的关键。

转述到第三手，通常只剩下最响亮的那个结论。

第三问：他为什么现在说？​

这句话说出来，谁得益、谁付钱、是说给谁听的？

这里有两个容易走偏的地方，要分开看。

第一，动机不干净不等于话说错了。一个想卖货的人，完全可能说对了事实。不能因为他是卖货的，就否定他说的内容。

第二，动机真正影响的不是真假，而是你该为核实它花多少力气。一个没有利益关联的人顺口说的一句话，你听过就算了；一个正靠这句话谋生的人给出的数字，你就得自己查一遍。

第四问：证据是什么等级？​

把证据从弱到强排个序：

  • 个人经历；
  • 单个案例故事；
  • 专家意见；
  • 有对照组的实验；
  • 多个独立来源都指向同一结论的综述研究。

顺序记不住没关系，记住一条判据就够用。凡是用“我认识一个人”“我朋友就是这样”来支撑一个普遍结论的，先把可信度降一级。

个案能证明“存在这种情况”，但证明不了“这种情况很普遍”。这两句话差别很大，而日常对话里它们经常被当成同一句。

第五问：有没有过期？​

价格、政策、技术方案、共识型结论都有保质期。

看到一个三年前的数字被当作现状引用时，先去找今年的版本，再回来判断它。因为数字一过期，往往整条论证跟着失效——后面所有的推算都建在这个数字上。

第六问：反向搜一次​

把结论加上“错了吗”“反例”“争议”这些词，再搜一遍，看有没有人早就反驳过它。

只搜支持自己的说法，是确认偏误最典型的动作，也有人把它列在思维错误的第一梯队里。

反向搜这一步的价值，不在于一定能搜到反例，而在于它逼你承认一件事：这条信息本来是有可能被推翻的。

别把六问用在所有信息上

每一片信息都走一遍六问，你一天什么也别想干了。

所以先做一次三秒分诊，只问一句话：这条信息会不会进入我的判断或决定？ 不会，直接划过去；会——尤其当它涉及钱、健康、孩子、职业、公开表态这五件事——再走六问。

分诊的意义在于，把你有限的核查力气集中到真正会影响你的那几条上。判断力是稀缺资源，不能平摊给每一条推送。

清单二：论证拆解与谬误识别​

拆解任何一段论证，按下面六步走。

① 论题   这到底是在争论什么？是不是中途被换了题目？
② 结论   他最想让我接受的那一句是什么？（常常不在开头）
③ 理由   支撑结论的理由有几条？哪一条是主梁，哪几条只是装饰？
④ 假设   要让这些理由成立，必须先默认什么？（价值观假设 + 描述性假设）
⑤ 概念   关键概念的定义清不清晰？"能力""风险""成功"指的是同一件事吗？
⑥ 反例   什么样的证据出现，会让他（和我）改变结论？

六步里，第四步和第六步最值钱，也最常被跳过。第四步挖出没说出口的前提，第六步把结论变成可检验的。

一条观点如果说不清“什么情况能推翻我”，那它就不是一个完整的观点，只是一个立场。立场只能用来表态，观点才能拿来讨论。

第五步对应逻辑学的第一条基本要求——同一律：同一个概念在同一段论证里必须始终指同一件事。

日常争论里那些吵到最后说“其实我们在说两件事”的场面，大多出在这里。一边在说“风险大不大”，另一边在说“风险值不值”——用了同一个词，指的却是两回事。

十四种常见谬误速查​

先提醒一句：认识这些名词，不是为了去抓别人的错——那会直接变成八个常见误用里讲的第一个坑（把批判性思维用成抬杠）。它的真正用途，是让你在自己讲道理时能听见这几种熟悉的声音，然后停下来重新组织一遍。

谬误长什么样怎么破
诉诸人身因为你这个人不行，所以你说的不行把人的问题与话的问题分开，各算各的
稻草人先把对方说成一个更蠢的版本，再打那个版本让对方复述一遍你的说法，对不上就先别反驳
诉诸权威因为是某专家说的，所以对问：他这句话是在他的专业范围内吗
诉诸大众大家都这么说流行度不是证据，只说明传播做得好
虚假两难要么 A，要么 B找第三个选项，或问“A 和 B 能不能都做一点”
滑坡一旦开了这个口，就会一路滑到底问每一级台阶的必然性，多数台阶是断的
循环论证用结论本身当理由把理由里的词换成同义词，看是不是原地打转
以偏概全三个案例得出一个普遍结论问样本有多大、怎么选的
幸存者偏差只看活下来的、成功的问那些同样做但失败的去哪了
事后归因先后发生，就说成因果找替代原因，问有没有对照组
举证责任倒置你证明不了它是假的，所以它是真的主张者举证，“不能证明”不等于“成立”
完美主义谬误做不到 100 分，所以干脆不做问“做到 60 分有没有价值”
诉诸情绪用恐惧或同情替代理由承认情绪，再单独问证据在哪
转移论题顺着一个词拐到别处去了把话拽回原论题，再往下走

这些谬误听起来像“一看就知道”的常识，但在真实场景里极难识别，因为它们很少以明显的坏样子出现。有一本用一百个日常生活案例讲谬误的书，说得很到位：绝大多数谬误不是明目张胆的胡说，而是“一半的真理”。

它有一半是对的，所以听起来可信；坏掉的那一半藏在没人注意的限定条件里，比如省掉了对象、时机、样本大小，或者省略了“在什么情况下才成立”。

所以识别谬误的关键，往往不是认出名词，而是把那个被省掉的限定条件找回来。

还有一处归类要说清。“以偏概全”和“幸存者偏差”两种归法都成立：既算论证结构上的谬误，也算解释信息时的偏误（见偏误清单）。两种归法不冲突——看你要修正的，是别人的论证，还是自己的判断。

带走的清单​

六问（信息）    它是什么 / 谁说的 / 他为什么现在说
                证据什么等级 / 过期没有 / 反向搜一次
                先三秒分诊：会进入判断或决定的，才走完六问

六步（论证）    论题 / 结论 / 理由（哪条是主梁）/ 假设 / 概念 / 反例
                第四步与第六步最值钱：挖出隐含前提、问出推翻条件

  • 信息筛完、论证拆开，下一步通常就是拍板：拍板前后十二问。
  • 如果你要拆的是自己的判断而不是别人的论证，先看两个干扰源。
