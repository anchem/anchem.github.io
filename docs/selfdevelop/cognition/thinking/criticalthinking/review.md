# 复盘：把一次经历变成一条判据

判断力不是从“多想想”里长出来的，是从**写下预期 → 等结果 → 对账**这个循环里长出来的。

这一篇给四张表，周期不同：

- **每周**：10 分钟，只改一条判据；
- **每月**：30 分钟，统计偏误与判断准确率；
- **单次**：一个决定结账时用；
- **每季**：看三个月趋势。

它们只有一条共同要求：**对照当时写下的字，不对照现在的记忆。**

## 为什么复盘有效：六句话 {#metacognition}

- **元认知的实质，是把自己当成一个观察对象。** 不只是想事情，还要知道自己正在怎么想。大多数人的观点其实停留在两个档位之间——要么是“未经思考就接受了”，要么是“接受了以后专门为它辩护”。这两档看起来相反，其实是一回事：都没有真正检验过自己的看法。只有走出这两档，才谈得上独立思考。
- **记账是唯一真正的杠杆。** 原因很实在：不写下来，你永远可以说“我本来就是这么想的”，于是每一次结果都没法变成经验。
- **复盘要先防结果污染。** 顺序是先复盘过程，再看结果；先问“当时我知道什么”，再问“现在我知道了什么”。反过来做，你的复盘就只剩一句话——赢了的都对，输了的都错。
- **要复盘的是判据，不只是结论。** 同一类错误反复出现，多半不是因为你不用心，而是你的判据写得太笼统。“下次要更谨慎”不是判据，“下次涉及他人的支出超过一千元，必须过一晚再定”才是判据。判据具体到这个程度，下次才能一眼看出自己有没有做到。
- **还要看清缺的是哪一样。** 判据改了却仍然做不到，问题往往不出在判据上。知与行之间的距离可以分成知识、动机、技能、习惯、环境五个档位。**定位错了，补的就不是缺的那一样。** 如果你缺的是环境，再加十条判据也没用，该做的是把手机拿出卧室。
- **能讲清楚，是认知到位最便宜的证据。** 把一件事讲到外行也能听懂，说明你至少已经把它的结构理清了。换一套说法讲一遍，卡住的地方就自己露出来了。

## 每周复盘（10 分钟）{#review-week}

每周花 10 分钟，回答下面五个问题。**注意第五题只写一条**——写三条以上的，下周一条都不会改。

| # | 问题 | 我的回答 |
| --- | --- | --- |
| 1 | 这周我改变过看法吗？因为什么？ | |
| 2 | 这周我遇到的哪条信息，我其实没核查就信了？ | |
| 3 | 这周哪次决定，是情绪在替我做的？ | |
| 4 | 这周我说过“大家都这么说”“我就知道”吗？ | |
| 5 | 下周我要改的一条判据是什么？ | |

## 每月复盘（30 分钟）{#review-month}

分三部分，按顺序做。

**第一部分：偏误频次统计。** 用[八个体感信号](./guards.md#tool-signal)逐条记命中次数。

注意记的是**次数**，不是“有没有犯”——只有记次数，才能看出趋势。

| 预警信号 | 本月次数 | 最近一次的具体事 | 下月对策 |
| --- | --- | --- | --- |
| “我早就是这么想的” | | | |
| “大家都这么说” | | | |
| “这次不一样” | | | |
| “已经投了这么多了” | | | |
| “我先找找支持这个说法的资料” | | | |
| “我现在就要定” | | | |
| “这数字看着挺有道理” | | | |
| 状态不佳（饿 / 困 / 赶时间 / 刚被打断） | | | |

**第二部分：判断准确率。** 翻开决策日志，把到了复查日期的条目逐条判定，重点看当时写下的把握程度与实际结果差了多少。

| # | 当时的决定 | 把握程度 | 实际结果 | 判定（判断对 / 判断错 / 被运气救了 / 被运气坑了） | 事后看，当时漏了什么 |
| --- | --- | --- | --- | --- | --- |
| 1 | | | | | |
| 2 | | | | | |

判定的关键在“判定”那一列：**要把“被运气救了”单独记成一类，不能和判断对混在一起。** 否则你会把运气当成能力，越练越自信、越自信越不准。

**第三部分：三条改进。** 一句话各写一条：下月要停掉的一个动作、要加上的一个动作、要改的一条判据。三条都要能被检查，不要写“多思考”这类词。

## 单次决策复盘卡 {#review-decision}

重要决定过了复查期以后，用这张卡复盘：10 个字段，一次填完，不要分几次。

字段的顺序就是当时的思考顺序。照着填，顺便就能发现你当初哪一步是跳过的。

```text
1  我在决定什么：
2  当时的验收标准：
3  当时可选的选项（至少三个）：
4  我选的方案与理由：
5  我的把握程度（0-100）：
6  什么会让我改主意：
7  实际结果：
8  分开看：判断质量如何 / 结果质量如何 / 差在哪
9  运气占了多大比例：
10 下次同类事情要改的那一条判据：
```

第 8 条和第 10 条是整张卡的用处所在。第 8 条强迫你把判断质量和结果质量分开；第 10 条把这次经历变成一个能带走的判据。

**没有第 10 条，这张卡就只是一份日记。**

## 季度偏误热力图 {#review-quarter}

每月复盘统计的是八条信号，这里先把它们归成五类，再把三个月的数字并排抄成一张表——八条分开看太碎，归成五类才看得出趋势。

看趋势，不看绝对值：某一类这个月命中 5 次、上个月 4 次，说明不了什么；但连续三个月都在 4 次以上，就说明它根本没被解决。

| 信号类别（归并自八条） | 第 1 月 | 第 2 月 | 第 3 月 | 趋势 |
| --- | --- | --- | --- | --- |
| 确认偏误类（只找支持的证据） | | | | |
| 从众 / 权威类 | | | | |
| 情绪类 | | | | |
| 沉没成本类 | | | | |
| 过度自信 / 计划谬误类 | | | | |

**判据只有一条：某一条连续三个月没有下降，说明你一直在靠“提醒自己”改它，而它需要的是流程。** 这时候该做的不是更用力，而是给它设计一个必须经过的步骤——比如“这类决定一律先写三个选项再说”。
