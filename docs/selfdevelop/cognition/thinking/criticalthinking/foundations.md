# 判断力是什么，在跟什么作对

前几篇给的是工具，这一篇回答“为什么”。只想动手的话可以先跳过——**但知道为什么，“怎么问”才不容易走形。**

这一篇讲两件事：批判性思维到底是什么（以及它不是什么），以及它在跟什么样的对手作对。第二件事比听起来重要：**偏误、谬误、噪声经常被混着说，它们的解法其实完全不同。**

## 它是什么，不是什么 {#definition}

- **它是对思考的思考。** 它不产生观点，只评估一个观点背后的推理过程质量如何。所以用它之前，你得先有一个观点——别人给的也行，自己想的也行。
- **它服务两个具体问题：该相信什么，该做什么。** 更准确地说，它是一种可反思、可反省的思维方式，而不是一种模糊的态度。这两个问题的答案，决定了你后面所有的行动。
- **它有明确的技能项。** 它不是一种性格，而是一组可以逐项练的能力：分析、沟通、调查、保持心智开放、容忍模糊、创造性解决问题。注意“容忍模糊”也在里面——很多人的问题不是不会分析，而是受不了“暂时没有答案”。
- **它不等于聪明，不等于学历，也不等于会辩论。** 这一条最反直觉：聪明人在犯错时反而更有优势，因为他们更擅长为自己的错找理由。**同一套偏误，在聪明人手里效率更高。**
- **它不负责从 0 到 1。** 产生想法归创造力管，这一块它不管。创造与批判是同一个思考过程的两个阶段：先发散、后收敛，而且**两个阶段不能同时进行**——一边想点子一边挑毛病，点子会先死掉。
- **它有成本。** 批判性思维要花时间和精力，所以必须分配着用：对高风险、不可逆、会影响他人的事用全力；对“今天中午吃什么”，不值得。**公平地对待每件事，等于对重要的事不公平。**

## 你的对手有三个：偏误、谬误与噪声 {#catalog}

这三样东西经常被混着说，但它们指的完全不是一回事：一个关于你的大脑怎么工作，一个关于论证的结构，一个关于判断的波动。**对手不同，解法也就不同。**

| 类别 | 对手是什么 | 典型代表 | 主要解法 |
| --- | --- | --- | --- |
| 认知偏误 | 大脑的默认快捷方式 | 确认偏误、锚定、损失厌恶、沉没成本 | 换视角、慢下来、记下来 |
| 逻辑谬误 | 论证的结构漏洞 | 稻草人、滑坡、虚假两难、循环论证 | 拆结构（[论证六步](./checks.md#tool-argument)） |
| 噪声 | 判断的不必要波动 | 水平噪声、模式噪声、情境噪声 | 结构化流程、独立判断后聚合 |

这个区分最实际的用处在这里：**如果问题是噪声，“更用心”是没用的**，得靠流程；如果问题是偏误，靠的往往是换视角。用错方法，再努力也白费。

### 认知偏误：按发生位置分组

按偏误在判断流程里出现的位置分组，比按字母顺序背要有用得多——**位置告诉你该在什么时候防它。**

**一、获取信息时**

- 确认偏误（只看支持自己的）；
- 可得性偏差（容易想到的当成常见的）；
- 选择性知觉（看见想看见的）；
- 锚定效应（被第一个数字锁住）。

这一组的问题在于：你还没开始思考，输入就已经被筛过一遍了。所以解法不在“想得更仔细”，而在主动去找反向的信息。

**二、解释信息时**

- 事后诸葛亮偏误（“我早知道”）；
- 叙事偏误（连贯的故事比零散的数据更可信）；
- 归因偏误（成功归于自己、失败归于环境）；
- 代表性偏差（用“像不像典型”代替概率判断）；
- 幸存者偏差（只看得见活下来的那些）。

这一组影响的是你怎么理解已经到手的材料。同一堆事实，换一个解释框架就可能得出不同结论。

**三、做决定时，与“怕失去”有关**

- 损失厌恶（同样大小的损失比收益更疼）；
- 沉没成本（已经花掉的不肯放弃）；
- 现状偏好（默认不改）；
- 禀赋效应（自己的东西更值钱）。

这一组都与“损失”有关：人要失去点什么时的反应，比能得到同样多时的反应强烈得多。

**四、做决定时，与“估计不准”有关**

- 过度自信（对自己估计留的余量不够）；
- 计划谬误（低估时间与成本）；
- 框架效应（换个说法就换个选择）；
- 承诺升级（投得越多越不肯撤）。

**五、受他人影响时**

- 从众；
- 权威偏误；
- 互惠；
- 稀缺（限时限量让人抢）；
- 嫉妒。

这一组不太像“思考错误”，更像社会压力，但后果一样：你的判断变成了别人判断的复制品。

### 噪声：前面所有清单都盖不住的那一块

偏误清单再长，也回答不了“为什么同一个人今天和昨天判得不一样”。这一块是噪声的领域。它把“判断不准”拆成三种不同的来源：

- **水平噪声**：不同人之间尺子的松紧不一样。同样是给方案打分，甲整体上就是比乙严——不管面前放的是什么方案，甲都倾向于给低分，乙都倾向于给高分。于是同一份材料交给这两个人，会得到两个不同的结论，而这个差异跟材料本身好不好毫无关系，只跟“谁在看”有关。
- **模式噪声**：同一个人对不同类别的东西有稳定的偏爱或厌恶，而他自己意识不到。比如某位评审对文字流畅的方案总是多给几分，对排版朴素的方案总是少给几分——这不是水平高低的问题，而是他有自己没察觉的口味。
- **情境噪声**：同一个人、同一个问题，换个时间问，答案会变。饿的时候、下午最困的时候、刚被别的事惹毛的时候，判断都会漂移。当事人通常毫无感觉，还以为自己一直很客观。

它的结论很硬。**在很多真实场景里（医生诊断、法官量刑、招聘面试），噪声造成的误差并不比偏误小，而人对噪声毫无感觉。**

偏误至少还有个方向，噪声连方向都没有——你甚至意识不到自己今天和昨天判得不一样。所以解法不是“更用心”，而是**决策卫生**：

- 结构化提问；
- 先各自独立判断，再聚合；
- 用外部参照代替记忆；
- 把一个大判断拆成几项，分别打分再合成。

这几条听着琐碎，却是目前唯一对噪声有效的办法。

## 带走的清单

```text
三种对手，三种解法
  认知偏误 → 换视角、慢下来、记下来
  逻辑谬误 → 拆结构
  噪声     → 结构化流程、独立判断后聚合（"更用心"没用）

定义的四条边界
  是对思考的思考，不产生观点
  服务"该信什么、该做什么"两个问题
  不等于聪明 / 学历 / 会辩论
  不负责从 0 到 1，而且有成本，要分配着用
```
