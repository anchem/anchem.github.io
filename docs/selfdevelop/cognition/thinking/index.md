# 思维

思维模型是看待问题、处理信息的固定视角。好的思维模型不能替你得出答案，但能保证你不漏掉关键的问题。

- [批判性思维](./criticalthinking.md)：对思考的思考，评估思考和论证的质量。它不负责从 0 到 1 构建思考。
- [批判性思维实战手册](./critical-thinking-playbook.md)：上面那份清单的展开版。五张可当场使用的清单、18 条分场景动作、30 天启动计划与复盘模板，另附书目地图与八种常见误用的纠正方法。

- 创造性思维（整理中）
- [责任圈思维模型](./responsibilitycycle.md)：区分个人范畴与可控领域，把精力集中在自己能改变的事情上。
