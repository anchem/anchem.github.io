# 个人成长

> 成为更好的自己，是解决一切问题的根本。

从 **健康、认知、能力、观点** 四个维度，系统性记录个人成长的知识与实践：健康是根基，认知是内核，能力是利器，观点是方向。

| 板块 | 回答的问题 | 主要内容 |
| --- | --- | --- |
| [健康](./health/index.md) | 如何维护身体这台底层硬件 | 运动、饮食 |
| [认知](./cognition/index.md) | 如何学习、如何思考 | 学习与知识体系、思维模型 |
| [能力](./ability/index.md) | 如何把认知转化为结果 | 管理、成事、决策、展示 |
| [观点](./outlook/index.md) | 如何看待人性、社会与人生 | 基本活动、人性、事业、社会 |

四个维度由内而外：健康与认知修炼自身，能力向外做功，观点则为前三者提供方向和判据。
