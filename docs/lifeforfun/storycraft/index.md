# 故事创作

我最初是被一个具体问题推着走进这个题目的：为什么有些故事里的人，我只看他做了一件事，就相信他是个什么人；而有些角色，作者给他写了一整页性格介绍，我依然记不住他。

后来发现，答案不在“介绍”里，在**结构**里——他想要什么、什么东西挡着他、他在压力下怎么选、这个选择让他付出了什么。这四样东西摆齐了，人物就自己站起来了。而一旦你掌握了这套看人的方法，你会发现它读的不只是虚构人物。

## 为什么用故事来学“人”

有三条理由，让我觉得故事是现实生活之外最划算的一所练人学校。

**第一，故事里的人是被放大的，所以看得清。** 现实中一个人的动机散落在十年的琐事里，你很难看见因果；故事把十年压缩到两小时，把动机拉成一条完整的线。莎士比亚让麦克白在十几个场景里走完从犹豫到疯狂的全过程，这在你身边的朋友身上可能需要二十年才能看清。

**第二，故事允许你反复重放。** 现实中你对一个人物的判断是一次性的、不可回退的；在故事里你可以把同一段戏读三遍，换一个视角再看一遍，甚至假设“如果当时他选了另一边会怎样”。这种可以反复推演的观察机会，在现实里极其昂贵。

**第三，好故事天然反刻板印象。** 一个写得好的角色，作者必须让他同时拥有互相拉扯的两面，否则没有戏。你越熟悉这套手艺，就越不容易把真人塞进一个标签里——这正是我想在现实里得到的能力。

:::tip[这套材料和“看剧写观后感”的区别]

它不是替你把作品讲一遍，而是把作者的**手艺**拆出来：这个人物的动机是怎么埋下的、他的缺陷是从哪一句台词露出来的、他转变得以成立的那个支点是什么。拆完之后，你手里拿到的是一套可以拿去读真人、也拿去改自己的工具。

:::

## 这套知识体系长什么样

它分五层：

| 层 | 名字 | 回答什么 | 对应篇目 |
| --- | --- | --- | --- |
| 第一层 | 核心概念 | 人物凭什么“立”起来？扁平与圆形差在哪？ | 核心概念 |
| 第二层 | 原型与性格理论 | 有哪些现成的类型工具箱？各自的边界是什么？ | 原型地图 |
| 第三层 | 塑造方法 | 作者具体用什么手段把性格写出来？ | 塑造方法 |
| 第四层 | 人物类型拆解 | 五类最常见的原型，逐类拆小说、影视与真实案例 | 五个类型页 |
| 第五层 | 生活迁移 | 这套眼光怎么用到识人、沟通、共情、边界、冲突、自我叙事上 | 生活迁移总纲 |

第一到第三层是“看得懂”，第四层是“拆得开”，第五层是“用得上”。**只读到第四层，你得到的是一个爱好；读到第五层，你得到的是一套看人的方法。**

## 结构骨架

五个类型页共用同一个骨架，方便你对位比较。展开任意一篇，你会看到同样八节：

1. **核心概念**：这个原型的内核是什么，用最直白的话说清。
2. **典型性格与亚型**：至少三种具体变体，以及各自的行为特征。
3. **塑造方法**：作者是用什么手段把这个类型写活的。
4. **案例拆解**：一个小说案例、一个影视案例、一个真实案例，逐个说明它怎么体现性格、作者/现实用了什么塑造逻辑。
5. **场景演绎**：把同一个人物放进四种不同场景，推演他会说什么、做什么、隐藏什么、改变什么。
6. **生活迁移**：这类人在现实里怎么被识别、怎么相处、怎么设边界。（这一节是重点，篇幅最长。）
7. **对比与反思**：这类原型的长处、风险、以及最常见的刻板印象怎么破除。
8. **问题思考**：三个把自己套进去的问题，用来检验你是真懂了还是记住了词。

## 三条建议

**一，先看结构，再看标签。** 原型是用来看“动机如何运转”的，不是用来给人发身份牌的。任何人贴上原型标签之后就停止观察，标签就变成了伤害——无论对虚构人物还是对真人。

**二，真实案例只作观察练习，不作定性。** 材料里出现的真实人物都来自公开史料、公开审判、公开出版物或公开报道。对每一个，文中都会写明**分析角度**，并且只讨论那一个角度，不推断其私生活，不给整个人下结论。真实的人比任何原型都复杂，也更少被看清。

**三，把最重的功夫花在生活迁移上。** 前四层是知识，第五层是能力和修养。读完就忘是正常的，用到自己身上才不算白读。
