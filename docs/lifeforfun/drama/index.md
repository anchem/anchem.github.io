# 影视剧

影视剧是生活的镜像——把人性、抉择、时代浓缩到有限的时间里反复推演。这里记录我从影视剧中提炼的认知与启示，不是观后感，是借作品思考。

## 已收录

- [《大明王朝1566》](./ming-dynasty-1566.md)：明代嘉隆之际的朝堂博弈，权术、人性与制度的三重切片

## 关联主题

影视剧中提炼的主题与[个人成长](../../selfdevelop/index.md)各板块互相印证，以下列出本板块内容触及的核心主题，便于从作品回到方法论：

- [人性](../../selfdevelop/outlook/humanity/index.md)：动机、立场、行为模式
- [社会](../../selfdevelop/outlook/society/index.md)：政治、经济、法律的运行规则
- [决策能力](../../selfdevelop/ability/decisionmaking/index.md)：在不确定中做出高质量选择
- [管理能力](../../selfdevelop/ability/management/index.md)：帝王术、用人、资源调配
- [思维](../../selfdevelop/cognition/thinking/index.md)：批判性思维、责任圈

> 作品是镜，方法论是尺。从作品里看见人性的样貌，再回到方法论去找解释和应对——这种往返才是看剧的进阶姿势。
